# アソビルド

コーヒー1杯、ポテトM、カップ麺3分。**制約のなかでミニゲームを作る**YouTube「アソビルド」で生まれたものを、その場で遊べるようにした場所です。

▶ **https://asobuild.coenoma.com**

スマホでもPCでも、タップ（またはスペースキー）だけで遊べます。ログインもインストールも要りません。

---

## このリポジトリの見どころ

番組では「コードを1文字も書かずに作る」ということをやっています。
そのために、**面白さが毎回ちゃんと入るようにする仕掛け**をリポジトリ側に持たせています。

### 1本のゲームは2ファイルしかない

```
src/games/hanko/
├── meta.ts    # 名前・あそびかた・称号
└── game.ts    # init / step / draw / bot の4つだけ
```

タイトル画面、スコア、自己ベスト、1タップのリトライ、称号、共有、
240×320のドット表示、効果音——これらは全部共通の仕組みが持っています。

### 「面白さ」をボットが数字で検査する

```bash
npm run fun -- hanko
```

3種類のボット（放置・でたらめ・上手い）に数百回プレイさせて、こう出ます。

```
ハンコ課長 (hanko)  合格
  放置    生存   7秒   スコア    0
  でたらめ 生存  15秒   スコア   20
  上手い  生存  43秒   スコア  649 (p90 993 / 最高 1237)

  ✓ 放置すると死ぬ（緊張があるか）        … 7秒（基準 8秒以内）
  ✓ 初見でも点が入る（1回で帰らないか）    … でたらめ操作の中央値 20点
  ✓ 連打だけでは勝てない                  … 15秒（基準 30秒以内）
  ✓ 腕前が効く（運ゲーでない）            … 上手い/でたらめ = 32倍
  ✓ 上手くてもいつか終わる                … 決着率 100%
  ✓ 上振れがある（今日は乗ってる、が起きる）… p90/p50 = 1.6倍
  ✓ 一気に遊びきれる長さ（やりきり感）    … およそ 9分で「部長」まで到達
```

落ちた項目には「何を直せばいいか」が出ます。
面白さそのものは人が決めますが、**面白くなりようがない状態**は機械で弾けます。

### 細かい工夫を貯めていく

「なぜあれは何度も遊ばれたのか」を作り込みのレベル（判定の甘さ、失敗したときの落ち方、
目標の刻み方）まで調べて、[docs/design/feel-catalog.md](docs/design/feel-catalog.md) に貯めています。
調べるたびに、次に作るゲームが強くなる、という作りです。

## 開発

```bash
npm ci
npm run dev                  # http://localhost:3020
npm run new -- <slug>        # ゲームの雛形を作る
npm run fun -- <slug>        # 面白さゲート
npm run check                # 型・ゲート・ビルド
```

詳しくは [docs/guides/はじめかた.md](docs/guides/はじめかた.md)。
