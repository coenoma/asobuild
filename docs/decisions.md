# 決めたことの記録

**「なぜそう決めたのか」を後から拾えるようにするための索引。**

原則や手順そのものはここに書かない。**正は各ドキュメント**で、ここに置くのは
「いつ・何を・なぜ決めたか」と、**正がどこにあるか**へのリンクだけ。

> 🔴 **中身をここに複製しない。** 複製した瞬間に、片方が必ず腐る。
> 3行で足りないなら、それは決定ではなく設計なので `docs/plans/` へ。

## 書き足すのはこういうとき

- オーナーが判断したとき（「これはやらない」「この順で行く」）
- 方針を変えたとき（前と違うことをするなら、前の判断を消さずに新しい行を足す）
- 企画・実装をボツにしたとき（**ボツの理由がいちばん価値がある**。同じ案が半年後にまた出てくる）

**消さない。** 覆った決定は「覆った」と書いて残す。判断の履歴そのものが資産になる。
