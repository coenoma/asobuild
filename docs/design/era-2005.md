# 2005年前後の空気 ── 時代背景・価値観・流行のカタログ

[retro-style.md](./retro-style.md) が「**見た目と手触り**の時代考証」なら、ここは「**中身**の時代考証」。
題材のタネ・画面の文言・称号の名前・診断系の企画・動画の問いかけ（「覚えてます？」）の材料庫にする。

**使い方**

- 作る前に、企画に関係する章だけ拾い読みする（全部読む文書ではない）
- **空気は隠し味。** 全部の要素を盛ると「平成テーマパーク」になって嘘くさくなる。1本に2〜3個
- **この文書に固有名詞を書くのはよい（研究）。ゲームに持ち込むのはだめ（表現）。**
  持ち込んでよいのは文化の**構造**だけ → [rights-and-originality.md](./rights-and-originality.md)
- すべてのゲームに適用する話ではない。使うかは企画ごと

---

## まず、この時代を一言で

> **「みんなと同じものを見ている最後の時代」と「自分だけのネット人格を持ちはじめた最初の時代」の重なり。**

全国共通の話題（ドラマ・ヒット曲）がまだ強烈に効く一方で、ネット広告費は2005年に**前年比54.8%増**、
mixi は同年**8月100万人→12月200万人**へ急増。マスの最後とパーソナルの最初が同居している。

### いちばん深い鉱脈は、消えた「人間関係のルール」

ガラケー・プリクラ・着うたは**舞台装置**。本当に「あーーー、あった！」が起きるのは、
いまはもう消滅した**行動のルール**のほう。

- **返信までの分数を読む**（実測: 返信が早いと「脈アリ」と感じる10代後半女性 55.8%。Vodafone 2006調査）
- ハートの数を数える。「？」で終わっているかを見る。件名が Re:Re:Re: になっていく
- **足あとを残すか残さないか**で悩む。「昨日あの人が見に来てた」が最大のイベント
- 既読が無い。**だから想像の余白が巨大**。同時に「返さなきゃいけない圧力」もこの頃に始まっていた

攻略の対象がアルゴリズムではなく**人間関係そのもの**だった、というのがこの時代のゲーム性。
題材に迷ったら、モノより先にここを掘る。

## ケータイの生活実感

| 当時の事実 | ゲームでの使いどころ |
|---|---|
| **パケ死**。定額前は従量制で、画像1枚に緊張感があった | 「1回の通信が重い」ことが緊張になる設計。残量ゲージもの |
| **赤外線通信**。連絡先も画像も、端末を突き合わせて渡す | 「共有＝そばに居る人へ手渡し」の距離感。対面2人プレイの口実 |
| **着メロ→着うた→着うたフル**（2004）。曲を「持ってる」が自慢 | 集める・自慢する、の単位。称号を「◯◯を手に入れた」形に |
| **待ち受け画像＝自分**。デコ待ち受け（画嬢）を配る文化 | リザルトを「待ち受けにどうぞ」の形で共有画像化（share は実装済み） |
| **センター問い合わせ**。圏外から戻ると未受信メールが届く儀式 | 「あとからまとめて結果が届く」演出。待つことが遊びになる |
| **月額315円の公式サイト**。占い・着メロ・ゲームを「登録」する | 診断系の画面様式（メニュー・改行の多い縦長ページ・「▼次へ」） |
| メールは1日何十通。絵文字と「一行の温度」に気を使う | 画面文言の型。短文・絵文字1個ぶんの感情（retro-style §5 と対） |
| **メールの読み合い**。寝る前の「おやすみメール」がうれしい女性 70.5%（Vodafone 2006調査）。ハートの数・メアドのセンス・「？」で終えるか、も全部シグナルだった | 推理・判定もの（脈アリ鑑定）／返信タイミングの間合いゲーム |

## ネットの空気（家のPC側）

- **個人サイト文化**: キリ番（切りのいいカウンタ番号を踏むと報告）、相互リンク、BBS、
  「お絵かき掲示板」、`<marquee>` で流れる文字、工事中GIF。**Flash倉庫**でゲームと動画を漁る
- **ハンドルネームが本体**。本名でネットに出るのは危ないという共通感覚。ネットとリアルは別人格
- **2005年はブログ元年の熱**（流行語トップテン）。「トラックバック」が通じた唯一の時代
- **mixi**（2004〜・招待制）: 2005年に**8月100万人→12月200万人**へ急増（公式年表）。
  あしあと・日記・コミュニティ。バズる場所ではなく、**知っている人に見られる場所**
- **前略プロフィール**（2004〜）: 100問に答えて「自分」を作る。中高生の名刺
- **バトン**（2005大流行）: 質問リストに答えて「次は◯◯さんに回します」。
  **診断とSNSシェアの中間にあった、この時代の"拡散"の形**
- **電車男**（2005映画・ドラマ）: ネット発の物語が地上波に。アキバ系・メイド喫茶・「◯◯萌え」が一般語に
- **のまネコ騒動**（2005）: ネット文化と商業の距離がはじめて社会問題になった年

## 教室と放課後

- **プリクラ帳**: プリクラを貼って回し見る。「落書き」機能の全盛。盛る前夜の「デカ目」黎明
- **プロフ帳・交換日記**: 紙の質問帳。「好きなタイプは？」「最近の口ぐせは？」——
  **質問に答えて自分を開示する遊び**がもともと紙にあった（バトンはこれのネット版）
- **ゲーセン**: ムシキング（2003）・ラブandベリー（2004）のカード筐体に行列。音ゲーとメダルとUFOキャッチャー
- **DSと脳トレ**（2004-2005）: 「ゲーム＝子どものもの」が崩れて、親も脳年齢を測った
- 放課後の連絡は「学校で決める→家に帰ってメール」。既読という概念がない世界

## 診断・占いの文化（診断系企画はまずここ）

**2005年前後は、日本の茶の間が占いを一番信じていた時期。**

- **動物占い**（1999〜ブーム）: 生年月日→12動物。「初対面の話題」の定番を作った元祖
- **細木数子・六星占術**（2004〜TV全盛）: 「地獄に落ちるわよ」。断言の芸
- **オーラの泉**（2005〜）: オーラの色・前世。スピリチュアルがゴールデンに
- **朝の星座占いランキング**: めざまし系。12位の日は本当に少しへこんだ
- **心理テスト本・深層心理クイズ**: 「森で最初に出会う動物は？」→「それはあなたの恋愛観」
- **ケータイ公式の占いサイト**（月額課金）: 相性診断・姓名判断。「彼との相性 78%」
- **血液型性格診断ブーム**（2004ごろ。TV企画が大量発生し、放送の第三者機関が注意を出したほど）:
  「性格を4つに分けて盛り上がる」文化は MBTI 以前に茶の間へ完備されていた
  （科学的根拠は無い、まで含めて当時の空気）
- 後年だが同じ文法: **脳内メーカー・成分解析**（2007）——「名前を入れるだけ」の飛び道具

### この文化の構造（借りてよいのはここ）

1. **入力は軽い**（生年月日・名前・数問）。**出力は断言**（「あなたは◯◯タイプ」。留保をつけない）
2. 結果には**キャラが割り当たる**（動物・色・武将）。数値やレーダーチャートではなく**二つ名**
3. **ラッキーアイテム**的な「明日から使える一言」が付く
4. 見せ合って「当たってる〜！」までが1セット。**共有の単位は教室とメール転送**
5. 深刻にしない。**外れても笑って済む重さ**に留める（本気の適性検査にしない）

### 画面様式の型（日本の2005。海外の「Y2K」メタリックに寄せない）

縦1列・白背景にピンク／水色／オレンジ・★☆♪・「NEW!!」・ランキング・今日の◯◯・
①②③で選ぶ・「▼次へ」「もどる」「決定」・「通信中…」。
シェアの言葉は**「友だちにメールで教える」「プロフに貼る」「待受に保存」**
（「Xに投稿」は存在しない世界。共有ボタンの文言から時代が出る）。

## 言葉のタネ

[retro-style §5](./retro-style.md)（書き方の規則）と対。こちらは**語彙の在庫**。

- 教室の言葉: 「ヤバイ」「マジで？」「ありえない」「ウケる」「キモい」「〜じゃね？」「テンション上がる」
- ネットの言葉: 「キタ━━━」「orz」「乙」「ｗｗｗ」「ちょｗ」「ネ申」「〜してみた」「今北産業」
- ギャル文字・小文字: 「ぁたし」「ょろしく」（2002〜04ピーク。**読めなさも含めて時代**）
- メールの型: 件名に本文を書く／「返信不要だよ」の気づかい／絵文字は1通に数個の節度
- **使い分け**: 画面の説明文は標準語のまま（retro-style の規則が優先）。
  時代の言葉を使ってよいのは**キャラのセリフ・称号・診断の結果文**まで

## 価値観の核（8つ）

1. **ネットとリアルは別人格**。匿名が普通で、実名は事件
2. **共有は手渡し**。赤外線・メール転送・回し見。「拡散」はまだ無く、届く範囲に体温がある
3. **持ってることが偉い**。着うた・レアカード・限定待ち受け。ストリーミング以前の所有の重さ
4. **待つことに慣れている**。ダウンロードも、返信も、週1の放送も。待ち時間が期待を育てた
5. **ランキングと診断をみんなで信じる遊び**。本気で信じてはいないが、乗るのが礼儀
6. **「大人が知らない場所」がある**。深夜ラジオ・個人サイト・ケータイの中。秘密基地の感覚
7. **上昇と不安が同居する**。「ちょいモテオヤジ」「富裕層」が流行語トップテンに入る年に、
   『下流社会』が刊行され（「格差社会」が流行語になるのは翌2006年）、モテと成功を臆面なく
   語る空気と「世の中、開いてない？」の不安が並ぶ。**パラメータを「モテ度★★★★」と
   堂々と出せた時代**（エビちゃんOL・愛され系ファッションもこの文脈）
8. **結婚は標準コース、でも役割は崩れ始め**。2005年の独身者調査（出生動向基本調査）では
   「いずれ結婚するつもり」が男女とも9割前後。一方「夫は外で働き、妻は家庭を守る」への
   賛成は3割前後まで下がり、「家族とは別に自分自身の目標を持つべき」は8割超。
   **この移行期のねじれ（恋愛／仕事／家族／自分らしさの綱引き）が、選択もの企画の葛藤軸になる**

## 現代→2005翻訳の手順（架空の新作の型②を時代側から支える）

1. 現代の題材の**中心の快感**を1行にする（MBTIなら「自分にタイプ名が付いて、人と見せ合える」）
2. その快感が2005年に**どの文化で満たされていたか**をこの文書から探す（→診断・占い／バトン／プロフ帳）
3. **入出力を当時の形式に翻訳する**（シェアボタン→メール転送・待ち受け保存、ストーリー→バトン）。
   考え方は「2005年にスマホアプリがあったら」ではなく
   **「2005年の携帯サイトに、なぜか2026年のサービスが存在していたら」**
4. 温度を合わせる（断言・二つ名・ラッキーアイテム・外れても笑える重さ）
5. 現代の名前は出さない（動画タイトルで「◯◯みたいな」と言うのはよい → [権利の線引き](./rights-and-originality.md)）

### 実例:「もし2005年にMBTIがあったら」

正確には「2020年代の16タイプ診断ブームが、2005年の若者文化にワープしたら」。
血液型ブーム（上記）が茶の間に完備されていたので、受け皿は当時から万全にある。

- **軸を輸入しない。4軸そのものを2005年の行動で作り直す**:
  即レス ⇄ じらし／大勢でワイワイ ⇄ ふたりで深く／モテたい ⇄ 自分らしく／様子を見る ⇄ 我が道。
  軸が自作なら、そこから生まれる16タイプは骨組みごとオリジナルになる
- **質問自体が2005年体験**（診断を受ける過程が懐かしさの本体）:
  - 「好きな人から23:48にメールが届いた！」A 30秒で返す／B 5分置く／C 朝返す／D 電話しちゃう
  - 「気になる人のmixiを発見。」A 即見る／B 足あとが残るから今日は見ない／
    C 友だちに先に見てもらう／D 自分の日記を更新して向こうから来るのを待つ
- **結果はカタカナの二つ名＋★のパラメータ＋断言3行**:
  「即レス小悪魔」——メール★★★★☆ モテ★★★★★ 一途度★★☆☆☆。
  「好きな人には即レスなのに、たまに急に止まるあなた。」最後に相性◎／相性△と明日のラッキー行動。
  二つ名の在庫: 足あと探偵・深夜長文ロマンチスト・メアドこだわり職人・着うた布教人・
  プリ帳プロデューサー・放課後ムードメーカー
- **型**: `oneshot` × `keitai`。全12〜20問、1問1画面「▼次へ」
- **共有**: 「待ち受けにどうぞ」（実装済みの share がそのまま使える）＋
  結果文の末尾は**バトンの文法**——「このURL、5人に回してね」
- **画面様式**: 上の「画面様式の型」。実在の月額表記などを茶化しすぎない
- **権利メモ**: MBTI は実在の検査・商標。名前・4文字コード・公式の軸名やタイプ名
  （「建築家」等）をゲーム内に出さない。**軸を自作していれば「16タイプ」という骨組み自体は
  誰のものでもない**
- **ゲートの注意**: oneshot は「最後までたどり着ける・初見でも進める・画面が動く」を見る
  （[genre-map.md](./genre-map.md)）。診断系は**結果の共有文が本体**なので、
  playtest の「人に言いたくなったか」を厳しめに

## 題材のタネ（在庫であって、企画の決定ではない）

使う前に必ず: 型に落ちるか（[genre-map.md](./genre-map.md)）・規模は§0のまま・権利距離・
**恋愛の重さは企画ごとに判断**（この時代は恋愛が濃いが、番組の顔にするかは別の話）。

**「もし2005年に◯◯があったら」の変換表**

| 2026年の当たり前 | 2005年の受け皿 | メモ |
|---|---|---|
| 16タイプ診断 | ケータイ人格診断（上の実例） | 第一候補。企画意図が結果画面だけで伝わる |
| Instagram | プリ帳・写メ・ブログ | 「盛る」前夜の加工文化 |
| Spotify | 着うた・MD | 「聴き放題」の逆＝1曲を持つ重さ |
| BeReal | 写メ日記 | 「今すぐ撮って送る」の原型はある |
| ChatGPT | 携帯サイトの「なんでも相談」窓口 | 深夜の秘密基地感と相性がいい |
| マッチングアプリ | ⚠️ そのままは扱わない | 出会い系の文脈は番組のトーンと合わない。やるなら「メル友・文通」の距離まで離す |

**単発のタネ**: 脈アリメール鑑定（Re:の数・ハート・返信分数から推理／oneshot）・
足あとをつけるな！（見たいが見られたくない潜入パズル）・赤外線、届いて！（対面2人で角度合わせ）・
メアド職人2005（作って判定される）・返信は何分後？（間合いの読み）・
ブログタイトル選手権（いちばん平成なのはどれだ）・放課後17:42（選択肢だけの超短編恋愛）。

待受メーカー・プリ帳デコのような「作るおもちゃ」は、スコアと bot の型に落ちにくい
（genre-map の外縁）。やるなら**共有画像が本体の oneshot** に畳むこと。
