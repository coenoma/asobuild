# 共有記憶のヒキ ── 触った瞬間に「あーーー！」が起きる条件

[era-2005.md](./era-2005.md) が「何があったか」の材料庫なら、ここは**選定の理論**。
どの記憶を題材にすれば、触った瞬間に声が出て、コメント欄が同窓会になるのか。
そして「モノ」ではなく**体験（感覚）そのものを再現するゲーム**をどう作るのか。

> ヒキは知名度とは別物。**知名度＝知っている**（video-doctrine の題材変数）、
> **ヒキ＝身体が反応する**。両方◎の題材が一軍。

---

## ヒキの採点（6条件）

| # | 条件 | 問い |
|---|---|---|
| 1 | **全員が通った道** | 当時その機械を持っていた人は、例外なく体験したか |
| 2 | **感情つきの記憶** | イライラ・祈り・恐怖・優越感が張り付いているか（事実だけの記憶は懐かしくない） |
| 3 | **手が覚えている** | 操作・音・間合いを、言葉より先に身体が思い出すか |
| 4 | **いまは完全に消えている** | 半分生きている習慣は懐かしさが薄い。**絶滅していること** |
| 5 | **一言で蘇る** | 「センター問い合わせ、連打したよね」——この一言で全部伝わるか |
| 6 | **語りたくなる差分** | キャリア・機種・世代・地域で微妙に違ったか（コメント欄の燃料） |

◎○△で採点して、**◎5つ以上だけを作る**。4つ以下は「懐かしいけど伸びない」に落ちやすい。

## 知らない人も楽しめる、の設計

当時を知らない人は「置いていかれる客」ではない。**世代間のコメントの往復**
（「あったあった！」×「え、これマジだったんですか」）がいちばん強い燃料になる。

- **不便は、強度があれば理不尽ギャグとして初見でも笑える**（押しても届かない。もう一回。まだ届かない）
- 感情曲線は普遍にする: 送りたい→届かない→工夫する→祈る→届いた。**時代知識ゼロで成立する曲線**
- 🔴 **順番が命: 知らない人がチュートリアル無しで遊べて、遊び終わってから「実話」と知る。**
  冒頭で歴史解説を始めた瞬間に、体験は教材になる
- 「※これは実話です」は**結果画面に1行**。ここが知らない人を「マジ？」コメントに変えるスイッチ

## 体験再現ものの設計文法（7つ）

スコアアタックではなく「感覚の再演」を作るときの決まり。型は既存のもの（action / oneshot）に落とす。

1. **不便を削らない。不便が主役。** fun-doctrine ②「3秒で最初の1点」とぶつかったら、
   最初の1点を**最初の失敗**に読み替える（失敗が進行になる設計にする）
2. **「祈り」を操作に変換する。** 待つだけにしない。波を読む・間合いを合わせる——
   当時は運だったものに、ゲームでは腕の余地を作る（これでゲートの「腕前が効く」が立つ）
3. **成就の瞬間に最大の祝福**（punch・ジングル）。当時は無音でうれしかったぶんを、ゲームが代わりに鳴らす
4. **スコア＝思い出の定量化。** 「0:47に届いた」がそのまま共有文になる。称号は世代の呼び名にする
5. **差分をひとつだけ仕込む。** 開始時に1回だけ選ばせる（ケータイの色など）。性能差はつけない。
   それだけでコメント欄が三つ巴になる
6. 実在の社名・機種名は出さない（色と雰囲気で描く）→ [rights-and-originality.md](./rights-and-originality.md)
7. 「実話です」は短く、盛らない（[video-doctrine](../video/video-doctrine.md) の誠実と同じ）

## フル実例: 「あけおめ、とどけ！」

**事実（裏取り済み）**: 元旦0時前後は「おめでとうメール・コール」が集中して繋がりにくくなり、
業界団体と携帯各社が毎年「控えて」と公式に呼びかけ、**利用制限までかけていた**。
この年中行事はのちに消滅した（＝条件4を満たす）。

- **採点**: 全員が通った道◎／感情（祈り）◎／手が覚えている（センター問い合わせ連打）◎／
  絶滅◎／一言で蘇る◎／差分（キャリア・過ごし方）◎ —— **6条件ぜんぶ◎の一軍**
- **型**: `action` × `keitai`。12月31日 23:58 から始まる
- **導入**: こたつとパカパカ。「0:00になったら『あけおめ』をおくろう」——説明はこれだけ
- **0:00**: 送信→「そうしんちゅう…」→「おくれませんでした」。
  画面の奥に**全国のみんなも押している波**が見える（説明ではなく絵で分からせる）
- **操作**: 輻輳の波が画面に見えていて、**波の谷で押すと通りやすい**（祈り→波読みへの変換。1ボタン）
- **緊張軸**: 電池。押すたび減る。連打すると「しばらくおくれません」
  （実際にあった利用制限の再演が、そのまま「連打では勝てない」ゲートを満たす）
- **途中**: 友だちからの「あけおめ」がセンターに溜まる→問い合わせで受信。届く側の喜びも入れる
- **スコア**: 届いた時刻と届けた人数。称号は「0:03 いちばんのり」「0:47 ねばりがち」「7:12 初日の出組」
- **リザルト**: 「※2000年代、元旦0時のメールは本当に届きませんでした。
  各社が『控えて』と呼びかけるほどでした」——実話の1行はここ
- **差分**: 最初に「どの色のケータイ？」（3色。中身は同じ）
- **ゲート見込み**: 放置＝電池が切れて死ぬ／連打＝制限で勝てない／波読み＝腕前／
  レア着弾（写メ年賀）＝上振れ。既存の action 項目にそのまま乗る
- **playtest の追加の自問**: 「終わったあと、誰かに『これあったよね』と言いたくなったか」
