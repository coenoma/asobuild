# 2000年代の手触りの出し方

「なんか懐かしい」は雰囲気ではなく、いくつかの具体的な制約から生まれている。
毎回ゼロから雰囲気を作らずに済むよう、効く要素だけを並べておく。

> ここに書いてあるのは主に **keitai 機種（240×320 のガラケー）** の手触り。
> PCブラウザ（flash）・ゲーセン（arcade）では寸法も質感も変わる。
> 機種の一覧と選び方は [platforms.md](./platforms.md)。§5（文言）と §6（やりすぎない）は全機種共通。

---

## 1. 画面が粗いこと（これが9割）

keitai 機種では **240×320（当時のQVGA縦持ち）** に描いて、それを引き伸ばして表示している。
拡大は補間なし（`image-rendering: pixelated`）なので、**何を描いても勝手にドットが粗くなる**。

- ドット風のフォントを読み込む必要はない。システムフォントで十分ドットになる
- 高解像度で描いてから縮小してはいけない（せっかくの粗さが消える）
- 座標は整数で扱う。`Painter` の `rect` は自動で丸めている

## 2. 色数を絞ること

`src/arcade/palette.ts` の10色だけを使う。生の `#hex` を書かない。

| テーマ | 出自 | 向いているもの |
|---|---|---|
| `keitai` | 2005年ごろのカラー液晶 | 既定。迷ったらこれ |
| `mono` | モノクロ液晶 | 形だけで見せたいとき。難度は上がる |
| `flash` | 2003年ごろの個人サイトのFlash | 白地・原色。ポップにしたいとき |

色を増やしたくなったら、それは形で表現できていないサイン。

## 3. 音は「ピコピコ」だけ

効果音は矩形波の合成で作る（音源ファイルを持たない）。
`sfx.tap() / score() / combo() / hit() / over() / best()` で足りる。
音を凝り始めると15分では終わらない。

## 4. 当時っぽい題材の選び方

当時のゲームは、題材が驚くほど身近で、しかもくだらなかった。

- 身の回りの物や動作（ハンコ、傘、自転車、コピー機、社員証）
- 名詞そのものが動詞になる（のばす、よける、つむ、はさむ、ならべる）
- タイトルは4〜6文字＋役職や属性（「◯◯課長」「◯◯番長」「◯◯マスター」）

**題材が地味なほど、当時っぽくなる。** 宇宙やドラゴンより、書類とハンコのほうが正解に近い。

## 5. 文言の書き方

- ひらがな・カタカナ多め、漢字は最小限（「見のがし」「カラぶり」「もどり中」）
- 判定表示は4〜6文字（「ドンピシャ」「ナイス」「セーフ」）
- 「！」は使ってよい。「✨」などの絵文字は使わない
- 英語を使わない（当時の端末は英語表記が少なかった）
  - 例外は**打つ文字そのものを見せるとき**（タイピング）。これは文言ではなく遊びの対象なので別。
    ただし説明・称号・判定表示は、そのゲームでも日本語で書く

## 6. やりすぎないこと

- 画面全体を揺らす、点滅させるのは1フレーム〜0.3秒まで
- スキャンライン風のフィルタは入れない（当時の液晶にスキャンラインはない）
- 「レトロ風」を狙った過剰なノイズ・グリッチは、当時のものではなく2010年代の演出

**当時の人は懐かしさを演出していない。** ただ性能が低かっただけ。そこを再現するのが正解。
