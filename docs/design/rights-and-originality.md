# 既存作を扱うときの線引き

「AIだけであのゲームを再現できる？」「記憶だけを頼りに作れる？」という企画をやる可能性がある。
そのとき守る線をここに固定する。**迷ったら公開しない側に倒す。**

---

## 原則

**遊びの仕組みを参考にすることと、具体的な表現をコピーすることは、まったく別のこと。**

前者は誰にでも許されている。後者は許されていない。この2つを混ぜないことがすべて。

### 参考にしてよい（遊びの仕組み）

たとえば自動で走り続けるゲームなら、こういうもの。

- 自動で前進する
- タップでジャンプする
- 穴を避ける
- 距離を競う
- だんだん難しくなる

こうしたルールの組み合わせは、誰のものでもない。
むしろ [feel-catalog.md](./feel-catalog.md) に貯めているような**なぜそれが面白いのか**の理解こそ、
持ち帰るべきもの。

### 必ずオリジナルで作る（具体的な表現）

| 対象 | 補足 |
|---|---|
| キャラクター | シルエット・色・モチーフまで変える |
| グラフィック全般 | 一切の模写をしない |
| UI | 配置・書体・配色を自分で決める |
| BGM・効果音 | 公式音源はもちろん、耳コピもしない |
| ステージ配置・数値 | 障害物の並び、速度、判定幅を自分で決める |
| タイトル・ロゴ | 元作品を連想させる語を含めない |
| コード | 移植・逆コンパイル・書き写しをしない |
| その他アセット | フォント・アイコン含む |

**公式の画像・音源・コードは、いかなる形でも持ち込まない。**

---

## 公開の段階ごとに判断が変わる

「作った」と「出した」は別。段階ごとに基準が上がる。

| 段階 | 基準 |
|---|---|
| **① 手元で試す** | 検証のために忠実に作ることはありうる。ただし**これを作った時点では公開可否は何も決まっていない** |
| **② 動画に映す** | 「自分だけで遊ぶ」とは別。画面に映る表現が元作品に寄りすぎていないかを確認する |
| **③ Webで公開する（誰でも遊べる）** | いちばん厳しい。**「既存ゲームのコピー」ではなく「遊びの構造や当時のゲーム文化から着想したオリジナル作品」として成立**していること |

①で作ったものを、そのまま②③に持っていってよいと考えないこと。
**手元の実験と公開物は、別に作り直すのが前提。**

---

## 公開前チェックリスト

`docs/design/rights-and-originality.md` のこの節を、公開のたびに通す。

- [ ] キャラクターの見た目（形・色・モチーフ）は独自か
- [ ] タイトルとロゴは独自か。元作品を連想させる語を含んでいないか
- [ ] UIの配置・書体・配色は独自か
- [ ] 音はすべて自前で生成しているか
- [ ] ステージ配置・速度・判定幅などの数値は自分で決めたか
- [ ] コードはすべて自分で書いたか
- [ ] ゲーム内・ページ内・共有文に元作品の名前が出ていないか
- [ ] `meta.inspiration` に「何から着想し、何を借り、何を自作したか」を書いたか
- [ ] **スクリーンショットを並べたとき、別の作品に見えるか**

### 「寄りすぎ」の判定基準

問うべきは「元作品を知らない人が見て分かるか」ではない。

> **元作品を知っている人が見て、同じ作品だと誤認するか。**

誤認しうるなら寄りすぎ。表現を離す。

## 気づいたら、必ず言う

これは作業ルールであると同時に、**AIに対する指示**でもある。

実装を進めながら「これは公開版ではもっとオリジナルに離した方がよい」と判断したら、
黙って作り続けず、**その場で明示的に指摘すること**。

- 「この見た目は元作品に寄りすぎているので、公開版では変えたほうがよい」
- 「このタイトルは元作品を連想させるので、別の名前にしたほうがよい」

指摘せずに完成させると、判断の機会そのものが失われる。
**作れてしまうことと、出してよいことは別**であり、後者を判断できるのは人間だけ。

## 記録を残す

着想元があるゲームは `meta.inspiration` に必ず書く。

```ts
inspiration: {
  from: '2000年代の自動横スクロール系',
  borrowed: '自動で前進して1ボタンで跳ぶという仕組み',
  original: 'キャラクター・絵・音・UI・地形の配置・コード',
},
```

これはゲームページにそのまま表示される。隠さず出すことが誠実さの表明になるし、
動画で「何を参考にして、どこを自分で作ったのか」を話すときの材料にもなる。

`npm run fun` を走らせると、`inspiration` があるゲームには公開前チェックの案内が出る。

## 商標・実在の商品

制約として現物（コーヒー、ポテト）を撮影するのは問題ない。
ただし**ゲームの中に企業名・商品名・ロゴを持ち込まない**。

- ⭕️ 動画で「マックのポテトMを食べ終わるまで」と言う、実物を映す
- ❌ ゲーム内に実在のロゴを描く、商品名をタイトルに使う
