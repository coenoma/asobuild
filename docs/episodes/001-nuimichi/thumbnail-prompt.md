# YouTubeサムネイル制作依頼

YouTubeチャンネル「アソビルド」の第1回動画のサムネイルを制作してください。

## 重要

**素材はこのメッセージに添付している実写・実キャプチャ画像です。まず添付素材をすべて確認し、構成を考えてから制作に入ってください。**
添付素材の中身（顔・ゲーム画面・カップ・図解）を生成AIで描き直したり、別人・別画面に差し替えたりしないでください。使ってよいのは切り抜き・拡大・トリミング・配置・色調整・文字やあしらいの追加です。

## チャンネルについて

### 番組名

アソビルド

### コンセプト

「AIに◯◯って頼んでみたら、どうなるのか」をそのまま楽しむ実験番組です。

AIを使った技術解説チャンネルというより、

**「AIと遊んだら、何が起きるんだろう？」**

を楽しむエンタメ・実験番組として見せたいです。

たとえば、

* コーヒー1杯を飲み終わるまで
* ポテトMを食べ終わるまで

など、日常的で少しくだらない制限時間のなかでAIに何かを作らせます。

基本的に本人はコードを書かず、Claude CodeなどのAIにかなり雑な依頼を投げ、その結果起きる予想外の展開も含めて楽しむ番組です。

# 今回の動画

## タイトル

**AIにガラケー最強ゲーム"糸通し"みたいなのを作ってと言ったら…**

## 動画尺

10分16秒

## 内容

スタバのソイラテ・トール1杯を飲み終わるまで、という制限時間で、

「懐かしのガラケーゲーム『糸通し』みたいなの作って」

とClaude Codeにかなり雑に依頼します。

本人はコードを1文字も書きません。

開始から14〜15分ほどで最初のゲームが完成しますが、出てきたのは

**「白い四角と黄色い丸が動いているだけ」**

という、糸通しとは到底思えない謎のゲームでした。

ここが動画前半最大の笑いどころです。

その後、制限時間終了後も延長戦としてAIとのやり取りを続け、49分ほどで「針と糸」がちゃんと登場する糸通し風ゲームまで完成します。

本人の自己ベストは560点。

最終的には、

**「雑に頼んだだけなのに、元のゲームより面白いかもしれない。AIおそろしや」**

という着地になります。

# 今回のサムネで最も重視したいこと

第1回なので、視聴者は「アソビルド」も本人も知りません。

そのため、ブランド感よりまず、

**初見で「なんか面白そう」と思わせること**

を最優先してください。

特に今回狙いたい感情は、

**「AIすげえ！」ではなく「AI、何作ってんだよw」**

です。

完成したゲームのすごさではなく、

**AIに雑に頼んだ結果、予想外の変なものが生まれてしまった瞬間**

をサムネの中心にしてください。

---

# 最有力の構成 ── 「期待 → 現実」の2段で見せる

**重要:** 初見の視聴者は「糸通し」がどんなゲームか知りません。
「そうじゃない」のツッコミは、**期待した姿が見えていて初めて成立**します。

なので構成は、

* **小さく（上や左上）**: `itotoshi_zukai.png`（糸と針の図）＋「頼んだの ↓」「イメージ」程度の短い添え字
* **大きく（主役）**: 白い四角＋黄色い丸の謎ゲーム画面
* その間に矢印などで「→ 出てきたのがこれ」の流れ

という **期待→現実のギャップ構図**にしてください。
図解が「糸通しってこういうゲームね」を一瞬で説明し、その直後に謎の四角と丸が来ることで、
糸通しを知らない人にも「全然違うじゃん」が伝わります。

## 大きな文字

**「そうじゃない」**

を第一候補にしてください。

タイトルですでに

「AIに糸通しみたいなのを作ってと言ったら…」

と問いを作っているため、サムネでは同じ説明を繰り返さず、

タイトル
→ AIに糸通しを頼んだ

サムネ
→ **そうじゃない**

という掛け合いになるようにします。

「作れるのか」「AIで作った」などの説明的なコピーにはしないでください。

---

## 主役

添付の `game_1274.png`（または予備のゲーム画面）にある、

**白い四角＋黄色い丸だけの謎ゲーム画面**

をサムネの最大の主役にしてください。

ゲーム画面は元々240×320px程度の縦長レトロ携帯UIですが、そのまま小さく置くのではなく、

**中身がスマホ表示でも認識できるよう、大胆に拡大・トリミング**

してください。

視聴者が一瞬見ただけでも、

「何これ？」

となることを重視します。

---

## 本人の顔

添付の `face_1696.png` / `face_1700.png`（または予備）を使用します。

ただし、

**本人の顔そのものを主役にはしないでください。**

役割は、ゲーム画面を見た視聴者の代わりに

**「……え？」**

と反応する存在です。

オーバーなYouTube顔ではなく、

* 真顔
* 困惑
* 若干あきれている
* 思っていたものと違うものを見ている

くらいの自然な表情を優先してください。添付の表情のまま使い、加工で表情を盛らないでください。

本人がまだ無名なので、「顔だけを大きく見せればクリックされる」という設計にはしません。

---

## ソイラテ

添付の本人写真に写っている、手に持ったソイラテのカップを残してください。

これはスターバックスを見せたいわけではありません。

**「コーヒー1杯を飲み終わるまで」という制限時間企画**

を象徴する小道具として使います。

スターバックスのロゴをサムネの主役にはしないでください。

カップは自然に手に持っている程度でOKです。

---

## Claude Code

「Claude Code」を小さなバッジ・ラベル程度で入れてください。

これは、

**「AIを使った実験動画である」**

ことを初見でも理解してもらうための補助情報です。

Claude Codeという文字をサムネの主役にはしません。

例：

`Claude Code`

あるいは必要なら、

`AIに丸投げ`

などでも構いません。

# 視覚的な優先順位

おおよそのイメージとして、

* 謎のゲーム画面：50〜55%
* 本人：25〜30%
* 糸通しのイメージ図（期待側）：10〜15%
* カップ・Claude Codeなど：10%前後

くらいの存在感にしてください。

厳密な面積指定ではなく、

**「頼んだ絵（糸と針）を見る → 出てきた謎ゲームを見る → 本人の反応を見る → AI実験なのだと理解する」**

という視線誘導を重視してください。

# 生成AI背景について

今回は、

**ガラケー時代風の街・部屋・ネオンなどの生成AI背景は基本的に使わないでください。**

すでに添付のとおり、

* 実際のゲーム画面
* 本人の実写
* 実際のソイラテ
* 自作の糸通し図解

という本物の素材があります。

アソビルドでは、

**「AIが作った嘘みたいなものを、人間が現実世界で実際に遊んでいる」**

という感覚を大事にしたいです。

そのため、サムネ全体までAI生成世界にする必要はありません。

平成・ガラケー感を足す場合も、

* ドット
* ピクセル的な装飾
* 携帯ゲーム風UI
* 細い罫線
* ゲーム由来の配色

程度のグラフィック処理に留めてください。

# スマホ表示を最優先

YouTubeホーム画面の小さなサムネイルでも、

1. 頼んだイメージ（糸と針）と謎のゲームのギャップ
2. 「そうじゃない」
3. 本人の反応

が瞬時に認識できるようにしてください。

細かい文字や説明は不要です。

# 今後のシリーズ展開も意識する

今回だけの固定レイアウトを作る必要はありません。

代わりに、今後のアソビルドで共通して使える「サムネの文法」を意識してください。

基本形は、

1. AIが作った変なもの・面白いもの
2. 本人のリアクション
3. その回の制約を象徴する実物
4. AIツール名を小さく表示
5. 大文字コピーは「説明」ではなく「ツッコミ」

です。

今回なら、

**頼んだイメージ（自作の糸と針の図・小）
→ AIが作った謎の四角と丸（大）
＋困惑する本人
＋ソイラテ
＋Claude Code
＋「そうじゃない」**

という構成になります。
