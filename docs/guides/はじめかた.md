# はじめかた

## 用意するもの

- Node.js 22（`nvm use 22`）
- それだけ。データベースも API キーも要りません

```bash
npm ci
npm run dev      # http://localhost:3020
```

## ゲームを1本作る

```bash
# 1. 雛形を出す（登録まで自動）
npm run new -- potato --title "ポテトのばし" --howto "長押しでのばす" --control hold --constraint "マックのポテトM"

# 2. 触りながら書く
npm run dev

# 3. 数字で確かめる
npm run fun -- potato

# 4. 公開前に通しで確認
npm run check
```

書くのは `src/games/potato/` の2ファイルだけです。
タイトル画面・スコア・自己ベスト・リトライ・共有・称号の表示は、共通の仕組みが持っています。

## コマンド

| コマンド | 何をするか |
|---|---|
| `npm run dev` | 開発サーバー（ポート3020） |
| `npm run new -- <slug>` | ゲームの雛形を作って登録する |
| `npm run fun -- <slug>` | 面白さゲート。ボットに数百回遊ばせて数字を出す |
| `npm run fun:all` | 全ゲームのゲート |
| `npm run typecheck` | 型チェック |
| `npm run build` | 本番ビルド |
| `npm run check` | 型・ゲート・ビルドを通しで |

> ビルドを確認したあとは `rm -rf .next` で消しておくとディスクが助かります。

## 面白さゲートの読み方

3種類のボットに数百回プレイさせて、次を見ています。

- **放置** … 何もしないボット。これで生き残れるなら、緊張がない
- **でたらめ** … 適当に押すボット。初見の人に近い
- **上手い** … ゲームが用意したボット（`bot()`）。上手い人の再現

落ちた項目には必ず「→」で直し方が出ます。**感想で直さず、そこから手をつけてください。**

数字はあくまで足切りです。全部緑でも、遊んでみて「もう一回」と思わなければ作り直しです。
