# はじめかた

## 用意するもの

- Node.js 22（`nvm use 22`）
- それだけ。データベースも API キーも要りません

```bash
npm ci
npm run dev      # http://localhost:3020
```

## ゲームを1本作る

```bash
# 1. 雛形を出す（登録まで自動）
npm run new -- potato --title "ポテトのばし" --howto "長押しでのばす" --control hold --constraint "マックのポテトM"

# 2. 触りながら書く
npm run dev

# 3. 数字で確かめる
npm run fun -- potato

# 4. 公開前に通しで確認
npm run check
```

書くのは `src/games/potato/` の2ファイルだけです。
タイトル画面・スコア・自己ベスト・リトライ・共有・称号の表示は、共通の仕組みが持っています。

画面は「機種」で選べます（`--platform`）。既定はケータイ（240×320 縦）で、
当時のPCブラウザ（550×400 横・タイピングはここ）とゲーセン（384×224 横・パッド対応）があります。
その遊びが**当時どの画面で遊ばれていたか**で選んでください。
→ [機種の地図](../design/platforms.md)

## コマンド

| コマンド | 何をするか |
|---|---|
| `npm run dev` | 開発サーバー（ポート3020） |
| `npm run dev:rec` | 収録モード（チェックリスト＋カンペ自動起動） |
| `npm run new -- <slug>` | ゲームの雛形を作って登録する |
| `npm run fun -- <slug>` | 面白さゲート。ボットに数百回遊ばせて数字を出す |
| `npm run fun:all` | 全ゲームのゲート |
| `npm run fun -- <slug> --record` | いまの数字を基準として記録し直す |
| `npm run typecheck` | 型チェック |
| `npm run lint` | 規約チェック。**ゲームの絶対ルール**（乱数・時刻・生の `#hex` 等）も機械で見る |
| `npm run selftest` | ランタイムの自己検査。機種・操作・リプレイの配管が生きているか（1秒） |
| `npm run build` | 本番ビルド |
| `npm run status` | **いまのやり残しを一望する**（遊んでいない／記録が古い／未コミット） |
| `npm run check` | 型・規約・自己検査・ゲート・ビルドを通しで |
| `npm run playtest -- <slug>` | **実際に遊んだ結果を記録する**（6つの問い） |
| `npm run ship` | 公開前の確認（check＋遊んだ記録があるか） |
| `npm run tune -- <slug> --param <名前> --target smartSec=45` | 難度の当たりを二分探索で探す（提案のみ） |
| `npm run ogp` | 実プレイを焼いた OGP 画像を作る |
| `npm run say -- "文言"` | 収録カンペに一言を出す |
| `npm run live -- ...` | カンペのフェーズ・制限時間・台本書き出し |

> ビルドを確認したあとは `rm -rf .next` で消しておくとディスクが助かります。

## 面白さゲートの読み方

3種類のボットに数百回プレイさせて、次を見ています。

- **放置** … 何もしないボット。これで生き残れるなら、緊張がない
- **でたらめ** … 適当に押すボット。初見の人に近い
  （タイピングのように「でたらめでは構造的に成功できない」遊びだけ、ゲーム側の `novice()` に差し替わる。差し替わっていると結果に明示される）
- **上手い** … ゲームが用意したボット（`bot()`）。上手い人の再現

落ちた項目には必ず「→」で直し方が出ます。**感想で直さず、そこから手をつけてください。**

数字はあくまで足切りです。全部緑でも、遊んでみて「もう一回」と思わなければ作り直しです。

**これは一度実際に失敗しています。** たまごポン初版は全項目を通ったのに、
遊ぶと何をすればいいか分からないゲームでした。そこで、

```bash
npm run playtest -- <slug>
```

で**人が遊んだ記録**を残すようにしました。6つの問いに y/n で答えるだけです。
記録には実装の指紋が入るので、**ゲームを直すと記録は自動的に古くなり**、
`npm run ship` が「遊び直してください」と止めます。
