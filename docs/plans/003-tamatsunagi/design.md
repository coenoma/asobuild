# たまつなぎ（設計）

> 依頼: 「『糸通し』じゃないけど、糸通しのエッセンスを彷彿とさせるミニゲーム」

## 0. エッセンスの特定（何を借りるのか）

`docs/design/genre-map.md` の通り、当時の「糸通し」は
**タップで上昇 → 壁の穴を抜ける**（チャリ走／Papi Jump／SFCave と同じ系統）。
ここをそのまま作ると**遊びの仕組みごとコピー**になるので、作り方から外す。

借りるのは仕組みではなく、**あの手触りの中身**のほう。

| 糸通しの何が気持ちよかったか | このゲームでどう再現するか |
|---|---|
| 極小の穴に、細いものを通す | 玉の穴（判定 ±17px）に、幅3pxの針を通す |
| 通った瞬間の「スッ」 | 通過ごとにヒットストップ0.045秒＋音＋光の輪 |
| 惜しい失敗＝当たる、という緊張 | **穴を外して輪にかすると糸が切れる**（遠く外すのは無傷） |
| 細長いものが一直線に貫く絵 | 針は中央を一直線に上がり、糸がそのまま画面に残る |
| 息を止めて、思い切る | 針は0.3秒かけて上がる。**撃った後は変えられない** |

**借りていないもの**: タップで上昇する操作、横スクロールする壁、キャラクター、
画面構成、音、数値。→ `meta.inspiration` に同じ内容を書く。

## 1. 一行ルール

> **上から降りてくる玉を、下から針を突き上げて糸に通す。穴の真ん中なら通る。かすったら糸が切れる。**

## 2. なぜ「かすると死ぬ」なのか

糸通しの緊張は「惜しい」が失敗であることから来る。**大きく外すのは無傷、
ちょっと外すのが致命傷**という判定にすると、その緊張がそのまま出る。

- 玉の穴（見た目 r=15 / 判定 r=17 … 甘い側に外す）→ 通る
- 玉の輪（見た目 r=26 / 判定 r=24 … 辛い側に外す）→ **糸が切れる**
- それより外 → 何も起きない

判定を見た目より甘く／辛くする根拠は feel-catalog A章。

## 3. 上下で難しさが逆転する（このゲームの背骨）

**玉は下に降りるほど、揺れ幅が小さくなって中央（糸の真上）に寄ってくる。**

| 高さ | 揺れ幅 | 通しやすさ | 得点 |
|---|---|---|---|
| 上（y<105） | ±96px | 難しい（速く動く／針の到達まで0.3秒のリードが要る） | 5点 |
| 中（y<200） | ±50px 前後 | ふつう | 3点 |
| 下（y<268） | ±13px | 簡単（ほぼ真ん中にいる） | 1点 |
| 糸の高さ（y≧268） | ±8px | — | **糸に当たって切れる** |

これで次が同時に成立する。

- **放置すると必ず死ぬ** … 下では中央に寄るので、落ちきった玉は必ず糸を切る
- **初見でも点が入る** … 下で撃てばだいたい通る（ただし1点）
- **腕前が効く** … 稼ぐには上で通すしかない。上は揺れが大きく、0.3秒先を読む必要がある
- **連打では勝てない** … 適当に撃つと「かすり」を踏む

緊張の軸は1つ（**全体が速くなって詰まってくる**）。落下・揺れ・出現間隔を
同じ係数で上げるので、遊ぶ側には「だんだん忙しくなる」の1本に見える。

## 4. 上振れ（「今日は乗ってる」の作り方）

- **多重ぬき**: 1回の突きで複数の玉が縦に揃うと、2つで×2、3つ以上で×3
- **たかぬき**: 上のほうで通すと1つ5点
- **連続ボーナス**: 6連続ごとに倍率+1（上限×3）

一番おいしいのは「上で3つ縦に並んだ瞬間に撃つ」で、
**狙って起こせるが、外すと糸が切れる**。リスクを取る選択肢＝上振れ（feel-catalog D章）。

## 5. 失敗の見せ場

- かすった: 針が折れて飛ぶ（`launchTumble`）＋画面ゆれ＋「かすった！」
- 糸が3回切れた: **通した玉が全部ばらばらとほどけて落ちる**（重力520、回りながら）

積み上げたものが一瞬で散る絵にする。得点は残るので損はしないが、
「あと1個で…」がいちばん強く出る形（feel-catalog F章）。

## 6. 見ていない人にも伝わるか（broadcast-design）

| 見せたいこと | 画面での出し方 |
|---|---|
| 狙う場所 | 中央に点線のねらい線を常時引く |
| いま危ないか | 下のほうに来た玉は `bad`（赤）に変わる |
| どこが高得点か | 上の玉は `accent`（黄）、中は `ink`、下は `dim` |
| うまくいったか | 通った玉が糸を伝って画面下の列に増えていく |
| 失敗したか | 画面ゆれ＋針が飛ぶ＋残りの糸（●●●）が減る |

**最も映える瞬間**: 上で縦に3つ並んだところを一突きで抜く「3れんぬき」。
**結果を見たくなる点**: 糸が切れるまでに玉の列がどこまで伸びるか。

## 7. 権利

着想元は当時のケータイゲーム全般の「狭い隙間を通す」という遊びの手触り。
**遊びの仕組み（タップで上昇＋横スクロールの壁）は借りていない**ので、
スクリーンショットを並べても別の作品に見える。
`meta.inspiration` に「何から着想し、何を借り、何を自作したか」を記録する。

## 8. 決まっていない（実装後に実測して決める）

- 落下速度・出現間隔・揺れ速度の初期値と上がり方 → `npm run fun` の数字で詰める
- `meta.goals` の点数 → 上手いボットの中央値／到達分数を見てから置く
