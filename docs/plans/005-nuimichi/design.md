# ぬいみち（設計）

> 依頼: 「『糸通し』を彷彿とさせるが、このリポジトリの既存ゲームとは**面白さの肝が違う**もの」

## 0. 何を借りて、何を変えるか

「糸通し」の実体は、依頼者の記憶とレビューを突き合わせると次のとおり。

| | 中身 |
|---|---|
| 操作 | 何もしないと落ちる。押している長さで上がる。糸は右へ進み続ける |
| 手触り | 上がる速さと落ちる速さがほぼ同じで、どちらもゆっくり。だから軌跡が**ひとりでにうねる** |
| 目的 | 針の穴（めど）に上下を合わせて通す |
| 失敗 | 針に当たったら**その場で終わり**。派手な演出はなく、静かに「あ…」で終わる |
| 褒められた点 | 中毒性（もう一回）／**上達の快感**（最初は1本もやっと、コツを掴むと連続で通せる）／スキマ時間 |
| 不満点 | **難易度が高すぎる（判定がシビア）**／**単調**（変化が少なく飽きる） |

### 既存3本との重なりを避ける

このリポジトリの既存3本は、肝がすべて「**一瞬の判定精度**」に寄っている。

| | 面白さの肝 | 操作 |
|---|---|---|
| ハンコ課長 | 押す／押さないの選別＋タイミング | 一瞬 |
| たまごポン | ゲージを狙って止める精度 | 一瞬（離す） |
| たまつなぎ | 揺れる的の未来位置を読む予測射撃 | 一瞬（撃つ） |
| **ぬいみち** | **自分の軌道を作り続ける／続けて通す** | **連続** |

`003-tamatsunagi` は同じ「糸通しのエッセンス」から出発したが、
**タップで上昇する操作はあえて借りなかった**（コピーになるため）。
その残りをこちらが取る形になるので、**同じ元ネタから2本作っても中身が重ならない**。

このリポジトリで**自機を動かし続けるゲームは初**。既存3本は自機の位置という概念すら持たない。

## 1. 一行ルール

> **長おしで上がり、はなすと落ちる。立ちならぶ針のめどに糸を通す。1回でも当たったら終わり。**

## 2. 面白さの肝をどこにずらしたか

下敷き側の中心は「1つの穴を精度よく通す」で、**毎回おなじことをする**。
ここが「単調」という不満の正体なので、中心を「**続けて通す**」ほうへ移した。

- 通した本数がそのまま倍率になる（8本ごとに ×1 → ×5）
- 1回でも当たれば終わるので、**倍率＝そのプレイがどこまで続いたか**そのもの
- 後半ほど1本の重みが増す。同じ操作をしていても**緊張だけが上がっていく**

レビューが褒めた「コツを掴むと連続で通せるようになる」を、感想ではなく**得点式**に載せた形。

## 3. 単調さを消す仕掛け（選択を置く）

針は「太い針（めどが広い・1点）」と「細い針（めどがせまい・5点）」が上下に並んで立つ。

- 細い針は太い針のすぐ隣（中心間 57px）。**取りに行くと次の針まで持ち直す距離が増える**
- あいだの桟は 22px。**判定の甘さ（±6px）の2倍より厚くする**のが必須条件
  （薄いと両側の甘さが重なって桟が判定上ゼロになり、遊ぶ側はルールを読み違える。実際に起きた）
- 細い針のめどのそばに「5」と書く。凡例を隅に置くだけでは、遊んでいる最中の視線には入らない
- 速くなるほど次の針までに動ける距離が縮むので、**同じ選択が後半ほど重くなる**
- 遠くに置かないのは、離すと選択ではなく運になるから

fun-doctrine §3「押さないを選ばせる」を、この操作系に合わせて
「**取りに行かないを選ばせる**」に置き換えたもの。

## 4. 「難しすぎる」への答え

| 不満 | この作りでの答え |
|---|---|
| 判定がシビア | めどの判定は見た目より上下 6px ずつ甘い（feel-catalog A章） |
| 出だしで何もできない | 最初の4本はめどを大きく（半径 53→23px へ段階的に）、糸の入り口の高さの近くに置く |
| 配置が理不尽 | 次の針は「**いまの速さで届く範囲**」にしか置かない（`reachAt()`）。速くなると自動で振れ幅が縮む |
| 何が起きたか分からない | 通るたびに `+点数` が飛び、めどに糸が残り、縫い目の列が1つ増える（音を消しても分かる） |

## 5. 1ミスで終わりにした判断（原則から外した）

fun-doctrine §6 の目安は「ライフ3（1ミスで終わると理不尽）」だが、**ここは外した**。

- 下敷き側の「静かに一発で終わる」が懐かしさの芯で、3回耐えるとその終わり方が薄まる
- 「どうなったら終わりなのか分からない」という指摘への答えにもなる（当たったら終わり、で一言）

外したぶんの代償は、**開始直後の保護**で払っている。実測は次のとおり。

| | 保護なし | 保護あり（現行） |
|---|---|---|
| でたらめ操作のスコア中央値 | **0点**（ゲート落ち） | 2点 |
| でたらめ操作の生存中央値 | **2.9秒**（ゲート落ち） | 3.6秒 |

保護の中身は「最初の4本は、めどを大きく・糸の入り口の高さの近くに置く」。
**1回当たれば終わるゲームでは、保護は難度ではなく"配置"でやる**というのが今回の学び
（→ feel-catalog A章に追記済み）。

## 6. 上振れ（「今日は乗ってる」の作り方）

- 倍率が本数で上がるので、スコアは**生存時間に対して非線形**に伸びる
- 細い針をどれだけ拾えたかで、同じ生存時間でも点が変わる
- 実測 p90/p50 = 1.8倍（基準 1.3倍以上）

## 7. 失敗の見せ場

派手にしない。**当たった瞬間に糸の先が手を離れ、糸を引いたまま、
現実よりゆっくり回りながら落ちていく**（`launchTumble` + 重力380）。
判定表示は「あ…」の一言だけ。

feel-catalog F章の「現実より遅く落とす」は満たしつつ、
下敷き側の「静かに終わるシュールさ」を消さない形にしてある。

## 8. 見ていない人にも伝わるか（broadcast-design）

| 見せたいこと | 画面での出し方 |
|---|---|
| 何をしているか | 針が立ちならび、糸が**その跡を線で残しながら**うねって抜けていく |
| 通したか | めどに糸が残ったまま流れていく／`+点数`が飛ぶ／縫い目の列が増える |
| いま何倍か | 右上に `×N` を常時。左上に通した本数 |
| どこが高得点か | 細い針のめどだけ金の縁（凡例「ほそ針 5てん」を下段に常時） |
| どうなったら終わりか | 下段に「あたったら おわり」を常時 |
| 失敗したか | 画面ゆれ＋糸が切れる印＋針が赤く残る＋「あ…」 |

**最も映える瞬間**: 倍率が上がりきった後半で、細い針を続けて抜くところ。
**結果を見たくなる点**: 何本つながるか（＝倍率がどこまで上がるか）。

## 9. 権利

借りたのは**操作の手触りと、1回外したら終わりという潔さ**だけ。
遊びの仕組み（倍率が本数で上がる／太い針と細い針を選ばせる／通した針に糸が残る）、
絵・画面構成・音・称号・数値・コードはすべて自作。`meta.inspiration` に同じ内容を記録。

> ⚠️ 公開判断が要る点: モチーフ（針のめどに糸を通す）と操作（押すと上がる）は
> 下敷き側とはっきり重なる。**「遊びの構造から着想したオリジナル作品」として成立しているか**は
> 人が見て決めること。線引きは docs/design/rights-and-originality.md。

## 10. 実測（`npm run fun -- nuimichi`）

| 項目 | 数字 |
|---|---|
| 放置 | 生存 2.4秒 / 0点 |
| でたらめ | 生存 3.6秒 / 1点 |
| 上手い | 生存 51秒 / 594点（p90 968 / 最高 1481） |
| 一気に遊びきれる長さ | およそ14分で「おはり名人」（ボット基準） |

種を2つずらして（`--seed-offset=777` / `31337`）も全12項目合格。

### 終盤に難度が頭打ちになる穴（塞いだ）

針の間隔を**距離**で置いているので、速くなるほど次の針までの時間が縮み、
そのぶん上下に動ける距離（`reachAt`）も縮む。配置の振れ幅をその距離に比例させていたため、
**終盤ほどめどが一直線に並んで逆に易しくなっていた**（上手いボットの最高が中央値の10倍まで伸びた）。

40秒すぎから「届く距離をどこまで使い切るか」の係数を 0.75 → 0.95 へ上げて塞いだ。
序盤〜中盤（人が遊ぶ大半の時間）の手触りは変えていない。

## 11. 人にしか決められない残り

- 実際に3回遊んで「もう一回」と思うか（`npm run playtest -- nuimichi`）
- 難度がちょうどよいか（初回の実測: 4〜5プレイで232点。**やや難しい**という感触が出たので、
  速くなり方 1.5→1.2、判定の甘さ 4→6px、開始直後の保護を強化して緩めた。効いたかは要確認）
- 見た目の良し悪し

## 12. 遊んで出た指摘と、その一般化

初回のプレイテストで出たものと、直した先。**一般化できたものはカタログへ送ってある**。

| 指摘 | 直したこと | 一般化先 |
|---|---|---|
| 2つ穴の針のルールが分からない。通れないはずの所を通れた | 桟 11px → 22px（判定の甘さ×2 より厚く） | feel-catalog G章 |
| 特典が大きいのか伝わらない | 細い針のめどのそばに「5」を書く | feel-catalog G章 |
| 細い針を通ると「かくっとなる」 | ヒットストップ（0.05秒）を廃止。手応えは光と文字の大きさへ | feel-catalog B章 |
| 「ど真ん中」の表示が針とかぶって見にくい | 判定文字を、通しためどと反対側の段へ | feel-catalog G章 |
| どうなったら終わりか分からない | 1ミスで終了に変更＋下段に「あたったら おわり」を常時 | — |
| 「あと28点」が動かない | **共通シェル**の直し（自己ベスト基準であることを画面に出す） | `src/arcade/GameShell.tsx` |
