# 007 — 初速シーズン（001〜005）の計画（2026-08-14 オーナー決定）

チャンネル開設からの12週を**初速シーズン**として設計する。
「1本出す」ではなく「シーズンを開幕する」。1本ごとの出来より、
**型の反復・題材の知名度・止まらないこと**が成否を決める
（根拠: [YouTube調査の精査](../../video/research-notes/2026-08-13-youtube.md)。
題材知名度で50倍差・疑問形で7倍・バズは登録に変換されず型の反復が登録を作る、いずれも実測）。

---

## 成功の定義（数値目安型）

> **12週で 登録1,000・平均視聴維持40%・サイト週500プレイ を「目安」に置く。**
> 数字は撤退装置ではなく**操舵輪**。届かなくても、数字を見て設計を変え続けられているなら健康。

| 指標 | 12週の目安 | どこで見るか |
|---|---|---|
| チャンネル登録 | 1,000 | YouTube Studio |
| 平均視聴維持率（長尺） | 40% | YouTube Studio |
| サイトの週次プレイ（ページ閲覧で代替） | 500 | Vercel Web Analytics |
| 先行指標: サムネCTR | 4〜6% | YouTube Studio |
| 先行指標: コメント数/本 | 10+ | YouTube Studio |

### 12週後の判断（3分岐）

1. **目安達成、または右肩の伸び** → シーズン2へ（型は維持、題材在庫を補充）
2. **未達だが、学習が回っている**（設計を変えると数字が反応する因果が見えている）→ 続行
3. **学習が回らない**（何を変えても無反応）**かつ楽しくない** → 形を変える（頻度・路線・尺）。やめる判断もここでだけする

## ケイデンス（週1目標＋自動降格ルール）

- **週1公開を目標**にする。公開曜日・時刻は001公開時に固定する（型の反復の一部）
- **在庫（収録済み・未公開の素材本数）が2本を切ったら、次の公開から隔週に落とす。**
  ペースを守るために品質や規模を削らない（規模の憲法 fun-doctrine §0 は不変）。
  落とすのはペースであって、番組の約束ではない
- 収録は公開の2本先を歩く（公開001の週に003を収録している状態が定常）

## シーズンラインナップ（相乗効果順）

すべて**「〜みたいな」路線（架空の新作）**。[権利の線引き](../../design/rights-and-originality.md)と
[機種の地図](../../design/platforms.md)に従う。タイトルは「［制約］で、AIは［題材みたいなゲーム］を作れるのか」の型。

| # | 題材 | 機種・型・操作 | 狙い | 権利の注意 |
|---|---|---|---|---|
| 001 | 糸通し風（ぬいみち） | keitai・action・hold | 公開済みゲーム。動画は編集中 | 済み（inspiration 記録あり） |
| 002 | 寿司打風タイピング | flash・action・type | 実装が軽い・新機種のお披露目・**Zenn記事（技術層）と相乗** | タイピング文法は一般。回転寿司のUI・皿の意匠に寄せない |
| 003 | マリカ風レース | arcade・action・steer | **最大知名度を在庫がある状態で投入**・疑似3Dの見せ場 | レース文法（コース・アイテム・順位）は一般。キャラ・コース意匠・アイテムの見た目は独自に。疑似3Dまで（3Dはやらない） |
| 004 | たまごっち風育成 | keitai・nurture・tap | ガラケー文化ど真ん中・nurture型の初出し・コメント欄が同窓会になる題材 | 育成文法は一般。キャラのシルエット・卵型筐体の意匠に寄せない |
| 005 | 桃鉄ミニ | keitai・chance・tap | すごろく×地理・CPU対戦の初出し | 地理すごろく文法は一般。キャラ（貧乏神等）・物件名リスト・「◯◯電鉄」連想の名は使わない |

**採点の物差し**（次の題材を選ぶときも同じ4軸で）:
①題材の知名度（最大変数・実測50倍差）②動画映え（失敗と成功が画面で分かるか）
③権利距離（誤認テストを通せるか）④制作費（機種・型の初出しは高くつく）

**シーズン2以降は看板の外も混ぜる**（2026-08-18 方針）。平成を看板にしつつ、
心理診断・クイズ・恋愛・日常・雑学で需要を拾う。毎回まったく違うものを作るのが番組らしさで、
番組のフォーマット（作る→遊ぶ→結果→視聴者も遊べる）は同じなので散らからない。
ジャンルの地図・罠・在庫は [genre-crossover.md](../../design/genre-crossover.md)。
候補の筆頭は「暇つぶしゲーム丸投げ」「3問性格診断」「名前が出てこない物（言葉版）」「初デート アリナシ」。

**避ける題材**: テトリス風（商標・トレードドレスの係争史が長く、誤認の線が近すぎる）。
落ちもの文法を使いたくなったら、見た目と目的を大きくずらしてから相談。

## 視聴→プレイ→コメントのループ（この番組だけの堀）

他のAI開発チャンネルに真似できないのは「**視聴者がその場で遊べて、おだいURLで同じ盤面を競え、
スコアをコメントできる**」こと。これをアルゴリズムのエンゲージメント信号に変換する。

- 公開の日にやることは **[公開チェックリスト](../../video/publish-checklist.md)** に固定（概要欄・固定コメント・`meta.video`）
- 概要欄と固定コメントの文面は **[テンプレ](../../video/description-template.md)**
- **次回の冒頭で、前回のスコア・リクエストコメントを拾う**（リピーター製造機。チェックリストの公開後項目）
- サイト→動画の逆導線は実装済み（`meta.video` を書けばゲームページに埋め込みが出る）

## 計測（Vercel Web Analytics・導入決定）

- Cookie なし・個人情報なし・スクリプトタグ1行。「サーバーを持たない」方針と両立（layout.tsx）
- 動画からの流入は UTM で見分ける（形式はテンプレに固定。`utm_campaign=ep002-sushida` の形）
- **週次レビュー**: 週1回、[weekly.md](./weekly.md) に5指標＋気づき＋次に変えることを1行ずつ。
  見る→変える→また見る、が回っていること自体が健康の定義
