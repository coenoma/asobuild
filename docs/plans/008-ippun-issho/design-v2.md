# 一分一生（いっぷんいっしょう）── 設計 v2.1

> **v1 はオーナーの実機評価で「全然意味がわからなかった」「目的と違う」となり、作り直し**（2026-08-21）。
> v1 の設計は [design-v1.md](./design-v1.md)。v2 初版を辛口レビューにかけ、10点を直したのがこの v2.1（§19）。**これが実装の正。**

## 0. 目的の捉え直し

### v1 が外した理由

v1 は「ふきだしが出たら素早くタップ（3段階の判定）・赤いふきだしとねんね中は触るな・つつきすぎるとすねる」という、
**反射ゲームの文法**（このリポジトリの action 向け原則: 3秒で1点・押すな要素・上振れ）を育成に持ち込んでいた。
遊ぶ人には「何を急ぐのか・何をいいタイミングで押すのか・何をスルーするのか」の**ルールを覚える作業**になり、
しかもそれができても、たまごっち的な体験にはならない。

### v2 の目的

> **実物を続けられないガサツな人が、「なぜあれは愛されるのか」を1分で追体験して実感できるゲーム。**

ルールを覚えさせるのではなく、**あの遊びの感情の流れ**を1分に圧縮する。愛される理由を6つに分け、それぞれを仕掛けに写す。

| # | 愛される理由（本物の分析） | 1分での仕掛け |
|---|---|---|
| ① | **生きていて、自分を必要としてくれる**（勝手に暮らしていて、ときどき呼ぶ） | 呼ばれていない時間も**歩く・座る・こちらを見る・あくび・花を見に行く**。ときどき「よんでくる」。一生は止められない |
| ② | **何が欲しいか読んで応える、の積み重ねで「うちの子」になる** | 呼ぶ前に**しぐさ**が出る（おなかを押さえる・ボールを目で追う・見上げる）。しぐさの間に渡せたら「わかってる！」。**その子には好きなものが1つある**（最期に明かされる） |
| ③ | **育ちが自分の世話を映す。何になるかは最後まで分からない** | ごはん派ならまるく、あそび派ならはね、消してあげなければねぼすけ、ほっとけば旅に出る。せいちょうの瞬間に**理由が1行**出る。かくれた金色が1つ |
| ④ | **うんち・病気・寝顔 ── 小さな生き物らしさ** | うんちをする（そうじ）・かぜをひく（くすり）・寝る（でんきを消してあげる） |
| ⑤ | **別れがあるから、世話した時間に重さが出る** | 最後の8秒は別れのためだけにある。手を振り、**あなたが世話した回数**が記念に残り、たねになって芽が出る |
| ⑥ | **人に話したくなる**（「うちの、◯◯になった」） | 名前をつける。**共有文に「ぽち（もふまめ）は 92さいで たねになった」が入る** |

### v2 の憲法（v1 の逆）

- **押してはいけないものを作らない。** 間違えても「ちがうの…」と首を振るだけ。減点は一切ない
- **急がせない。** 反応の速さで点差をつけない。タイマーバーを出さない。最初の2回はあきらめない
- **数字を競わせない。** 判定テキストを出さない。返すのは顔・動き・ハート
- **画面にあるものは「キャラ」「ふきだし」「5つのボタン」だけ。** ふきだしの絵とボタンの絵は**同じ描画**
- **どんな育ち方も愛おしい。** ほったらかしの子は「のら→たび」になるが、それは失敗ではなくその子の人生

## 1. 一行ルール

> **よばれたら、ほしいものを おす。それだけ。**

```
題材: 1分で一生を終える小さな生き物「まめ」
型: nurture。機種 keitai。操作 aim（ボタンを選ぶ）
押す: ふきだしの絵と同じボタン（ごはん・あそぶ・そうじ・くすり・でんき）。なでては キャラをタップ
押さない: 無い
失敗: 無い（応えないと育ちと寿命に出るだけ）
上がる: 段階が進む。こどもになると「？」（何が欲しいか言わない）が増える＝読む楽しさが増える
称号: 仲の深さ 4段階（ともだち／なかよし／かぞく／あいぼう）
タイトル: 一分一生（slug: ippun-issho のまま）

── 見せる前提 ──
権利: 借りるのは「世話をすると育ち、どう世話したかで姿が変わる」という仕組みと、
      育成ゲーム全般の一般文法（食べる・遊ぶ・トイレ・薬・消灯）。絵・アイコン・キャラ・名前・終わり方・コードは自作（§16）
映える瞬間: ①しぐさを読んで先に渡し「わかってる！」 ②せいちょうで別の姿になり理由が出る ③うんち→そうじ ④最期に手を振る→たね→芽
結果が気になる点: 「何になるのか」「何さいまで生きるか」「かくれた金色は出るか」「この子の好きなものは何だったか」
成否の見えやすさ: ふきだしとボタンの絵が同じ／芽5つ（なかよし）／うんち・汗・Zzz・白眉
```

## 2. 操作（aim）── 判定は `input.tap`（押し始めの1フレーム）だけで行う

- **画面下に5つのボタン**（常に同じ位置・同じ絵・同じ順）: ごはん／あそぶ／そうじ／くすり／でんき
- **ふきだしの絵 ＝ ボタンの絵**（同じ `drawIcon(kind)` で描く）
- **絵つきのふきだしは、出た瞬間に同じ絵のボタンへ点線が飛ぶ**（1.4秒。でんき・そうじ・くすりも同じ）。**ふきだしが出ている間はそのボタンの枠を accent にしたまま**。ボタンは点滅させない
- **ふきだしをタップ** → もう一度点線（0.5秒）。「絵が同じ」を指で教える
- **キャラをタップ**:
  - ふきだしが出ているとき → **答え**として解釈。「なでて」なら正解、それ以外は「ちがうの…」
  - ふきだしが無いとき → **なでる** +1（クールタイム1.0秒。中は「えへへ」で点なし）。一生で得点になるのは15回まで（以後はハートだけ浮く＝「もう十分なでてもらった」）
- **「？」のふきだし**: 何が欲しいか言わない。しぐさで読む（§4）。**1回外すか3.5秒たったら絵を見せて、ふきだしを3秒延長**
- **空を押す**（何も無い所）: キャラがこちらをちらっと見る（0.3秒）
- **ねんね中のボタン・キャラ**: 「すやすや…」。でんきだけ効く
- **たまご期**: どこを押しても「ぽかぽか」。たまごのまわりの輪は孵化まで薄く脈打って残す（押した瞬間だけ濃く）
- **なまえ中**: カード以外を押すとカードが揺れて「なまえを えらんでね」
- **できごと中の関係ないボタン**: 「ちがうの…」
- **かぜ中のキャラ**: 「つらそう…」（汗が1つ落ちる）
- **飾った花をタップ**: キャラが花を見に行く（0.8秒）
- **おわかれ中のタップ**: 次へ送る（手振り中は記念の文を早める。記念の文は1行ずつ進む）
- **「ちがうの…」の0.6秒中**: 入力を受け付ける（首振りは0.3秒に短縮して上書き）
- 最下段の手引きは**消さない**（dim・9px）。最初の30秒だけ4秒ごとに「ボタンで おせわ・キャラを タップで なでなで」と「みぎうえの め は なかよし」を交互に出し、以後は前者に固定

ヒット判定の順: ボタン5つ（x = 4 + i×47、y 232〜294、幅44・高さ62）→ ふきだし（52×44）→ キャラ（中心 (120,160)・半径36）→ 花（左下 16×16）→ 空（32 ≤ py < 120）→ それ以外。

## 3. 一生の時間割

寿命 **L は「おとな」になった瞬間（41秒）に決まる**:

```
L = 58 + 10 × 世話率 + rng(−1.5, +1.5) + (ながいき体質なら +5)
世話率 = 応えた数 ÷ (応えた数 ＋ あきらめさせた数)。分母0なら 0
ながいき体質 = init で 25%。画面には出さない（記念に「ながいきの子だった」）
```

→ 放置 56.5〜59.5秒（ゲート `idle-survives` 45秒に対し余裕）、よく世話して 66.5〜69.5秒、ながいき体質なら最長 74.5秒。
**おわかれは L−8 から。** 41秒より後の予定は **L の比率**で置く（span = (L−8) − 41）:

| 予定 | 時刻 |
|---|---|
| できごと2回目の窓 | 41 + 0.10×span 〜 41 + 0.45×span |
| 3回目のねんね | 41 + 0.30×span（**span ≥ 14 のときだけ**） |
| おとしより | 41 + 0.60×span |
| おわかれ | L − 8 |
| たねになる | L−6〜L−4.6（おわかれの中。沈む0.9秒→たね→芽）。記念の文は芽の上に。`over` は L＋0.6 |

不変条件（実装で assert 相当のコメントを置く）: `41 < できごと2開始 < できごと2締切 < おとしより < L−8 < L`。

| 区間 | 段階 | 何が起きるか |
|---|---|---|
| 0〜3.5秒 | **たまご** | 揺れる。どこを押しても「ぽかぽか」+1（3回まで。1回0.4秒早まる、最短2秒）。孵化「うまれた！」+2 |
| 孵化〜 | **なまえ** | 3枚の名前カードが部屋の中央に大きく出る（各 68×36）。キャラはその上で跳ねる。**押されるまで待つ**（唯一止まってよい画面）。8秒たったら自分で名乗る「じぶんで なのった」 |
| 〜19秒 | **あかちゃん** | 呼びかけ 4.0〜5.0秒おき。ごはん・なでて中心。「？」10%。14.5秒にねんね（2.5秒） |
| 19秒 | **せいちょう①** | こども4種のどれかに。理由が1行出る |
| 19〜41秒 | **こども** | 呼びかけ 4.0〜5.0秒おき。あそぶ中心。「？」35%。30秒にねんね。できごと1回目（22〜38秒）。**うんちは一生に最低1回**（26秒までに出ていなければ次のごはんで、無ければ30秒に） |
| 41秒 | **せいちょう②** | おとな10種のどれかに。**ここで寿命 L が決まる** |
| 41〜おとしより | **おとな** | 呼びかけ 4.5〜5.5秒おき。「？」45%。ねんね・できごと2回目は上の表。**15% で理由なくかぜを1回ひく**（まだなら。罰ではない） |
| おとしより〜L−8 | **おとしより** | 白い眉・杖・跳ねずに歩く。「おとしよりに なった」+3。呼びかけ 5.5〜6.5秒おき、なでて中心 |
| L−8〜L | **おわかれ** | §9 |
| L−8〜L | **おわかれ→たね→記念** | §9。表示年齢は おわかれに入った瞬間に最期の年齢で止め、沈んだら「◯◯さいまで いきた」に。L＋0.6秒で `over = true` |

年齢: `(孵化,0)→(19,6)→(41,18)→(おとしより,65)→(L, 80 + 1.5×(L−56))` を線形補間（最期は 80〜107さい）。境界比較は `s.time + dt`。
**`over` 後に新しい呼びかけ・できごと・ねんねを始めないガード**を置く。

## 4. 呼びかけ ── しぐさ → ふきだし

### ふきだしの枠は1つ。優先順位と待避
`かぜ > ねんね > できごと > うんち > 呼びかけ`。高いものが出たら低いものは**消さずに待機**（呼びかけの経過時間は止める。うんちは絵だけ残す）。
**横取りされた呼びかけは `ignored` に数えない。** `ignored` は「7秒（最初の2回は10秒）たってあきらめた」ときだけ +1。

### その子の「すきなもの」
init で `fav` ∈ {ごはん, あそぶ, なでて} を1つ引く（画面には出さない）。呼びかけの抽選で fav の重みを +20、「？」のときは 50% を fav にする。
→ 何度か遊ぶと「この子は あそぶのが すき」が読めてくる。記念で明かす。

### 出し方
- 「起きていて、何も起きていない」（ねんね・あくび・せいちょう直後の間・できごと・かぜ・おわかれ・なまえ、のどれでもない）とき、タイマーが0で**しぐさ**から始める
- 満たした 1.2秒後に次のタイマーが走る
- 種類と重み（fav に +20）

| 段階 | ごはん | あそぶ | なでて | 「？」にする率 |
|---|---|---|---|---|
| あかちゃん | 55 | 20 | 25 | 10% |
| こども | 30 | 45 | 25 | 35% |
| おとな | 35 | 30 | 35 | 45% |
| おとしより | 30 | 10 | 60 | 40% |

- そうじ・くすり・でんきは抽選に入らない（うんち／かぜ／ねんねで出る）
- 同じ種類が3回続かない（直前と同じなら1回引き直す）

### しぐさ（1.2秒。**文字は出さない**）
| 欲しいもの | しぐさ |
|---|---|
| ごはん | おなかを両手で押さえ、おなかの横に「ぐるぐる」の短い曲線2本、体が一瞬つぶれる |
| あそぶ | ボールが床を転がってきて、目で追い、小さく跳ねる |
| なでて | こちらへ寄って（4px前へ・少し大きく）見上げ、目がきらっとする |
| そうじ（うんちのとき） | うんちを見てそわそわ（うんちが出たら、ふきだしの前に1.2秒） |

しぐさの間に正解を渡したら「わかってる！」**+5**・ハート2つ（ふきだしは出さずに済む）。

### ふきだし（しぐさの後）
- 絵つき（ボタンと同じ絵）か「？」。「？」の間もしぐさを繰り返す
- **持続 7秒（最初の2回は10秒）。タイマーバー無し。** 3回目以降は5秒でしょんぼり顔。時間切れで「…」になって消え、`ignored` +1
- 正解 → アニメ 1.0秒（ごはん: 茶碗が出て もぐもぐ／あそぶ: ボールを追って跳ねる／なでて: 目を細める）・ハート・`addPop`。**浮く数字（+N）は出さない**（数字を競わせない。返すのはハートの数と大きさ: なで＝小1・応えた＝1・「？」初回正解と「わかってる！」＝2・できごと＝2〜3）
- **4秒以上待たせてから応えた**ときは「まってたよ！」とハート2つ（点は同じ）
- 間違い → 「ちがうの…」首振り（点は動かない。「？」なら外し +1）

## 5. ねんね（でんき）

- あくび（0.8秒・「ふぁ〜」）→ 横になる → **でんきのふきだし**
- **でんき** → 部屋が暗くなる（星）→ ぐっすり顔 →「ぐっすり」+2・`lit` +1
- 押さない → 明るいまま寝返り。朝「ねむそう…」（半目3秒）
- 2.5秒で朝。明かりは自動で戻る
- ねんね中に他のボタン・キャラ → 「すやすや…」。起きているときに でんき → 1秒暗くなって自分で点ける「まっくら！」（点も罰も無し）

## 6. うんち・かぜ

- **うんち**: ごはんの 2〜4秒後に 40%（画面に1つまで）。**3つ山の丘型**（渦巻きにしない）。**そうじのふきだし**（呼びかけが出ていれば待機）
  - そうじ → 「きれいになった」+3・`cleaned` +1
  - 4秒でハエ2匹。**8秒放置でかぜ**
- **かぜ**: 汗・震え・遅い。**くすりのふきだし**。呼びかけ・できごとの時計は止める（捨てない）
  - くすり → 「なおった！」+3・`cured` +1
  - 6秒放置 → 自然に治る（`sick`）
  - 起きる条件: うんち8秒放置／`ignored` が4を超えてからの各あきらめで 30%。**一生に1回まで**

## 7. できごと（3種から2つ・init で決める）

`ev1Kind/ev1At`（22〜38秒）・`ev2Kind/ev2At`（§3 の窓。41秒に確定）のスカラーで持つ。「起きていて何も無い」まで先送り。
**捨てるのは「おわかれに入った」ときだけ**（かぜ・うんち・ねんね中は先送りの時計を止める）。

| できごと | 見た目 | 応える | ほっとく |
|---|---|---|---|
| **おくりもの** | 端へ行って花を持って戻る。**ハートのふきだし**＋キャラが光る | キャラをタップ →「あげる！」+8。花は左下に飾られる（一生残る） | 6秒で自分で飾る |
| **ともだち** | 小さな別の生き物（耳が三角・cool）が左から来る。**あそぶのふきだし** | あそぶ → いっしょに跳ねる +6 | 6秒で帰る（跳ねて去る） |
| **ながれぼし** | 星が空の一点で**止まってぴかぴか光る（4.5秒）**。横切らせない | 空（32 ≤ y < 120）をタップ →「ねがいごと！」+10 | 静かに消える |

## 8. 育ち ── 世話が姿になる

### 統計（flat）
`fed` `played` `cleaned` `lit` `naps`（ねんね回数） `cured` `petted` `guessed`（「？」初回正解） `knew`（しぐさで先に渡した数） `ignored`／
**こども期（19〜41秒）**の `fed2` `played2` `ignored2`（41秒に判定するので、おとな期で数えると必ず 0 対 0 になる）／`answered`／フラグ `sick` `lucky`（init 28%・非表示）`longLife`（init 25%・非表示）／`gift` `friend` `wished`／`fav`。

### 19秒: こども（4種）

| 条件（上から順） | 形態 | 見た目 | 理由の1行 |
|---|---|---|---|
| `ignored` ≥ 2、または 一度も応えず・なでてもいない | **のらまめ** | くすんだ色・葉っぱ・ほっぺに傷 | ひとりで いきてきたから |
| `fed` ≥ `played` + 1 | **ころまめ** | まんまる・手足が小さい | ごはんが すきだったから |
| `played` ≥ `fed` + 1 | **ぴょんまめ** | 長い耳・足が長い | あそぶのが すきだったから |
| それ以外 | **ぽよまめ** | ほっぺ | たくさん かまってもらったから |

### 41秒: おとな（9種＋かくれ1種）

| こども | 条件（上から順） | おとな | 理由の1行 |
|---|---|---|---|
| のら以外 | **`lucky` かつ `ignored` ≤ 1 かつ `sick` でない** | **きらまめ** ★（金色・きらきら。せいちょう時 +15（倍率なし）・以後の加点 ×1.5 切り上げ） | だいじに そだてられたから |
| ぽよ | `lit` < `naps` ÷ 2 | **ねぼまめ**（半目・ナイトキャップ） | でんきが ついたまま ねたから |
| ぽよ | それ以外 | **もふまめ**（ふち毛） | ぐっすり ねむれたから |
| ころ | `played2` ≥ `fed2` | **もちまめ**（もちっとした楕円） | あそぶのも すきになったから |
| ころ | それ以外 | **まんまるまめ**（さらにまるい） | ごはんが だいすきだから |
| ぴょん | `fed2` > `played2` | **とことこまめ**（足が長い） | よく たべて よく あるいたから |
| ぴょん | それ以外 | **はねまめ**（羽） | はねるのが すきだから |
| のら | `ignored2` = 0 | **なつきまめ**（胸にハート） | さいごまで そばに いてくれたから |
| のら | それ以外 | **たびまめ**（帽子・首巻き） | じぶんの みちを いくから |

**絵の作り方**: こども4体のボディを土台に、おとなは**パーツ1〜2個の差分**（羽／帽子＋首巻き／ナイトキャップ／胸のハート／縦横比／足の長さ／色）。
体は 16×16 ドット×4。**顔は 64px の空間に矩形・円で直接描く**（16×16 の升目に押し込めない。半目・しょんぼり・汗が描けないため）。

### おとしより
形態は変えない。色褪せ（ink→dim、dim→line）・白い眉・杖。跳ねずに歩く。

### せいちょうの瞬間

## 9. おわかれ（L−8〜L）と 記念

初見者テスト2回目で「生きて立っている本人の前で弔辞（集計）を読んでいる」「集計の後に沈むので感情の山が潰れる」と言われ、

## 15. 原則から外したこと

| 原則 | ここでの扱い | 理由 |

| 入力は1つ（tap） | aim（5ボタン＋キャラ） | 「何が欲しいか読んで渡す」は選択そのもの。1ボタンに畳むと題材が消える |

## 16. 権利

- 借りるのは**仕組み**（世話で育つ・世話で姿が変わる）と、育成ゲーム全般の一般文法（食べる・遊ぶ・片づける・薬・消灯）
- 距離を取るために変えたもの: なかよしの表示は**ハート列ではなく芽5つ**／手引きは**アイコン列を光らせずふきだしから線**／うんちは**渦巻きでなく3つ山**／終わり方は**たね→芽**（翼・輪・星を足さない）／「っち」の命名を避ける
- 自作: キャラ「まめ」と全形態・アイコン・名前候補・しぐさで読ませる仕組み・世話の癖で分かれる分岐・記念の文・称号・コード
- `meta.inspiration.original` は**名詞句だけ**。ゲーム内・ページ内・共有文に元作品の名前は出さない

## 17. 人にしか決められない残り

- 説明を読まずに「呼ばれたらボタン」と分かったか（最初の10秒）
- しぐさを読んで先に渡せたとき、嬉しかったか。「？」を外したとき、もう一回試そうと思ったか
- 別れの8秒で何か感じたか。記念の数字を見て「次はもっと構おう」と思ったか
- まめがかわいいか。うんちで笑えたか
- 呼びかけ 5〜6秒おき・ふきだし7秒が「せかされない」速さか、逆に退屈か
