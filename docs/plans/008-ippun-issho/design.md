# 一分一生（いっぷんいっしょう）── 設計 v5

> v4 を実機で遊んだオーナーの FB（2026-08-22）で、遊びの根幹に届く指摘が出た。
> ①「とじる」がよく分からない ②結局チカチカを押すだけに見える ③左上メーターを見て下ボタンを押す**往復作業**で、真ん中のキャラを見ない ④メーターの点滅と押すボタンの点滅で**視線がガチャつく** ⑤なぜ1分で一生なのか、意味・必然性がない（何さい・◯にちめの進みも分からない）。
> オーナー判断（2026-08-23）で作り直す（v5）:
> **⑤ 題材を「一日の命」の生き物に**（朝生まれて夜に力尽きる＝一日の一生を1分に。儚さが主題）。
> **③④ メーターを廃止し、キャラの顔・しぐさ・動きで欲求と体調を見せる**（キャラを見て察して応える）。
> **①② とじるを廃止し、一日をずっとそばで看取る**（時間は流れ続ける。点滅の作業感を消す）。
> 過去の版は並べない（[docs/README.md](../../README.md)）。履歴は [decisions.md](../../decisions.md)。**これが実装の正。**
> v4 のコード（緑の1ビット液晶・つぶの体・世話ボタン・記念・たね→芽・放置で死ぬ緊張）は土台として活かす。

## 0. 正解の気持ち

一日しか生きない小さな生き物を、朝から夜まで、そばで看取る。

| 時 | 気持ち |
|---|---|
| あさ（生まれる） | いとおしい（生まれたての、たよりない子） |
| ひる（世話する） | ほっとする・充実（応えると喜ぶ。育ちが見える） |
| 具合が悪くなる | 心配・**しまった**（見ていたのに気づけなかった／気づいて直せた） |
| ゆうがた | 切ない（動きがゆっくりになる。もう長くない） |
| よる（力尽きる） | 見届けた・ありがとう（世話が足りれば静かに。足りなければ早く、かわいそうに） |

**うまくいった** = 「よるまで、幸せに生きた」静かな満足。**いかない** = 「昼に力尽きた。もっと見ていれば」という後悔。
一日しか生きない、が主題。**だから1分で一生**。「セミが一週間」「小さな虫は一日」の、あの儚さ。

v4 の芯（自分の手で失敗する・放置で死ぬ）は残す。v2 の芯（キャラを見て察する）を戻す。両方を「一日の命」で一つにする。

## 1. 一行ルール

> **一日の命。あさ生まれて、よるに力尽きる。ようすを見て、してほしいことをする。**

```
題材: あさに生まれて よるに力尽きる、一日だけの小さな生き物（架空。カゲロウのような儚さ）
型: nurture。機種 keitai・theme mono（緑の1ビット液晶）。操作 aim
押す: 5つの世話（ごはん・あそぶ・なでる・くすり・ひなた/おやすみ）。※つぶをタップも「なでる」に一本化
押さない: 無い
失敗: ようすを見ずに放っておくと、しょんぼり→ぐったり→**昼や夕方に力尽きる**（早い死＝かわいそう）
進む: 時刻で進む（あさ→ひる→ゆうがた→よる、約50秒）。年齢の数字も「◯にちめ」も無い
称号: 見送った回数の肩書き 4段階（みとりびと系。実測で確定）
タイトル: 一分一生（slug 不変）。howto「一日の命を あさから よるまで」／constraint「1分で一生。一日だけの命」

── 見せる前提 ──
権利: 借りるのはジャンル共通の文法（世話・排泄・薬・分岐・終わり・少数ボタン・モノクロ液晶とビープ）だけ（調査票 §6）。
      卵型・「っち」・特定製品のキャラ/死の絵柄・看板キャラの語幹は持ち込まない（メーターはジャンル一般文法なので、廃止は権利でなく UX の判断＝§12）
映える瞬間: ①生まれる ②ようすを見て先に気づいて応える「わかってる！」 ③ひるに姿が決まる ④ゆうがた〜よる、動きがゆっくりになって静かに力尽きる（世話が足りないと早い）
結果が気になる点: 「どんな姿になるか」「よるまで生きられるか」「今度こそ看取れるか」
成否の見えやすさ: **キャラの顔・姿・動きがすべて**（お腹を押さえる・そわそわ・あくび・ぐったり×目・にこにこ・跳ねる）。空の色で時刻
```

## 2. 画面（メーター無し・キャラが主役）

mono の1ビット。**強調は反転・点滅・太さだけ**（mono では accent/good/bad が ink と同色）。

```
y  0-16   共通HUD（しあわせ／BEST）
y 20-40   時刻の帯: 空に 太陽（あさ左→ひる上→ゆうがた右下）／よるは月。文字は「あさ」「ひる」「ゆうがた」「よる」だけ（数字なし）
y 44-214  液晶の窓（角丸四角＋ink枠）。**中央にキャラを大きく**（20×20ドット×3〜4）。
            キャラの様子が情報のすべて。メーターは無い。
            ・おなかがすいた → お腹を両手で押さえる・動きが鈍る・しょんぼり（＋頭上に小さく「おなかマーク」）
            ・たいくつ → そわそわ・ボールが転がってきて目で追う
            ・さみしい → こちらに寄って見上げる
            ・ぐあいがわるい → ぐったり・汗・×目（頭上にカプセル＝くすりの合図）
            ・ねむい（ゆうがた〜） → あくび・目が半分
            ・げんき → 跳ねる・にこにこ
          頭上の合図は**ひとつだけ**（いちばん困っていること）。点滅は最小限（合図の絵のみ・メーターの点滅は無い）
y 218-304 世話ボタン5つ（x=4+i×47・幅44・高さ62）: ごはん・あそぶ・なでる・くすり・おやすみ。押した瞬間は反転
y 306-318 手引き（dim・常時）: 「ようすを 見て、してほしいことを ボタンで」
```

- **とじるボタンは無い**（v4 の「とじる」を廃止）。一日をずっと見守る。時間は流れ続ける
- **メーターの数値（●●●○）を出さない。** 空腹・退屈・体調は、キャラの姿と動きで表す。「見て察する」がこのゲーム
- キャラをタップ = なでる（さみしいときは「わかってる！」、そうでなければ「くすぐったい」）
- 判定は `input.tap` のみ。ヒット順: 世話ボタン → キャラ → それ以外（「ん？」でこちらを見る。無反応ゼロ）
- 起動時に窓の全ドットが 0.3秒 点灯（懐かしさ）

### しぐさ → 欲求 → ボタン（初見が察せるように）

キャラの様子は**ボタンの絵と結びつく形**で見せる。応えると喜ぶ、応えないと しょんぼり→ぐったり。

| キャラの様子（見て分かる） | 応えるボタン | 応えたとき | 見て先に気づいて応えたとき |
|---|---|---|---|
| お腹を押さえる・鈍い | ごはん | もぐもぐ・跳ねる | 「わかってる！」（先に気づいた＝多め） |
| そわそわ・ボールを追う | あそぶ | いっしょに跳ねる | 〃 |
| こちらに寄って見上げる | なでる（キャラをタップ） | 目を細める | 〃 |
| ぐったり・汗・×目 | くすり | しゃんとする | 〃 |
| あくび（ゆうがた〜） | おやすみ | 目を閉じてやすむ | 〃 |

## 3. 一日 ── 時刻で進む（あさ→よる）

時間 `t`（生まれてからの秒）で進む。約50秒。年齢の数字・「◯にちめ」は無い。

| 時刻 | `t` | 何が起きるか |
|---|---|---|
| あさ | 0〜12 | たまご→孵化（タップで早まる）→なまえ→よちよち。ごはん・なでて中心。呼びが多い |
| ひる | 12〜28 | 元気。あそぶ中心。**ひるの中ほど（t=20）で姿が決まる**（せいちょう）。放っておくと ぐあいわるく |
| ゆうがた | 28〜42 | 落ち着く。動きがゆっくりに。なでて中心。空が茜色 |
| よる | 42〜48 | 眠くなる。おやすみ。月が出る |
| 力尽きる | 48（または早い死） | §7。世話が足りていれば **よるに静かに**。足りないと **ひる〜ゆうがた に早く** |

- **放っておくと早く力尽きる**: 空腹・退屈・具合悪いのを放置すると `よわり` が溜まる（キャラが しょんぼり→ぐったり→動かない）。`よわり` が一定を超えると、その時刻で力尽きる（ひるなら「ひるに ちからつきた」）。**世話すれば `よわり` は戻る＝気づけば助かる。ただし、静かなしぐさは見落とすこともある**（「見ていたのに気づけなかった」が"自分のせい"の後悔になる。だから しぐさが見落とし得るが理不尽でない帯に収める＝§2 の可読性が核）
- **うんちは可視オブジェクトとして出さない**（48秒の一生に うんち→病気の二段は重い。調査票 §5.8 の懐かしさにも うんちは入っていない）。放置すると **ぐあいがわるい（×目・ぐったり）** が生じ、**くすり** で治す。そうじボタンは作らず、ボタン5つを保つ
- 世話ボタン5つ = **ごはん・あそぶ・なでる・くすり・おやすみ**（v4 の「そうじ」を廃し「おやすみ」を新設。一日の命に「夜、寝かせる」が要る）

## 4. 世話の手応え

- キャラの様子（§2 の表）を見て、合うボタンを押す。**頭上の合図はひとつだけ**（点滅の作業感を消す）
- 応えると: キャラが動く（もぐもぐ・跳ねる・目を細める・しゃんと・目を閉じる）＋ハート＋しあわせ＋ピピッ（`cue`）が鳴っていたら止む
- **様子を見て、合図が出る前に先に応えた**とき: 「わかってる！」＋ハート2つ（先に気づいた＝多め）。ここが「うちの子が分かる」の芯
- `よわり` があるときに世話した: 「…だいじょうぶ」（許してくれる。`よわり` が戻る）
- 間違い（元気なのにごはん 等）: 首を振るだけ。減点なし

## 5. 育ち（ひるに1回。t=20）

朝の世話の癖で、昼の姿が決まる。統計は flat（`fed` `played` `petted` `cured` `slept` `missed` `weak` `weakEver` `fav` `lucky`）。
条件は式でなく**ぼかした一言**（本家は隠されていた）。姿は 3〜4種＋かくれた金色。1日なので v4 の「こども→おとな」2段でなく**1回**に絞る（規模）。

| 条件（上から） | 姿 | 一言 |
|---|---|---|
| `fed=0 && played=0`（一度も世話していない） | **のら**（くすんだ） | ひとりで がんばった |
| `lucky` かつ `weakEver` でない | **きら**（きらきら・以後 ×1.5） | だいじに された |
| `fed > played` | **ころ**（まる） | ごはんが すきだった |
| `played > fed` | **ぴょん**（はねる） | あそぶのが すきだった |
| それ以外 | **ぽよ**（ほっぺ） | かまってもらった |

ゆうがた〜よるは、姿はそのまま**動きがゆっくりになり、色が淡くなる**（老い）。せいちょうの瞬間は 頭上に「◯◯に なった」＋一言、キャラは下（重ねない）。

## 6. 得点（しあわせ）と称号

減点なし。単位「しあわせ」。
- 生まれた +2／様子を見て先に応えた +4／合図に応えた +3／なでる +1（さみしい時 +3）／せいちょう +5／きら +15 以後×1.5／**よるまで生きた +10**（早い死は 0）／**ゆうがたの一番星に願う +8**
- **上振れは2本**（feel-catalog はこのゲーム名指しで「1本だと崖・2〜3本に分ける」）: ①きら（`lucky` init 25%・非表示）②**ゆうがたの一番星**（init 20% でその一生に出る・空をタップで +8）。出る一生と出ない一生の分散＝夕暮れの切なさとも合う
- 芽5つ（しあわせ 20ごと・上帯中央・●○＋称号）。称号は「見送る側」の肩書き（みならい／せわやき／かぞく／みとりびと）。**暫定 30/48/64/80** を置いて実測（session-length は**単一一生の得点**で判定。とじる廃止で v4 より低得点なので last は p90〜p93・到達5〜8%の線。`--runs=400`×3シードで確定）

## 7. 最期（よる、または早い死）

| | よるまで生きた | 早く力尽きた（`よわり` 超過） |
|---|---|---|
| 見せ方 | 月夜。こちらを向いて、目を細めて「きょう、たのしかった」（2秒） | 昼/夕の空のまま。ぐったり→動かなくなる。「…」（2秒。この間 `cue`×3＝ピーピー） |
| 消えかた | すっと**ひかりになって昇る**（一日の命。たね→芽でなく、朝露が乾くような消え方） | 同じ（ゆっくり） |
| 記念（0.7秒おき4行） | 1.「ぽち（ころ）は、」 2.「ごはん 5・あそび 4・なでなで 6」 3.「ほんとうは あそぶのが すきだった」（fav 最多3回以上なら「いちばん すきだった」） 4.「よるまで いきた」 | 1.「ぽち（のら）は、」 2.（同じ／0手なら「なにも してもらえなかった」） 3.「ひとりで すごした」 4.「ひるに ちからつきた」 |
| 見出し | 「ぽち・よるまで いきた」 | 「ぽち・ひるに」 |
| `over` | 記念4行目が出て 2.5秒後（共通シェルのジングル） | 同じ |

- おわかれに入ったら世話ボタン・手引きを消す。`over` 後は共通シェルの「もう一回」＝リトライ導線
- `reason()` = 「ぽち（ころ）は よるまで いきた」／「ぽち（のら）は ひるに ちからつきた」。`meta.ending = { color:'ink', share:true }`
- 翼・輪・墓・おばけ・UFO は描かない。「ひかりになる」は光の粒が昇るだけ（宗教中立）

## 8. 見た目と音

- `theme: 'mono'`。世界は1ビット。**メーターが無いぶん、窓の中はキャラと空（太陽/月）だけ**＝すっきりして、目線がキャラに集まる
- 液晶の窓は角丸四角＋ink枠。本体は面だけ（輪郭・卵型・紐を描かない）
- キャラは 2〜3コマの差分アニメ。**時刻で動きが変わる**（あさ よちよち→ひる 跳ねる→ゆうがた ゆっくり→よる とろとろ）＝一日の流れが体で分かる
- 空: あさ（左に太陽・薄い）→ひる（上に太陽・明るい）→ゆうがた（右下・茜＝反転で暗め）→よる（月・星）
- 音: 呼び＝ピピッ（`cue`）／力尽きる＝ピーピー（`cue`×3）。共通シェルは得点でも鳴る
- 文字はひらがな。記号は「！」「…」「Zzz」「×」だけ。カタカナ語をUIに出さない
- アイコン: 茶碗・ボール・手・カプセル・月（おやすみ）を1ビットで自作

## 9. ボット（上手い人）

`{ press, px, py }`。`round(s.time*60) % 21 === 0` の1フレームだけ press。
```
たまご: 押す（0.35秒ごと）。なまえ: 0.6秒で左カード
様子を見る: 病気→くすり／ねむい(ゆうがた〜)→おやすみ／おなか→ごはん／たいくつ→あそぶ／さみしい→なでる（キャラ）／
           元気で何も無ければ たまに なでる。困りごとが無ければ押さない（＝ずっと世話し続けない）
おわかれ: 押さない
```

## 10. ゲートの見込み（nurture）

- 放置: 世話ゼロ → よわり 溜まる → 昼〜夕に早死に（約30秒）＋記念 ≈ 40秒。**`idleSurvivalMinSec` を 30 に下げる必要が出るかも**。まず既定45で回し、落ちたら「一日の命は早く死ぬのが主題」と理由を添えて下げる（黙って下げない）
- でたらめ: まばらに当たる。上手いとの差 2倍以上を狙う
- 上振れ: きら（lucky）＋よるまで生きた+10 の有無で p90/p50 ≥ 1.2
- 実装したら 3シードで測り、goals・分岐・idle基準を確定

## 11. ガサツな人の1分（想定）

- あさ: たまご連打→名前→よちよちの子。**お腹を押さえてしょんぼり**している→ごはんだ、と察して押す→跳ねる
- 見ていると、そわそわ→あそぶ、寄ってくる→なでる。**キャラを見ている**（メーターでなく）
- 目を離した隙に ×目でぐったり→「あ、ぐあい悪い」→くすり →「…だいじょうぶ」
- ひる: **姿が決まる**「ころに なった／ごはんが すきだった」
- ゆうがた: 動きがゆっくり。なでる。切ない
- よる: あくび→おやすみ→目を細めて「きょう、たのしかった」→ひかりになる→記念「よるまで いきた」→もう一回
- 早い死の回: 放置して 昼に ぐったり→動かない「…」→「ひるに ちからつきた」「なにも してもらえなかった」→ ごめん、と思う→もう一回

## 12. 権利

調査票 §6 どおり。**メーターの廃止は権利の距離ではなく UX の判断**（メーターは複数社が独立採用したジャンル一般文法で、識別標ではない。廃止の理由はオーナー FB ③④＝キャラを見ない・視線ガチャつき）。
液晶の窓は角丸四角・本体の輪郭やストラップ穴を描かない（卵型にしない）・「っち」なし・死は**「ひかりになって散る／朝露が乾くように消える」**（墓/おばけ/UFO/天使の輪＋羽を避ける。"昇る"より"散る・消える"に寄せて宗教中立）・名前は「つぶ」系を保つか一日の命に合う名に。`meta.inspiration` は名詞句・製品名を出さない。最終判断は人。

## 13. 人にしか決められない残り

- **キャラの様子だけ（メーター無し）で「おなか空いた/退屈/具合悪い」が分かるか**（v5 の芯）
- 「一日の命」で「1分＝一生」が腑に落ちるか。あさ→よるの進みが直感的か
- 様子を見て先に応えた「わかってる！」が「うちの子が分かる」に感じるか
- 早く力尽きたとき「ごめん」が来るか／よるまで看取れたとき満足か
- 生き物の見た目・名前・「ひかりになる」終わり方
