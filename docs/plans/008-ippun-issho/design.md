# 一分一生（いっぷんいっしょう）── 設計

> 依頼（2026-08-21・オーナー）: 「世話できないガサツな人でも楽しめる、1分で一生分を楽しめる
> "たまごっち的な育成ゲーム"。短いのに何度もやりたくなって、毎回ちょっと違う一生になるもの」
>
> 型は **nurture（育てる）の初出し**。機種は keitai。操作は tap のみ。
> 初版を別エージェントに辛口レビューさせ、10点を直した（§18）。**この版が実装の正**。

## 0. 依頼を3つの設計条件に翻訳する

| 依頼の言葉 | 設計条件 | 実装での担保 |
|---|---|---|
| 世話できないガサツな人でも楽しめる | **放置しても死なない。失敗は"罰"ではなく"別の一生"になる** | 寿命は時間で決まる（早死にが無い）。ほったらかし・連打・寝てるのを起こす、は全部「育ち」に変換されて別の姿になる。罰は**時間を奪わず**ハート（倍率）を落とすだけ |
| 1分で一生分 | **たまご→あかちゃん→こども→おとな→おとしより→たねになる、の全部が60秒に入っている** | 寿命 58〜66秒。年齢が画面で進み、3回の「せいちょう」と最期の墓碑銘まで1プレイに収める |
| 短いのに何度もやりたくなる／毎回ちょっと違う一生 | **生まれつき×育ちで姿が分岐し、できごとが毎回違い、最期に一生が四行で語られる** | うまれつき3種（たまごの柄で分かる）×世話の質→おとな7種。きんのたまご（30%）は完璧に育てたときだけ金色に。できごと4種から毎回2つ。墓碑銘は形態×できごと×性格×年齢の合成 |

### この型（nurture）で守ること・action と逆のこと

genre-map.md のとおり、nurture は **「放置しても壊れない」が必須**（ゲート `idle-survives` ≥45秒）。
action の「放置すると死ぬ」を持ち込まない。緊張の代わりに置くのは **「この子がどう育つか」と「何しあわせ渡せたか」**。

既存の `tamago`（たまごポン）は「育てる型」で作って失敗し action に作り直した（002）。
同じ轍を踏まないために、**何をすればいいかが画面だけで分かる**（ふきだしが出たらタップ）、
**上手くなる余地がある**（反応の速さで3段階・赤の見分け・起こさない我慢・完璧＋きんのたまごで金色）、
**手応えが一手ごとに返る**（+点が飛ぶ・ハートが増減する・顔が変わる）を最初から入れる。

## 1. 一行ルール

> **ふきだしが出たらタップ。ねんね中と赤いふきだしはガマン。60秒で一生が終わる。**

決めること5つ（new-game スキルの形式）:

```
題材: 1分で一生を終える小さな生き物「まめ」
型: nurture（世話をしている・待っている時間がいちばん長い）
押す: ふきだし（ごはん・あそぼ・なでて・おふろ）が出たらタップで応える。できごと（ながれぼし等）もタップ
押さない: ねんね中（夜・Zzz）に触ると起こしてしまう／赤いふきだし「わがまま」に応えると甘やかし
失敗: 起こす（ハート-2・ぷんぷん1.2秒）／ほっとく（ハート-1）／甘やかす（ハート-1・ふらふら1.2秒）／つつきすぎ（ハート-1・すねる1.2秒）
上がる: 時間とともに「段階」が進む（成長・老い）。難度ではなく**リズムが変わる**（赤ちゃんは昼寝が多い・老いると昼寝とゆっくりした要求）
称号: 世話する側の肩書き 4段階（数値は実測で確定。§9）
タイトル: 一分一生（slug: ippun-issho）

── 見せる前提の確認 ──
権利: 着想元は「1990年代末〜2000年代の携帯型育成玩具・ケータイの育成ゲーム」の文法。
      借りるのは「世話をすると育ち、どう世話したかで姿が変わる」という仕組みだけ。
      キャラ「まめ」と全形態の絵・1分で一生を終える構成・ふきだしに応える1ボタン操作・うまれつき×育ちの分岐・
      できごと・墓碑銘・称号・UI・音・コードはすべて自作。卵型筐体の意匠・3ボタンUI・既存キャラのシルエット・
      「星に帰る」系の終わり方・おやつのしつけルール・名前の「っち」には寄せない（§16）
映える瞬間: ①せいちょうの瞬間（光って別の姿になる）②ねんね中に触って「おこしちゃった！」
          ③ながれぼしを取った瞬間 ④最期に墓碑銘が出て、たねになり、芽が出る
結果が気になる点: 「何になるのか」「何さいまで生きるか」「きんのたまごを金色まで育てられるか」
成否の見えやすさ: ふきだし＝今やること／夜＝触るな／赤＝ガマン／ハート5つ＝なかよし度／+点が飛ぶ／
              ぷんぷん・すねる・ふらふらは顔と色で分かる／年齢と段階が常時表示
```

## 2. 一生の時間割（実時間）

寿命 **L = 60 + rng(−2, +2)** 秒。おとしよりになった瞬間にハートが4以上なら **+4秒**（「ながいき」）。
放置でも58秒以上生きる（`idle-survives` 45秒を満たす）。上手いと長生き＝得点機会が増える。
**寿命で終わる以外の終わり方は作らない**（早死に無し）。これが「ガサツでも楽しめる」の土台。

| 区間 | 段階 | 何が起きるか |
|---|---|---|
| 0〜4秒 | **たまご** | たまごが揺れる。タップで「ぽかぽか」+1（3回まで。1回ごとに孵化が0.4秒早まる、最短2秒）。孵化で「うまれた！」+2。**たまごの柄でうまれつきが分かる**（§7） |
| 〜16秒 | **あかちゃん** | 要求: ごはん・なでて中心。**昼寝が多い**（起きている5〜6.5秒ごとに2.0秒）。最初の昼寝が**9秒前後**＝最初の10秒で1回は失敗させる（fun-doctrine ②）。**孵化後2.5秒はつついても heat が積もらない**（生まれたては何をされても嬉しい） |
| 16秒 | **せいちょう①** | こども3種のどれかに（育ちで決まる） |
| 16〜32秒 | **こども** | 要求: あそぼ中心。20秒から赤い「わがまま」が混ざる。昼寝は9〜12秒ごとに2.2秒。できごと1回目（18〜30秒） |
| 32秒 | **せいちょう②** | おとな7種のどれかに（うまれつき×育ち。きんのたまご＋完璧なら**きんまめ**） |
| 32〜L−12秒 | **おとな** | 要求はバランス型＋おふろ。昼寝は12〜15秒ごと。できごと2回目（34〜L−14秒） |
| L−12秒 | **せいちょう③** | おとしよりに（同じ姿のまま白髪・杖・色が褪せる）。**寿命基準で置く**ので下手でも老後が12秒ある |
| L−12〜L−3秒 | **おとしより** | 要求: なでて中心・間隔ゆっくり。**昼寝が増える**（6〜8秒ごとに2.8秒）。20%でながれぼしがもう1回（L−10〜L−5秒・配点大） |
| L−3〜L秒 | **さいご** | 要求もできごとも止まる。夜空。墓碑銘が4行出る。タップで次の行を即出し、全部出たあとのタップで終わりへ |
| L秒 | **たねになる** | `over = true`。まめが土に沈み、たねが落ち、**芽が出る**（0.85秒の余韻は共通シェル） |

- **年齢**は区分ごとに進み方が違う（子ども時代はゆっくり、大人は早い）:
  `(4秒,0さい)→(16秒,6さい)→(32秒,18さい)→(L−12秒,65さい)→(L秒, 88+2×(L−60) さい)` を線形補間。
  画面には常時「こども 12さい」のように出す。最期は 84〜100さい
- 境界の比較は `s.time + dt` で行う（`s.time` はそのフレームの開始時刻。ランタイムが後から dt を足す）

## 3. 要求（ふきだし）── 遊びの中心

### 出し方

- 「起きていて、何も起きていない」（ねんね・あくび・ねんね待ち・ぷんぷん・すねる・ふらふら・かぜ・できごと・さいご、のどれでもない）とき、タイマーが0になったら出す
- 間隔（一様乱数）: あかちゃん 2.0〜3.0 ／ こども 2.4〜3.4 ／ おとな 2.8〜4.0 ／ おとしより 3.4〜4.6 秒。孵化の1.0秒後に最初の要求
- ふきだしの持続は **全段階 3.5秒**（段階で0.4秒変えても体感できない。変えるのは間隔のほう）。
  **ふきだしの中に残り時間のバーを出す**（縮む。good→accent2）
- 種類と重み（段階ごと）

| 段階 | ごはん | あそぼ | なでて | おふろ | **わがまま（赤）** |
|---|---|---|---|---|---|
| あかちゃん | 45 | 10 | 45 | 0 | 0 |
| こども | 25 | 40 | 15 | 10 | 10（20秒以降） |
| おとな | 25 | 25 | 20 | 15 | 15 |
| おとしより | 30 | 10 | 45 | 5 | 10 |

### 応えたとき（ごはん・あそぼ・なでて・おふろ）

残り割合 r = 1 − 経過/持続 で3段階（feel-catalog B章「段階のある評価」）。
でたらめ操作でも平均0.5秒で押してしまうので、**「すぐ」は本当に速いときだけ**にする:

| r | 判定表示 | 基礎点 |
|---|---|---|
| ≥ 0.85（0.52秒以内） | すぐ来てくれた！ | 3 |
| ≥ 0.5（1.75秒以内） | ありがと | 2 |
| それ未満 | まにあった | 1 |

得点 = 基礎点 × **倍率**（**加点前のハートで計算**）。倍率 = 1 + floor(ハート/2)（ハート0〜5 → ×1〜×3）。
**初期ハートは2**（×2で始まる。初手から手応えが返る）。
応えたらハート +1（上限5）、`care` +1（「すぐ」ならさらに+1）。
顔が「にこにこ」0.8秒、ハートが1つ浮き上がり、`+N` がまめの脇から**上へ**飛ぶ（y≈140 で消える。ふきだしや上の段には届かない）、`addPop`。

### ほっといたとき（持続が切れた）

ハート −1（下限0）、`wild` +1、顔が「しょんぼり」1.0秒、判定表示「まってたのに…」（減点はしない）。
**ハートが減った瞬間を見せる**: 上のハート列で消えるハートが0.5秒点滅し、まめの胸から割れたハート（accent2）が1つ落ちる。

### わがまま（赤いふきだし・王冠のアイコン）

- ふきだしの縁は `bad`。**バーは縮まず、左から右へ満ちる**（「ここまで待てば勝ち」に見える。緑と同じ形にしない）。
  アイコンの横に小さく「×」を描く
- **応える（タップ）** → 「あまやかした！」ハート −1・`rough` +1・ふらふら1.2秒（目が渦・要求停止）。得点なし
- **ガマンする（満ちるまで待つ）** → まめが**ぷいっと顔をそむけてから、にこっとする**（0.6秒。能動的な絵を必ず入れる）→「ガマンできた」**+2×倍率**・ハート +1・`care` +1

これが fun-doctrine §3「押さないを選ばせる」。色は `bad` で固定（ハンコ課長の差戻と同じ記号）。
※ 元作品の「おやつ」のルールに寄せないため、対象は**食べ物にしない**（§16）。

## 4. 押してはいけないもの②: ねんね

- 起きている時間が続くと**ねんね待ち**に入る（新しい要求は出さない。出ている要求が片づくのを待つ）→ あくび（0.8秒・「ふぁ〜」・目が半分）→ ねんね。**あくびが予告**（E章: 0.4秒以上前）
- ねんね中は**画面が夜になる**（空が暗く、月と星、Zzz が浮く。0.5秒で移り変わるが、判定は状態で即切り替え）
- 起きている長さ／ねんねの長さ: あかちゃん 5.0〜6.5 / 2.0 ／ こども 9〜12 / 2.2 ／ おとな 12〜15 / 2.2 ／ おとしより 6〜8 / 2.8 秒
- **ねんね中にタップ** → 「おこしちゃった！」ぷんぷん**1.2秒**（怒り顔・湯気）、ハート −2、`rough` +1、`addShake(0.5)`。
  目が覚めたあと、次のねんねまでの時間は**通常の0.85倍**（寝不足）。
  ※ 初版の2.5秒・0.6倍は、でたらめ操作が一生の4割を身動きできない計算になった。罰は時間ではなくハート（倍率）で払わせる
- ぷんぷん中のタップ → 「ぷんぷん」と出るだけ（無反応にしない）
- あくび中のタップ → 「ねむいの…」（罰なし・起きない）
- 自然に起きる → 「おはよ」小さく、昼に戻る

| 孵化後2.5秒以内・何も無い | 「えへへ」（heat を積まない。生まれたては何をされても嬉しい） |

| 起きていて何も無い | 「つんつん」。体が傾く。`pokeHeat` +1（毎秒0.5ずつ減る）。3に達したら「しつこい！」すねる1.2秒（そっぽを向く）・ハート −1・`rough` +1・heat リセット |
| すねる中 | 「ぷい」 |
| あくび中 | 「ねむいの…」 |
| ねんね中 | 起こす（§4） |
| ぷんぷん中 | 「ぷんぷん」 |
| ふらふら中（甘やかし後） | 「ふらふら…」 |

## 6. できごと ── 毎回ちょっと違う一生を作る

init で**4種から2つ**を選び（重複なし）、1つ目は 18〜30秒、2つ目は 34〜L−14秒に予約する。
さらに **20%** でおとしより期（L−10〜L−5秒）に「ながれぼし」をもう1回（配点大。上振れの主役）。
予約時刻に「起きていて何も無い」でなければ先送り。**先送りは最大6秒、超えたら捨てる**（`wild` は増やさない。本人のせいではない）。
**さいごに入ったら未消化の予約は捨てる。** 同時に2つは見せない。

| できごと | 見た目 | タップすると | ほっとくと |
|---|---|---|---|
| **ながれぼし** | 星が空を1.4秒で横切る | 0.6秒以内「ねがいごと！」**+12×倍率**／それ以降「とどいた」+6×倍率。`wished`。**老後の1回は +20×倍率／+10×倍率** | 「みのがした」（罰なし） |
| **かぜ** | 「ハクション」体温計。3.0秒の窓。**残り回数を ●●●● で出す**（叩くごとに埋まる） | 4回タップで「なおった！」+6×倍率・`care`+2（1回ごとに「さすさす」+1）。`cured` | かぜひき3.0秒（汗・要求停止）、`wild`+1、`sick` |
| **ともだち** | 別の小さな生き物（耳が三角・cool 色）が歩いてきて「あそぼ？」3.0秒 | 「いっしょに あそんだ」+8×倍率・`friend`。跳ねて帰る | 「かえっちゃった」、`wild`+1 |
| **ちょうちょ** | 蝶がひらひら 2.5秒 | 「つかまえた！」+4×倍率・`butterfly`（跳ねる） | 飛んでいく（罰なし） |

- 「かぜ」だけは連打が正解。残り回数を現物のそばに出すので、連打を罰するゲームの中で**ここだけ連打してよい**と読める
- できごとの判定文字は**まめの上（y≈120。ふきだしは出ていない）**に出す。下段（y222）だと粒と被る

## 7. せいちょう（分岐）── うまれつき × 育ち

### うまれつき（init の乱数・腕前で動かせない）

| うまれつき | たまごの柄 | 現れ方 |
|---|---|---|
| のんびり | 無地 | ゆっくり揺れる |
| やんちゃ | しましま | 高く弾む |
| さびしがり | みずたま | きょろきょろする |

加えて **30% で「きんのたまご」**（柄の上に金の斑点がきらめく）。「この子は金色になれる」と最初から分かる＝一生の賭けが立つ。

### 統計（flat なスカラーで持つ）

`care` `wild` `rough`（一生の合計）／`care2` `rough2`（こども期 16〜32秒だけ）／フラグ `gold`（きんのたまご）`wished` `caughtCold`（かぜをこじらせた。`sick` はかぜひき中の残り秒数のタイマーなので名前を分けた）`cured` `friend` `butterfly`。
これ以外の統計は持たない（使われない値は state を太らせるだけ）。

### 16秒: こども（育ちで決める）

| 条件（上から順） | 形態 | 性格 |
|---|---|---|
| `rough` ≥ 2 かつ `rough` ≥ `wild` | **とげまめ** | 起こされ・つつかれて、とげとげ |
| `wild` > `care` | **のらまめ** | ほっとかれて、自由に（**放置はここ**） |
| それ以外 | **ぽよまめ** | ふつうに愛されて、ぽよぽよ |

### 32秒: おとな（「よく世話されたら"うまれつき"が出る。雑なら"育ち"が出る」）

| 条件（上から順） | おとな |
|---|---|
| **`gold` かつ `rough`合計 0 かつ `wild`合計 ≤ 1** | **きんまめ** ★ 以後の得点 ×1.5（切り上げ）。金色、きらきら |
| `care2` ≥ 3 かつ `rough2` = 0（こども期をちゃんと世話した） → うまれつきで | のんびり→**もふまめ**（もふもふ）／やんちゃ→**はねまめ**（羽）／さびしがり→**なつきまめ**（胸にハート） |
| それ以外（こども期が雑） → こどもの形態で | ぽよ→**ねぼすけまめ**（ねむそう・よだれ）／のら→**たびまめ**（帽子と首巻き）／とげ→**いがまめ**（全身とげ） |

- 上手い人: こども期を世話する → うまれつき3種のどれか（毎回違う）。きんのたまごの回だけ、完璧なら金色
- 放置: のら → たびまめ。でたらめ連打: とげ → いがまめ（起こす・つつきすぎで `rough` が積もる）
- **7種の差は「うまれつき」か「育ち」かで読める**。条件の閾値ひとつ違い、という分岐を作らない

### L−12秒: おとしより

形態は変えない。色が褪せ（ink→dim、dim→line の写像）、白い眉、杖。「おとしよりに なった」+5×倍率。

### せいちょうの瞬間の演出（映える瞬間①）

0.6秒前から体が点滅（予告）→ 境界で `hitStop(0.08)`・画面全体が一瞬明るく（0.12秒）・`addPop`・
きらきら8粒（**`s.time` と成長時刻からの決定的な関数で描く**。state に配列を持たない）・
判定文字「◯◯に なった！」を**まめの上**に1.4秒大きく → **+5×倍率**（「せいちょう」）。

## 8. さいご（L−3秒〜）と、たねになる

- 要求・できごと・ねんねを止める。空を夜にして星を増やす。まめは座り（4px下がる）、目を閉じる
- 墓碑銘を 0.0 / 0.7 / 1.4 / 2.1 秒に1行ずつ、画面上部（y≈56〜116）に出す。**タップで次の行を即出し**:
  1. 「◯◯（形態名）は、」
  2. できごとの一片（優先順）: `wished`→「ながれぼしに ねがい、」／`cured`→「かぜを なおして、」／`sick`→「かぜを こじらせ、」／
     `friend`→「ともだちと あそび、」／`butterfly`→「ちょうちょを おいかけ、」／無し→「しずかな まいにちで、」
  3. 性格の一片（優先順）: きんまめ→「きんいろに かがやき、」／`rough`≥4→「よく おこされながらも、」／`wild`≥8→「じゆうに いきて、」／
     ハート≥4→「たくさん あいされて、」／それ以外→「のんびり くらして、」
  4. 「◯◯さいで たねに なりました」
- 全行が出たあと（2.1秒以降）のタップで終わりへ。**出し切る前に終わりへは飛ばない**（誤タップで墓碑銘を失わない）
- L秒で `over = true`。まめが土に沈み（0.3秒）、たね（ink の小さな丸）が落ち、**芽（good 色の双葉）がぽんと出る**（`addPop`）。
  共通シェルの `OVER_HOLD`（0.85秒）がそのまま余韻になる。**次の一生がここから始まる**、という絵
- `reason()` = 「◯◯さいで たねになった（形態名）」（例:「88さいで たねになった（もふまめ）」）

派手な「やられ」は作らない。**豆だから土に還って芽が出る**、で題材と終わり方を一致させる。
「星になる／星に帰る」は元作品側の言い回しとして強く記憶されているので使わない（§16）。

## 9. 称号（世話する側の肩書き）

単位は **「しあわせ」**（「312しあわせ」「あと28しあわせ」。点数が"この子に渡したもの"だと伝わる）。

| 段階 | 名前 | 置く位置 |
|---|---|---|
| 1 | みならい | 上手いボットの中央値以下（1〜2プレイで届く） |
| 2 | せわやき | 中央値のすこし上 |
| 3 | おやばか | p80 前後 |
| 4 | そだて名人 | **上手いボット200回中 12〜21回が到達する線（p90〜p94）** |

ゲートの式は `分 = (200 / 到達回数) × 中央値秒 / 60`。中央値 ≈ 62秒なので、
到達5回だと 41分で落ちる（上限30分）。**通るのは到達 7〜34回**。真ん中の 12〜20回（13〜17分）を狙う。
**実装の最初に暫定値を置く**（goals が無いと「最初の称号」「遊びきれる長さ」の2項目が判定から黙って消える）。

## 10. 上振れ（p90/p50 ≥ 1.2）と腕前（上手い/でたらめ ≥ 2.0）の設計

上手いボットは決定的に動くので、上振れの源は**設計の乱数**だけ。小さく頻繁な上振れは平均化されて効かない（002・hanko で実証済み）。
**大きくて、出たり出なかったりするもの**を2つ置く。

| 源 | 何が起きるか | 効く先 |
|---|---|---|
| **きんのたまご（30%）→ きんまめ ×1.5** | 完璧に育てた回の3割で、後半の得点が1.5倍 | 上振れの主役①（ボットは完璧なので30%の回で+30%前後）・人には「賭け」 |
| **老後のながれぼし（20%・+20×倍率）** | 出る一生と出ない一生がある | 上振れの主役② |
| できごとの組み合わせ | 4種から2つ。配点 4〜12×倍率 | 上振れ・変化 |
| ハートの倍率（×1〜×3） | 続けて応えると1回の重みが3倍。起こす・甘やかすと落ちる | 腕前 |
| 判定3段階（0.52秒以内で3点） | 画面を見ている人だけ3点 | 腕前・伸びしろ |
| わがままの見分け・ねんねの我慢・つつかない | でたらめ操作は赤に応え、夜に起こし、つつきすぎてすねる | 腕前 |
| 寿命のゆれ（±2秒）＋ながいき（+4秒） | 老後の要求回数が変わる | 上振れ・腕前 |

## 11. ゲートの見込みと、測ってから決めること

nurture で効く10項目: 再現性／リプレイ／初見でも点が入る／腕前が効く／画面が動く間隔（0.25〜12秒）／
最初の称号／一気に遊びきれる長さ／**放置しても壊れない（≥45秒）**／いつか終わる（≤600秒・決着率90%）／上振れ（≥1.2）。

| 項目 | 見込み（レビュー時の机上計算） |
|---|---|
| 放置しても壊れない | 寿命 58秒以上で必ず通る |
| いつか終わる | 寿命で必ず終わる（決着率100%） |
| 初見でも点が入る | でたらめ操作で 60〜80点の見込み |
| 画面が動く間隔 | 要求約14回＋せいちょう3回＋できごと2回＋たまご ≒ 2.6秒に1回 |
| 腕前が効く | 3〜4倍の見込み。**未達なら**わがままの出現率を上げる／起こしたときのハート減を増やす |
| 上振れ | きんのたまご30%×1.5 と老後ながれぼし20%で **1.3前後**の見込み。**未達なら**老後ながれぼしを +25 に／きんのたまごを35%に |
| 最初の称号・遊びきる長さ | 実測の分布から §9 の位置に置く。3シードで安定するか見る |

測るのは `npm run fun -- ippun-issho` と `--seed-offset=777 / 31337` の3本。
形態の分布（上手い／でたらめ／放置がそれぞれ何になるか）も数えて報告する。

### 実測（2026-08-21・レビュー反映後）

| | 放置 | でたらめ | 上手い |
|---|---|---|---|
| 生存（中央値） | 60秒 | 59秒 | 64秒 |
| しあわせ（中央値） | 17 | 75 | 200（p90 254 / 最高 349） |

全10項目合格（3シードとも）。腕前 2.7倍（777: 2.5 / 31337: 2.5）・上振れ 1.3倍（3シードとも）・画面が動く間隔 3.0秒・
「そだて名人」（258）まで 11分（777: 18分 / 31337: 16分）。称号は 150 / 210 / 238 / 258。

形態の分布（各200回）: 上手い＝きん約3割＋もふ・なつき・はねがばらける／でたらめ＝ねぼすけ・いが／放置＝たび100%。
**たびまめは「でたらめ」には出ない**（よく押すぶん要求にそこそこ応えてしまい `wild > care` にならない）。人が雑に遊べば出る。

## 12. 画面（240×320）

```
y  0-16  共通HUD（スコア／BEST）
y 19     「こども 12さい」          ♥♥♥♡♡ ×2
y 34-206 空（昼: bg2＋太陽 ／ 夜: bg＋月＋星。0.5秒で移り変わる）
y 100    ふきだし（44×36。アイコン＋残り時間バー。わがままは bad の縁・満ちるバー・小さな×）
y 120    せいちょう・できごとの判定文字（ふきだしが無いときだけ使う段）
y 180    まめの中心（12×12ドット×4倍=48×48。地面の上で揺れる。のんびり±2px／やんちゃ・さびしがり±3px）
y 206-250 地面（昼: line ／ 夜: bg2）
y 222    要求・つんつん系の判定文字（14px・popScale。good/bad/dim に加えて、ふらふらは accent2・さすさすは cool）。**背後に bg の帯を敷く**（地面の上でも読める）
y 286    凡例「ふきだし → タップ」
y 300    凡例「■ねんね ■あかいふきだし → ガマン」（■は色見本: 夜の bg2 と bad。ひらがな表記）
```

- 「一生の道のり」の帯は置かない（段階名と年齢が常時出ていれば足りる。同時に見るものを絞る）
- まめの**体だけ**をドット絵（`sprite()`）で持ち、**顔は矩形の重ね描き**で作る
  （にこにこ・しょんぼり・ねんね・ぷんぷん・ふらふら・かぜ・つんつん・すねる・目を閉じる）。形態×表情を個別に描かない
- 形態の見分け（シルエットの差）: まめ=小さい豆／ぽよ=まるい＋頬／のら=くすんだ色＋葉っぱ＋傷／とげ=頭に3本のとげ／
  もふ=ひとまわり大きくふち毛／はね=羽／なつき=胸にハート／ねぼすけ=半目＋よだれ／たび=帽子と首巻き／いが=全身とげ／
  きん=金色＋きらきら。おとしより=色褪せ＋白眉＋杖
- ともだちは別のシルエット（耳が三角・色は cool）
- **色の意味を固定**: bad=触るな（わがままの縁）／accent2=ハート／accent=きん（きんのたまごの斑点・きんまめの体ときらきら。パレットで金に見えるのはこちら）／good=加点・なおった・芽／cool=水・羽・ともだち／dim=くすみ・老い
- きらきら・雨粒・星などの粒は **state に持たず `s.time` からの決定的関数で描く**（配列のコピー漏れと再現性事故を構造で消す）

## 13. ボット（上手い人）

`bot(s, rng)` に frame は来ないので、連打は `Math.floor(s.time * 60)` の剰余で press を明示する
（押しっぱなしは1回しか tap にならない）。

```
over／さいご → 押さない
ねんね・あくび・ぷんぷん・すねる・ふらふら・かぜひき中 → 押さない

要求中: わがままなら押さない／それ以外は t ≥ 0.3 で押す（人の反応時間ぶん遅らせる。解決した次フレームで離れる）
たまご: (frame % 30 < 15) で毎秒2回
それ以外 → 押さない（つつかない）
```

## 15. 原則から外したこと（理由つき）

| 原則 | ここでの扱い | 理由 |
|---|---|---|
| 緊張の軸を時間とともに上げる（③） | 難度は上げない。**リズムが変わる**だけ | nurture は「放置しても壊れない」が先。上げるのは圧ではなく変化 |
| ライフ3 | ライフを持たない（死なない） | 「ガサツでも楽しめる」の土台。失敗は育ちに変換される |
| 5秒を超える演出（§4） | さいご3秒＋余韻0.85秒。タップで行を早送りできる | 墓碑銘がこのゲームの"結果"そのもの。共通シェルの結果画面には入らないのでここで見せる |
| 上振れ 1.3倍 | nurture 既定の 1.2倍 | genre-map.md の既定。黙って下げていない |
| state をフラットに | 要求・できごと・浮く文字は小さなオブジェクト／配列を持つ | 必ずコピーしてから変更する。粒（きらきら等）は配列にせず時間の関数で描く |

## 16. 権利

- 借りたのは**「世話をすると育ち、どう世話したかで姿が変わる」という仕組み**だけ（rights-and-originality §①）
- 持ち込まないもの: 卵型の筐体・3ボタンのメニュー・既存キャラのシルエット・「っち」の命名・公式の画像や音・
  **「星に帰る／星になる」の終わり方**（元作品側の言い回しとして強い。こちらは「たねになる」）・
  **「おやつを与えすぎると悪く育つ」のしつけルール**（こちらは食べ物でない「わがまま」に応えるかどうか）
- `meta.inspiration` に同じ内容を書く。ゲーム内・ページ内・共有文に元作品の名前は出さない
- 判定の問い「元作品を知っている人が見て同じ作品だと誤認するか」→ 1分で終わる・ふきだしに応えるだけ・
  まめの形・うまれつき×育ち・墓碑銘・たねになる、のどれも元作品には無い。**別の作品として成立している**と判断。最終判断は人

## 17. 人にしか決められない残り

- 実際に3回遊んで「もう一回」と思うか（`npm run playtest -- ippun-issho`）
- ふきだしの持続（3.5秒）がガサツな人に十分か／上手い人に退屈でないか
- 墓碑銘の文面が刺さるか、くどくないか
- まめの絵が「かわいい」か（AI は判定できない）
- 称号の名前

初版を別エージェントに辛口レビューさせた。採用した指摘と、しなかった指摘。

| 指摘 | 直し |

| ぷんぷん2.5秒＋寝不足0.6倍で、でたらめ操作が一生の4割を身動きできない | 1.2秒・0.85倍。罰は時間でなくハートで |

| 浅いコピーで壊れる配列・オブジェクトが多い | 統計はスカラー、粒は時間の関数、できごとの予約は小さな配列を必ずコピー |

| おとしよりが50秒固定だと下手な人（L=58）は老後が5秒 | L−12秒基準に |
| たまご期は叩くほど正解なのに孵化直後から heat が積もる | 孵化後2.5秒は heat を積まない |
| 「ほしになる」「おかし」が元作品の表現・ルールに近い | 「たねになる」「わがまま」に |
| 要素過多（おとな7・できごと5・統計11・道のり帯） | できごと4・未使用統計を削除・道のり帯を削除。おとな7種は「うまれつき／育ち」で読める形に組み替えて維持 |

**実装後の検収で足したもの**: せいちょう直後の「間」（`growHold` 1.4秒。新しい要求・できごとを始めない。
「◯◯に なった！」が次のふきだしに消されないため。上手いの中央値は 212→200 に下がったがゲートには影響なし）／
あくび開始の「ふぁ〜」／さいごの星を 14→32 個に増やし墓碑銘の背後に帯／ともだちは左へ3回跳ねて退場／
寝不足 0.85 倍が二重に掛かっていたバグを修正／`inspiration.original` を名詞句だけに（ページの文型に合わせる）。

**採らなかった指摘**: 倍率上限の撤廃（1ミスで×1に落とす）。上振れには効くが「ガサツでも楽しめる」と正面衝突する。
「だいこうぶつ（5%で3倍）」は 002 で効かなかった実績があるので最初から入れない。
