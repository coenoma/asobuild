# 一分一生（いっぷんいっしょう）── 設計 v12（最終）

> v1〜v11 はオーナーの実機FB 11回（→ §15）で作り直し続けたが、v11 で「**全然全く面白くない**」。
> 部分修正を重ねる進め方そのものが誤りだった（足すたびに字が増え、直すたびに別の重なりが生まれた）。
> v12 は **32件のFBを統合して根本原因を特定し（§0）、設計から作り直し、設計レビュー2本（反証役・初見プレイ再生）の指摘を取り込んだ**もの。これが実装の正。
> 企画意図: 「世話できないガサツな人でも楽しめる、1分で一生分を楽しめる"たまごっち的な育成ゲーム"。短いのに何度もやりたくなって、毎回ちょっと違う一生になる」。
> **完成の定義（2026-08-23 オーナー）**: 「本家の本質（日常の中で"あの子どうしてるかな"と思う、ペットのような存在）を1分に凝縮して追体験」は**そもそも不可能なお題**だった。UI/UX・デザインの方向はこのままで、**「ゲームとしてこれ以上なく面白く、ついつい・気づいたらまた遊んでいる」を磨き切って完成**とする。§2 の「本家の気持ちとの対応」は参考に残すが、判断基準は「面白いか・また遊ぶか」（[fun-doctrine](../../design/fun-doctrine.md) ②⑥⑦・§3）。
> **最終FB（2026-08-24）「ルールが見えない」**: 速く押すと点が高いのか・連続で倍になるのか・頼まれていない世話は何になるのか、画面が言っていなかった。流れ星は操作系（ボタン4つ）から外れていた。→ 流れ星を削除し、**速さと連続を点に直結させて、窓とボタンの間の帯に言葉で出す**（§5）。
> **公開前の最後の調整（2026-08-24）**: たまごを割る場面を廃止（生まれた状態から始める。放置ゲートは `meta.funGate` で 20秒に上書き＝理由は meta.ts に）。「はやい」は呼ばれて **0.7秒以内**に厳しく。

## 0. 統合分析 ── 32件のFBと、7つの根本原因

| 根本原因 | 該当FB（版） | なぜ起きたか |
|---|---|---|
| **A. 賭けるものが無い → 感情が動かない → 面白くない** | 追体験でない(v1,v2)・1分=一生の必然性(v4)・一日の命が伝わらない(v5)・**全く面白くない(v11)** | 触ってさえいれば死なない（上手いbot生存100%）。本家の1位「自分が死なせた」と、その裏の安堵「…まってたよ」が構造的に起きない |
| **B. 中身が「記号合わせ」で、判断が無い** | 何を急ぐのか(v1)・チカチカ押すだけ(v4)・キャラを見ない(v4)・なでる時機が不明(v5) | 欲求→対応ボタンが1対1で、押す以外の選択が無い。作業であって遊びではない |
| **C. 状態・進捗・手応えが"表示した場所"で認識されない** | 何歳か不明(v2)・良いか悪いか不明(v5,v6)・上帯は一つも入らない(v6)・植物に気づかない(v7,v8)・合計は見なかった(v9)・顔横の数字と花が不明(v11) | 11版で表示を移動し続けた結論: **キャラ以外の場所に置いた情報は見られない**。見られたのはキャラの顔・大きさ・中央の大文字・音だけ |
| **D. 字が多すぎる** | 重なり(v7〜v10)・表示時間が短い(v10)・文字だらけ(v10)・窮屈でださい(v11) | 直すたびに文字表示を足した |
| **E. テンポに山と谷が無い** | 必死で変化が見えない(v6)・祝いの最中に要求(v8) | 要求が一定間隔で滴り続ける |
| **F. 毎回の違いが見えない** | 1分=一生の必然性(v4)・次につながる情報(v9)・間違い探し(v8) | 姿の違いが顔の差分程度。「前回と違う一生だった」が起きない |
| **G. 初見の10秒で何をすればいいか分からない** | 全部(v1)・演出か要求か不明(v2)・とじるが不明(v4) | 名前選択・とじる等の手続きが遊びの前に挟まる |

**設計レビュー（反証役）が加えた診断**: 上の対処として最初に書いた案（呼ぶ前に押すと＋5／2つ同時の呼び／t=30 の隠し条件で姿が決まる／野生で放置ゲートを通す）は、**主線が「光ったボタンを押す」のままで、死は誰も踏まない経路に置かれ、姿は同点処理と25%の運で決まり、野生は関所対策**だった。1分の一生に要る動詞は本家の「生活の合間に世話する」ではなく「**形づくる**（何になるかは自分がしたこと）」。それを t=30 まで隠さず、**毎タップ体に出す**。

## 1. v12 の原則（7つ。ここから外れたら戻す）

1. **キャラが UI。** 欲求・体調・育ち・年齢はすべて**キャラの体・顔・姿勢・動き・持ち物**で見せる。別の場所にメーター・数字・芽を置かない（原因C）
2. **毎タップが舵。** ごはん→体が丸く／あそぶ→足が伸びる／なでる→毛が立つ。押した0.3秒後に体が変わる。欲しがっていないときの世話も効く（2倍）。t=30 に「自分が作った形に名前が付く」。**もう一回の理由＝次は別の形を作る**（原因B・F）
3. **本当に死ぬ。生まれた瞬間から、その子はあなたに頼る。** 呼びを放てば6秒で雨、18秒で力尽きる（本家「僅かな気の緩みで死ぬ」）。ふつうに遊んでいて起きる4〜6秒の遅れで雨に触れ、助けて「…まってたよ」の安堵が毎回1〜2度起きる配分にする。**呼んでいる最中に違う世話をすると首を振って断る**（やみくもな連打を実際に弱くし、人には「聞いて」と伝わる）（原因A・B）
4. **読ませる字は3か所だけ。** ①生まれた瞬間の名前（1回・1.5秒）②場面の見出し（ひる／ころに なった！／よる）③最期の記念（3行）。ラベルは時間帯名とボタン名だけ。キャラの言葉は「…まってたよ」「きょう、たのしかった」の2つだけ。手応えは**反応と「＋N」の数字**（原因D）
5. **波のテンポ。** 静か（ひとり遊び）→ 呼ぶ → 放つと段々強く → 応えると大きく喜ぶ → また静か。あさは3回だけ呼ぶ（教える期間）。場面転換と変身は全停止（原因E）
6. **姿は一目で別物。大きさは年齢。** 丸・足長・毛玉・帽子・光る体。体の大きさは t で育つ（あさ 64px → ひる以降 80px。窓の4割を占める存在感）。調子は顔・姿勢・雨雲と雨で（原因C・F）
7. **最初の10秒で全部教える。** 生まれて名前 → すぐ「なでて」と見上げる（吹き出し＝ボタンと同じ絵・**あさだけ**ボタンが光る）→ 押す → 喜ぶ → 「はやい！ ＋5」→ 体が少し変わる（原因G）

## 2. 正解の気持ち（本家 §5.7 との対応）

| 本家で刺さった気持ち | v12 でどこで起きるか |
|---|---|
| 1位 罪悪感「自分が死なせた」 | 呼びを放つ→雨→×目→光が抜ける。**応えれば必ず助かる**ので死は必ず自分のせい。ふつうの遅れでも雨までは行くので「しまった」が毎回起きる |
| 2位 一生を見届けた愛着 | あさ→よる を離れず看取る。最期に「きょう、たのしかった」→ 光の粒 → たね |
| 3位 余白のエモさ | ひる・ゆうがたの静かな時間。キャラがひとりでちょこまか動く（本家 §4「待機中の動きが愛着の源」） |
| 4位 面倒の先の愛おしさ | 応えるたび体が変わって育つ。自分が作った形に名前が付く |
| 5位 呼び出しの焦り | ピッ→ピピッ→雨→ピーピー と段階的に強くなる |

**うまくいったとき**: 自分が作った形で、よるに星を見て、静かに光になる。「いい一日だった」。
**うまくいかなかったとき**: ひるに、呼んでいたのに気づかず、×目で倒れて、光が抜けていく。「ごめん」。→ たねが残る → もう一回は1タップ。

## 3. 一生の流れ（`t` は孵化からの秒。全停止中は止まる。実時間は約63秒）

```
t  0     たまごは無い。生まれた状態から「ぽん」＋ピッ＋＋2 で始まる。小さな つぶ（DOT 4）。名前を大きく1回（1.5秒）
t  0-15  あさ ── 3回呼ぶ: なでて(t≈1)→ごはん(t≈6)→あそぶ(t≈11)。この間だけボタンが光る（教える）。
         反応は1.2秒以内。次の呼びは前の反応が終わってから
t 15     ★ひるの間（2秒・全停止）。見出し「ひる」と太陽。体が一回り大きく（64→80px）。のび（座る）
t 15-30  ひる ── 呼びの間隔 7〜9秒。ボタンは光らない（吹き出しだけ）。2つ同時が起きうる。余白＝ひとり遊び。
         呼びに**はやく**応えるほど点が高く、**連続**で倍になる（帯に「はやい！ ＋5 ×2」と出る）
t 30     ★へんしん（2.6秒・全停止）。白く光る→「ぽん」→一回り大きく→等倍。「ちびは ころに なった！」＋「しあわせ NN・ともだち」
         以後、形は固定（名前が付いた）
t 30-45  ゆうがた ── 落ち着く（減りが遅い・動きゆっくり）。太陽が右へ下りて窓の外へ沈む。
         余白＝頼まれていない世話で形を舵取りする時間（帯に「まるくなる」等と出る）
t 45     ★よるの間（2秒・全停止）。月と星。あくび。見出し「よる／もうすぐ おわかれ」（一日の命だと言葉で伝える唯一の行）
t 45-50  よる ── 呼ばない。眠そう（Zzz）。なでる＝寝かしつけ（＋5・目を閉じる）。病気のまま迎えれば早い別れ
t 50-57  看取り（≈7秒・タップで送れる）。空を見上げる→「きょう、たのしかった」→ 光の粒になって散る → たね → 記念4行 → 6つの姿の影絵（今回の姿だけ塗る）
         over（共通シェルの結果画面へ）
```

**早い別れ**: 呼びを放って 18秒で、その時刻に力尽きる（§6）。**暗転しない**（罰にしない）。言葉は「つぎは そばに いて」＝次への誘い。光が3つ上って、たね、記念4行。
**放置**: 生まれてすぐ放たれ、t=20 で力尽きる（実時間 ≈27秒）。nurture の放置ゲート（≥45秒）は `meta.funGate` で 20秒に上書き（理由: 「見ていない時間があるのが前提」の型ではない。meta.ts）。

## 5. 世話と反応（4ボタン＋吹き出し＋キャラ＋空）

押して無反応になる枝は作らない。**反応そのものが手応え**。
**ルールは3つだけで、全部 帯に言葉で出る**（最終FB「速く押すと高いのか・連続で倍か・頼まれていない世話は何か、が分からない」への答え）:
1. 呼ばれたら **はやく** 応えるほど高い: はやい！（気にしているうち／呼ばれて**0.7秒以内**）＋5 ／ ふつう ＋3 ／ おそい（強く呼ばれてから）＋1
2. **連続**で応えると倍: 3連続で ×2、5連続で ×3。「おそい」・雨・違うボタンでコンボが切れる（「コンボ おわり」「ちがう」）
3. 頼まれていない世話は点でなく**形の舵**: 「まるくなる」「あしがのびる」「けがはえる」と出て、t=30 の姿に効く

| 押したもの | 欲しがっている（Lv1〜4） | 欲しがっていない | できない |
|---|---|---|---|
| ごはん | もぐもぐ（1.2秒）・♪・**はやい＋5／＋3／おそい＋1 ×コンボ**・まる軸 +1 | 食べる（短い）・「まるくなる」・**まる軸 +2**（欲求は戻らない＝連打で延命しない） | 病気・寝た後: 首振り。ほかの欲求を呼んでいる最中: 首振り＋「ちがう」（コンボ切れ）。満腹で3回続けて: 「げふ」＋6秒食べられない |
| あそぶ | ボールを追う（1.2秒）・大笑い・同上・あし軸 +1 | 追って座る（短い）・「あしがのびる」・あし軸 +2 | 病気・よる: 首振り。ほかを呼んでいる最中: 「ちがう」 |

## 6. 呼びの段階（波のテンポ）と、死

3つの欲求（おなか・きげん・さみしさ）は 0〜4 の連続値。時間で減る（あさ速い・ゆうがた遅い・よる止まる・反応アニメ中は止まる）。**2 で「気にする」、1 以下で「呼ぶ」**。呼び始めからの秒で段階が上がる。

| 段階 | いつ | キャラ | 音 | 応えると |
|---|---|---|---|---|
| Lv0 げんき | — | ひとり遊び（歩く・見回す・のび・くしゃみ・鼻歌） | — | — |
| Lv1 気にする | 値=2 | しぐさ＋**小さな吹き出し**（点滅なし） | — | はやい！ ＋5 |
| Lv2 呼ぶ | 値≤1（呼び始め） | **大きな吹き出し**・こちらを見る・あさはボタン点滅 | ピッ | 0.7秒以内 はやい！ ＋5／以降 ＋3 |
| Lv3 強く呼ぶ | +3秒 | 吹き出しに「！」・点滅・前に寄る | ピピッ | おそい ＋1（コンボ切れ） |
| Lv4 よわる | **+6秒** | しょんぼり沈む・**雨雲と雨**・「コンボ おわり」 | ピピッ（3秒ごと） | おそい ＋1 |
| Lv5 ぐあいわるい | +10秒 | ×目・倒れる・大雨・枠点滅。**吹き出しが くすり に変わり、くすりボタンが光る** | ピーピー（2秒ごと） | くすり → ＋5・ばんそうこう |
| 力尽きる | +18秒（Lv5 から8秒） | §8 | ピー……（下降） | — |

- **雨を前倒し**（6秒）: ボールを見ていて気づかなかった程度の遅れで雨に触れ、助ける。これが毎回の「しまった→ほっ」。18秒は「1秒1回の乱打が偶然当たる」より短く「目を離した」より長い線（でたらめボットの生存が約55%になる実測で置いた）
- **2つ同時**: 自然に起きる（減りの位相を子ごとに ±15% ずらすので組み合わせは毎回違う）。
- **死の経路の担保**: ゲートの3体（上手い・でたらめ・放置）は死を踏まないので、「10秒世話してから放つ」ボットを検収スクリプトに置き、t≈35 で力尽きることを機械で確かめる

## 7. 育ち（毎タップ体に出る。t=30 に名前が付く）

体は3つの軸 `maru / ashi / kenami`（0〜8）でその場で描く。世話するたび対応する軸が +1（欲しがっていないときは +2）。**押した0.3秒後に体が変わる**＝すべてのタップが舵。

| 軸 | 体の変化（連続的。段ごとに絵が変わる） |
|---|---|
| まる（ごはん） | 0-1: 基本形 → 2-3: 丸く太い → 4-5: ほぼ球 → 6+: 球で転がって移動（足が消える） |
| あし（あそぶ） | 足の棒が 0 → 2ドット → 4 → 6 と伸びる。4+ で耳が立つ。6+ で歩かず跳ねる |
| けなみ（なでる） | 外周の毛（棘）が 0 → 4本 → 8本 → 12本。8+ でふわふわ揺れる。目が細くなる |

## 11. ボット（上手い人）

0.35秒に1手。病気→くすり ＞ よるで起きていれば なでる ＞ 欲求に応える（55% は気にしているうちに先回り＝はやい、30% は呼ばれて2秒＝ふつう、15% は強く呼ばれてから＝おそい。**呼びごとに1回だけ決める**＝毎フレーム引くと最速に収束して点が1つに固まる崖。人間の上手い人の揺らぎ。満腹には食べさせない）＞ 待つ。→ 雨なし・均等・寝かしつけ＝「きれいな一生」と きら を自然に満たす。
