# 一分一生（いっぷんいっしょう）── 設計 v4

> v1（反射ゲーム化）・v2（「ダメを作らない」応答ゲーム化）はどちらもオーナーの実機評価で却下。
> 根幹の指摘: **「これをやってどんな気持ちになると正解なのか。うまくいったとき／いかないときの気持ちが本家と同じでなければ、追体験ではない」**。
> v3 は本家と同ジャンルを**調べてから**設計した（[調査票](../../research/virtual-pet-1996.md)）。
> v3.1 を実装し、初見者テスト・本家世代テスト（画面のみ）にかけたところ「触りたい 8/10」まで来たが、
> **依頼の核心「自分が死なせた罪悪感・ごめん」がまだ来ていない**（失敗が全部「とじている間＝手の届かない場所」で起きるため）。
> オーナーの判断（2026-08-22）で**骨格を変えて罪悪感を入れる**ことにしたのが v4（§14）。**これが実装の正。**
> 過去の版は並べない（[docs/README.md](../../README.md)）。方針の履歴は [decisions.md](../../decisions.md)。

## 0. 正解の気持ち（調査で裏付けた感情モデル）

| 場面 | 気持ち | 裏付け（調査票の節） |
|---|---|---|
| 見ていない時間 | **気になる**（ポケットの中で鳴っている。見えているのに触れない） | §5.1 授業中にピーピー／§3.1「常時世話が要らなければ責任を実感できない」（横井） |
| 開けて世話する | **ほっとする**（元気だった／減ってたからあげた。心配が静まる喜び） | §3.1「世話のやけるよろこび」／§5.2「催促されるのが癒やし」 |
| 放っておいた | **しまった、ごめん**（うんちを置いて寝たら病気。慌てて直す） | §5.7 1位「自分が死なせた罪悪感」／§3.1「ままならなさ」 |
| 毎回「とじる」 | **面倒だが、やると気持ちいい儀式**（カチッ。ポケットにしまう） | §5.7 4位「面倒くささの先の愛おしさ」 |
| 何も起きない回 | **余白**（老いた子がゆっくり歩いて、こちらを見る。なでるだけ） | §5.7 3位「余白のエモさ」／§4「待機中の微妙な動きが愛着の源」 |
| 育った姿を見る | **えっ、こうなったの**（自分の世話の結果） | §5.3 進化条件は隠されていて友だちと比べた |
| 死ぬ | **もっと構ってあげればよかった**／**ちゃんと見届けた** | §5.7 2位「一生を見届けた愛着」／§3.1 死ぬ仕様は社内の反対を押し切った |

**うまくいったとき** = 「14さいまで見届けた」静かな誇り。**いかないとき** = 「ごめんね」という罪悪感（「損した」ではない）。
**繰り返す理由** = 次の卵で「今度こそ」。

配分の決めごと: 新しい仕掛けを「焦り」だけに注がない。**「しまった」は確率に任せず、ガサツな人の典型行動で必ず1回起きる**ようにする（§3）。

### v4 の芯（v3.1 が外していたこと）

初見者と本家世代のテストが同じことを言った: **失敗が全部「とじている間＝手の届かない場所」で起きるので、後悔が自分の手に紐づかない**。
「押した『とじる』だけが暗転になるなら、いま起きていることは全部自分の選択になり、意味が反転する」（初見者）。
本家世代:「全部やさしいと、あの"自分のせいで死なせた"が一切来ない。こちらの落ち度を一つだけ残して」。

v4 は3つ変える。
1. **自動クローズをやめる。** とじるのは自分が「とじる」を押したときだけ。目を離すのは自分の選択
2. **開いている間も、目の前でゆっくり減る。** メーターが減り、放っておけば よわっていくのを、開けた画面で見せる（v3.1 は開いた瞬間に前回の減りがまとめて反映＝手の届かない所で減っていた）
3. **死ぬ前に、開いた状態で予兆を見せる。** 満タン→暗転→即死をやめる。よわると「よぼよぼ」、直さずまた とじたら死ぬ。放置ルートも病気（×目）を必ず通す（本家の記憶＝骸骨と注射器）

## 1. 一行ルール

> **ひらいて せわして とじる。とじれば 時間がとぶ。ほうっておくと よわる。**

```
題材: ポケットの中の小さな液晶で一生を終える生き物「つぶ」
      ※「まめ」は本家の看板キャラの語幹と重なるため捨てた（§12）。形態名も語尾を揃えない
型: nurture。機種 keitai・theme mono（緑がかったモノクロ液晶）。操作 aim
押す: 5つの世話（ごはん・あそぶ・そうじ・くすり・でんき）＋つぶをタップ（なでる）＋「とじる」
押さない: 無い（間違えても「いらない」と首を振るだけ）
失敗: 開けたまま放っておく／とじたまま放っておくと、目の前で よわり・うんち・病気になり、直さなければ死ぬ。全部「自分が目を離した結果」
時間: 開いている間もゆっくり進む（メーターが目の前で減る）。**自動では閉じない**。「とじる」を押すと時間が大きく飛ぶ＝自分で目を離す。一生は8回ほど開けて 55〜70秒
称号: 仲の深さ4段階（ともだち／なかよし／かぞく／あいぼう）
タイトル: 一分一生（slug 不変）。howto「ひらいて せわして とじる」／constraint「1分で一生。ポケットの中の小さな液晶」

── 見せる前提 ──
権利: 借りるのはジャンル共通の文法（メーター・呼び出し・消灯・排泄・薬・分岐・終わり・少数ボタン・モノクロ液晶とビープ・画面上辺のアイコン列）だけ（調査票 §6）。
      卵型・「っち」・特定製品の死の絵柄・キャラの形・看板キャラの語幹は持ち込まない（§12）
映える瞬間: ①開けた目の前でメーターが減り、放っておくと よわっていく ②とじて戻ったらうんちと病気で「しまった」→直して「…まってたよ」 ③開けたら姿が変わっていた ④「ありがと」→たね→芽（早い死は「…しずかだ」）
結果が気になる点: 「何になるのか」「何さいまで生きるか」「今度こそ死なせずに育てられるか」
成否の見えやすさ: 液晶の中の顔・メーター・うんち・×目と汗・Zzz・反転した「！」
```

## 2. 画面と操作（240×320・mono テーマ）

mono では `accent` `good` `bad` が `ink` と同色。**強調は反転（ink 地に bg 抜き）・点滅・太さだけ**で作る。

```
y  0-16   共通HUD（しあわせ／BEST）
y 20-40   左「あさ」「ひる」「よる」（12px）  右「4さい」（16px）   ← 開けるたびに必ず出る。「◯にちめ」は閉じている札の側
y 44-214  液晶の窓（角丸四角・ink の枠線 2px。卵型にしない）。中は1ビット:
            上辺 y48-60: **呼び出し表示**。困りごとがあるとき「！」＋**欲しいものの絵を1つだけ**反転点滅（下の5ボタンと同じ絵）。
              何も無ければ空。※5個のアイコンを上下に二重に並べない（v3.1 で「上のは何」と迷われた。上＝いま欲しいもの、下＝操作）
            左上 y64-: メーター「おなか ●●●○」「きげん ●●○○」（常時。ラベルは反転させない＝反転すると濁点が潰れて「きけん」に読める。●が1つになった行だけ点滅）
            床の線 y=190。つぶ（16×16ドット×4）が中央で2コマでちょこまか。たまにこちらを見る
            うんち（右下・3つ山）・病気（×目＋汗）・ねんね（Zzz）・クマ（ねむれなかった）はここに出る
y 218-238  「とじる」（幅いっぱい・反転のボタン。「とじる（ポケットに しまう）」）
y 242-304  世話ボタン5つ（x=4+i×47・幅44・高さ62）: ごはん／あそぶ／そうじ／くすり／でんき（アイコン列と同じ絵＋9pxラベル）。押した瞬間は反転
y 306-318  手引き（dim）: 「ボタンで せわ・つぶを タップで なでる・とじると じかんが すすむ」
```

- **起動時**: 窓の全ドットが 0.3秒 点灯して消える（液晶の点灯チェック。ほぼタダで「あーーー！」）
- **開いているとき**: ボタンとつぶのタップが効く。**自動では閉じない。** 開いている間もゆっくり時間が進み、
  **おなか・きげんが目の前で減る**（`OPEN_DRAIN` = 5秒で1マス）。呼び出しが鳴ったら応える。放っておくと目の前で よわっていく（§5）
- **とじる**: 「とじる」を押すとポケットへ（**カチッ**＝`click`、液晶がスッと消える）。開けてから 1.2秒は押せない（誤タップ対策）。
  **手で押したときだけ**「ほっ」＋ハート＋2（困りごとが無いとき）。**自分で目を離す**のがこのゲームの選択
- **とじているとき（`CLOSED_DUR` = 2.4秒。時間が飛ぶ）**: 液晶は消えず**暗いまま中が見える**（つぶのシルエットが動く・うんちがポトッと増える・「！」が点滅）。
  画面の下半分に**自分の一日の札**「1にちめ・がっこう…」＋時計。つぶが呼ぶと **ピピッ**（`cue`）。この間に おなか −2・きげん −1・うんち・病気が進む（§3）。
  押しても開かない: 本体が小さく揺れて「…いまは ひらけない」
- **なでる**: 開いているときにつぶをタップ。顔がにこっ＋ハート。点は**1回の「ひらく」に1回 +1**。「なでて」と呼ばれているときは +3
- 判定は `input.tap` のみ。ヒット順: 世話ボタン → とじる → つぶ → 液晶の中 → それ以外（どちらも「ん？」でこちらを見る。**無反応ゼロ**）

## 3. 一生 ── 時間で進む（開いても、とじていても）

たまご（3秒・タップで最短2秒）→ なまえ（5秒で自分で名乗る）→ あかちゃん。
以後は **ゲーム内時間 `t`（孵化を0とする秒）で段階と年齢が上がる。** 開いている間も、とじて飛んでいる間も、`t` は進む。

| 段階 | 年齢 | せいちょうの時刻 | 特徴 |
|---|---|---|---|
| あかちゃん | 0〜1 | ― | 呼び出しが多い。ごはん・なでて中心。昼 |
| こども | 2〜5 | **`t`=12 で①** | あそぶ中心。`t`=8 からうんちが出やすい。夕方 |
| おとな | 6〜10 | **`t`=26 で②（ここで姿が決まる）** | バランス＋おふろの代わりに でんき。夜がくる |
| おとしより | 11〜13 | **`t`=40** | **何も求めない（余白）**。白い眉・杖・ゆっくり。なでるだけ |
| おわかれ | 14 | **`t`=48**（または よわり死） | §7 |

年齢は段階内で `t` に比例して上がる（例: こどもは 2→5）。最期は 14さい前後。本家は日数＝年齢で、長生きは称賛された（調査票 §5.3）。

### 時間の進み方（v4 の芯）

| | 速さ | そのあいだに起きること |
|---|---|---|
| **開いている** | 実時間と同じ（`t` += dt） | おなか・きげんが **5秒で1マス**減る（`OPEN_DRAIN`）。放っておけば目の前で よわる。呼び出しに応えれば戻る |
| **とじている**（2.4秒） | `t` が **8秒ぶん飛ぶ**（`CLOSED_JUMP`） | おなか −2・きげん −1。ごはんを直前にあげていれば 60% うんち。うんち放置で病気（昼50%・**夜100%**）。夜に でんきを消していなければ クマ＋「ねむれなかった…」きげん −2 |

- だから**開けっぱなしは楽だが間延びする**（時間がゆっくり・退屈）。**とじると速く進むが、その隙に悪くなる。** どちらも自分の選択
- 呼び出し（おなか≤1「ごはん」／うんち「そうじ」／病気「くすり」／夜のねむけ「でんき」）は、開いていれば「！」＋アイコン反転、とじていても **ピピッ**（`cue`）。とじたまま鳴りっぱなしで応えないと `missed` +1
- 昼夜: 段階の時刻で「あさ・ひる・よる」。夜（こども終盤・おとな終盤）は Zzz が出て、でんきを消すと「ぐっすり」

### よわりと死（§5 に詳しく。ここは骨子）

- おなか0 または 病気のまま**時間が進むと**、`weak` がゆっくり溜まる（開いている間 3秒で +1、とじている飛びで +1）。**開いた画面で「よぼよぼ…」の予兆が出る**（`weak`≥2 で）
- `weak` が **6** になったら、その場（開でも閉でも）で死ぬ。**開いていれば、よぼよぼの間に世話すれば必ず助かる**（`weak` は世話で 0 に戻る）
- 放置（開けたまま放置／とじたまま放置）は、おなか→うんち→病気→よぼよぼ→死 を**必ず順に通る**（本家の記憶＝骸骨と注射器を、×目で見せる）。約 45〜50秒で死ぬ

## 4. 呼び出しと世話の手応え

- 開けた瞬間・開いている最中に困りごとが起きたら **ピピッ**（`cue` +1。1増やす＝1回鳴る。続けて鳴らすならフレームを分ける）＋アイコン列の該当が反転点滅。困りごとが無ければつぶが小さく跳ねて「げんき！」
- 正しい世話: 絵が動く（もぐもぐ／跳ねる／さっと消える／×目と汗が消える／暗くなる）＋メーターの●＋**ハート**（**5つの世話すべてと なでる・手でとじた「ほっ」に出す**。1系統だけにしない）＋しあわせ
- 困りごとが全部片づくと反転が消え、つぶが**こちらを見てにこっ**（「ほっとする」の絵）。その状態で**手で とじる** → 「ほっ」＋ハート＋ +2
- 間違い（満腹でごはん 等）は首を振るだけ。減点なし
- **`weak` があるときに世話したとき**: どの世話でも（**そうじ・くすりを含む**）「…まってたよ」（許してくれる）。ここで `weak` が 0 に戻る＝罪悪感が愛着に変わる瞬間

## 5. 育ち（せいちょう①②）と かくれた運

統計（flat）: `fed` `played` `cleaned` `cured` `litCount`（消灯成功）`petted` `missed`（呼ばれたまま応えなかった）`weak`（累計・世話で0に戻る前の最大を別に覚える）`weakEver`（一度でも よわったか）`sickDays`（病気になった回数）／`fav`（なでる・あそぶ・ごはん。init）／`lucky`（init 25%・非表示）／`alive`。
ボット用に `phase`（egg/name/open/closed/bye/gone）`phaseAt`・`petThisOpen`・`caredAt` を持つ。

| せいちょう | 条件（上から） | 姿（語尾を揃えない） | 理由の1行 |
|---|---|---|---|
| ① こども（t=12） | `weakEver` かつ `missed` ≥ 2 | **のら**（葉っぱ・傷） | ひとりで がんばったから |
| | `fed` > `played` | **ころ**（まる） | ごはんが すきだから |
| | `played` > `fed` | **ぴょん**（耳が長い） | あそぶのが すきだから |
| | それ以外 | **ぽよ**（ほっぺ） | かまってもらったから |
| ② おとな（t=26） | `lucky` かつ `weakEver` でない かつ `sickDays` = 0 | **きら**（きらきら。+15・以後 ×1.5） | だいじに そだてられたから |
| | のら: おとな期に `missed` が増えなかった | **なつき**（胸にハート） | さいごまで そばに いたから |
| | のら: それ以外 | **たび**（帽子・首巻き） | じぶんの みちを いくから |
| | ころ | **まんまる** | ごはんが だいすきだから |
| | ぴょん | **はね**（羽） | はねるのが すきだから |
| | ぽよ | **もふ**（ふち毛） | たくさん なでられたから |

- 分岐は実測で調整する（v3.1 では「差+2」だと ぽよ に固まった。閾値は実装時に fun で確かめて、根拠を meta のコメントに残す）
- 姿は1ビットのドット（16×16）。**ボディ4体（つぶ・ころ・ぴょん・のら）＋パーツ差分**が原則。ぽよ/まんまる等で独立ボディを足すなら、その分の描画量を密度に見合わせる。顔は矩形・円で 64px 空間に描く。おとしよりは白い眉＋杖、動きが遅い
- 条件は式ではなく**ぼかした一言**で見せる（本家は条件が隠されていた。調査票 §5.3）。**この理由文はキャラに重ねない**（v3.1 で「見せ場が読めない」と指摘。頭上 y=44、キャラは下）

## 6. 得点（しあわせ）と称号

| 何をしたか | しあわせ |
|---|---|
| ぽかぽか／うまれた | +1（3回まで）／+2 |
| 呼び出しに応えた（ごはん・あそぶ・そうじ・くすり・でんき） | +3 |
| 呼ばれる前に満たした（メーターを見て先に） | +4 |
| なでる（1回の「ひらく」に1回）／「なでて」と呼ばれて なでた | +1／+3 |
| せいちょう①②／おとしより | +5／+5／+3 |
| 困りごとが無い状態で とじた | +2（自分で目を離せた） |
| きら | せいちょう時 +15・以後 ×1.5 |
| 最期まで生きた | +10（よわり死は 0） |

芽5つ（しあわせ 20 ごと）。上帯の**中央**に置く（右上だと年齢表示と衝突する。v3.1 の判断）。うんちは3つ山で**目を付けない**（v3.1 で「小さいお友達に見えた」）。
称号: ともだち／なかよし／かぞく／あいぼう。**最後の称号は上手いボットの 2〜11% だけが届く線**。暫定 50／75／100／135 を最初に置いて実測で置き直す。

## 7. おわかれ と 記念（t=48、または よわり死）

| | 最期まで生きた（t=48） | よわり死（`weak`=6 の その場） |
|---|---|---|

## 8. 見た目と音 ── 懐かしさの記号（調査票 §5.8）

- **`theme: 'mono'`**。世界は1ビット（ink と bg）。`dim` はメーターの空き●・呼び出し表示の淡い部分・手引き・芽の未達だけ。`bg2` は窓の外の本体の面
- 液晶の窓は角丸四角＋ink の枠線。**本体は面だけ**（輪郭線・卵型・ストラップ穴・紐は描かない。丸ボタン3つを窓の下に横並びにしない）
- つぶは 2コマの差分アニメで左右にちょこまか。たまにこちらを見る（「ちょこまか動く姿が愛おしい」）
- **音**: 呼び出し＝ピピッ（`cue`）／とじる＝カチッ（`click`）／死＝ピーピー（`cue`×3）。共通シェルは得点でも鳴る
- 文字はひらがな。記号は「！」「…」「Zzz」「×」だけ。手引きや札にカタカナ語（「カード」等）を出さない（「えらんでね」で足りる）
- アイコン5種（茶碗・ボール・ほうき・カプセル・電球）を1ビットで自作。**うんちは3つ山で目を付けない**（v3.1 で「小さいお友達に見えた」）。上辺の呼び出し表示と下のボタンは同じ絵

## 9. ボット（上手い人）

`{ press, px, py }`。フレーム番号は来ないので **`round(s.time×60) % 21 === 0` の1フレームだけ押す**（0.35秒に1手。偶奇で押すと毎秒30タップになる）。
```
たまご: 押す（0.35秒ごと）。なまえ: phaseAt から 0.6秒で左のカード
ひらいている: 病気→くすり／うんち→そうじ／petThisOpen=0→なでる／ねんね中で明かりが点いている→でんき／
             おなか<3→ごはん／きげん<3→あそぶ／困りごとが無くなって 1.2秒たったら とじる
   ※なでるを でんき より先に置く（でんきを先にすると、消灯後に「なでる」へ戻る経路が消える。v3.1 実測）
とじている・おわかれ: 押さない（おわかれは 1.0秒ごとに送る）
```
自動クローズが無いので、開けっぱなしにしない上手いボットは「困りごとを片づけて とじる」を繰り返す。人が開けっぱなしにしても時間は進む（§3）。

## 10. ゲートの見込み（nurture）

- 放置（開けっぱなし or とじっぱなしで世話しない）: おなか→うんち→病気→よぼよぼ→`weak`=6 で死 → 約45〜50秒＋記念 ≈ **55〜60秒**。`idleSurvivalMinSec` は **既定 45 のまま回す**（落ちたら数字を添えて下げる）
- でたらめ（画面全体を一様）: とじる・世話がまばらで、よわりを直しきれず死ぬ。≈25〜35点。上手い ≈100点 → **腕前 3倍前後**
- 上振れ: きら（25%・+15・×1.5）で p90/p50 ≈ 1.3。うんち・病気の回数のぶれが連続的な分散
- 画面が動く間隔: 開いている間 2〜4秒に1回（減り・世話）✓。いつか終わる ✓
- 実装したら 3シードで測り、goals と分岐閾値を置き直す（v3.1 の実測手順どおり）

## 11. ガサツな人の1分（想定）

- たまご連打 → 名前 → 「！ごはん」→ ごはん。**開けたまま少し放置すると、目の前でメーターが減る**（ここで「減るんだ」と分かる）
- 面倒になって「とじる」を押す（自分で目を離す）。カチッ。暗い液晶＋時計。ピピッと鳴る
- 開ける。**うんち＋おなか空き**。そうじとごはん。反転が消えてにこっ。とじる（ほっ）
- **姿が変わっている**。夜。でんきを押さずに とじる（初見の7割）
- 開けたら **クマ「ねむれなかった…」**。うんちを置いていれば **×目の病気＋「よぼよぼ…」**。「しまった、ごめん」→ くすり →「…まってたよ」
- おとなに。夜は でんきを消す。おじいちゃん（何も求めない・なでる）
- 「ありがと」→ たね → 芽 → 記念「ほんとうは なでられるのが すきだった」「14さいまで いきた」→ タップでもう一回
- もう一回: 「今度は放置しすぎず、うんちを片づけて、でんきを消そう」

## 12. 権利

調査票 §6 の線引きどおり。**意図して時代の記号（モノクロ液晶・ドット・ビープ・少数ボタン・上辺のアイコン列）を使う**ので、距離を取る点を明記する:
- キャラ名は「つぶ」（「まめ」は本家の看板キャラの語幹と一致するため捨てた。**最終判断は人**）。形態名は語尾を揃えない
- 液晶の窓は角丸四角（卵型にしない）／本体は面だけで輪郭・ストラップ穴・紐を描かない／丸ボタン3つを横並びにしない
- 「っち」を使わない／死の絵はたね→芽／アイコン・キャラ・文言はすべて自作／製品名をゲーム内・ページ内・共有文に出さない
- `meta.inspiration.original` は名詞句だけ

## 13. 人にしか決められない残り

- **開けた目の前でメーターが減り、放っておくと よわる**のを見て「しまった、ごめん」が来るか（v4 の芯）
- 直したあとの「…まってたよ」で、罪悪感が愛着に変わるか
- 緑の1ビット液晶を見て、本家を知る人が「懐かしい、触りたい」と思うか
- 早く死なせてしまったとき、もう一回やりたくなるか（罰に感じないか）
- 開いている間の減りの速さ（5秒で1マス）・とじの飛び（8秒）・2.4秒のとじ時間の長さ。「つぶ」という名前

## 14. v3.1 → v4（2026-08-22・オーナー判断で骨格変更）

v3.1 の初見者テスト・本家世代テストが同じことを言った: **失敗が全部「とじている間＝手の届かない場所」で起きるので「自分が死なせた・ごめん」が来ない。** これは依頼の核心（「うまくいかないときの気持ちが本家と同じでなければ追体験ではない」）に直結する。骨格を変えた。

| v3.1 | v4 |
|---|---|
| 6秒で自動クローズ | **自動では閉じない。「とじる」を押すのは自分**（目を離すのが自分の選択） |
| 開いた瞬間に前回の減りがまとめて反映（手の届かない所で減っていた） | **開いている間もゆっくり減る（目の前で）。放っておくと目の前で よわる** |

| 8回の turn で年齢が飛ぶ（0→4など）／寿命が見えない | **年齢は時間で連続的に上がる**。段階（あかちゃん〜おとしより）も時間で |
