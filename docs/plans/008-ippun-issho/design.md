# 一分一生（いっぷんいっしょう）── 設計 v3

> v1（反射ゲーム化）・v2（「ダメを作らない」応答ゲーム化）はどちらもオーナーの実機評価で却下。
> 根幹の指摘: **「これをやってどんな気持ちになると正解なのか。うまくいったとき／いかないときの気持ちが本家と同じでなければ、追体験ではない」**。
> v3 は本家と同ジャンルを**調べてから**設計した（[調査票](../../research/virtual-pet-1996.md)）。v1 → [design-v1.md](./design-v1.md)、v2 → [design-v2.md](./design-v2.md)。

## 0. 正解の気持ち（調査で裏付けた感情モデル）

| 場面 | 気持ち | 裏付け（調査票の節） |
|---|---|---|
| 見ていない時間 | **気になる**（ポケットで鳴っている。開けられない） | §5.1 授業中にピーピー／§3.1「常時世話が要らなければ責任を実感できない」（横井） |
| 開けて世話する | **ほっとする**（元気だった／減ってたからあげた。心配が静まる喜び） | §3.1「世話のやけるよろこび」（バンダイのパーパス）／§5.2 「催促されるのが癒やし」 |
| 放っておいた | **しまった、ごめん**（うんちが溜まって病気。慌てて直す） | §5.7 1位「自分が死なせた罪悪感」／§3.1「ままならなさ」（辻） |
| 育った姿を見る | **えっ、こうなったの**（自分の世話の結果。誇らしい／情けない） | §5.3 進化条件は隠されていて友だちと比べた |
| 死ぬ | **もっと構ってあげればよかった**／**ちゃんと見届けた** | §5.7 2位「一生を見届けた愛着」／§3.1 死ぬ仕様は社内の反対を押し切った（横井） |

**うまくいったとき** = 「ちゃんと育った。幸せだったかな」という静かな誇り。
**うまくいかないとき** = 「ごめんね」という罪悪感（「損した」ではない）。
**繰り返したくなる理由** = 次の卵で「今度こそ」（§5.4「リセットはしたくない」）。

v1・v2 に無かったもの: **見ていない時間**と、**放っておいた結果**。本家の核は「呼び出し・排泄・死を全部持っていてままならない」こと（§2 競合比較）。
v2 の「ダメを作らない」は、ガサツな人を守るつもりで核を抜いていた。ガサツな人こそ「しまった」を味わってこそ追体験になる。

## 1. 一行ルール

> **ひらいて、せわして、とじる。とじているあいだに時間がすすむ。**

```
題材: キーホルダーの液晶の中で一生を終える小さな生き物「まめ」（見た目はジャンルの記号＝モノクロ液晶のドット）
型: nurture。機種 keitai・theme mono。操作 aim
押す: 5つの世話（ごはん・あそぶ・そうじ・くすり・でんき）＋キャラをタップ（なでる）＋「とじる」
押さない: （無い。間違えても「いらない」と首を振るだけ）
失敗: 放っておくと おなかが空き・うんちが溜まり・病気になり・**早く死ぬ**。これは罰ではなく「その子に起きたこと」
上がる: 一生は8回の「ひらく」。あかちゃん期は呼び出しが多く、育つと間隔が開く。老いると なでて が増える
称号: 仲の深さ4段階（ともだち／なかよし／かぞく／あいぼう）
タイトル: 一分一生（slug 不変）。howto「ひらいて せわして とじる」／constraint「1分で一生。液晶のキーホルダー育成」

── 見せる前提 ──
権利: 借りるのはジャンル共通の文法（メーター・呼び出し・消灯・排泄・薬・分岐・終わり・少数ボタン・モノクロ液晶とビープ）だけ（調査票 §6）。
      卵型の本体・「っち」・特定製品の死の絵柄（墓＋おばけ／UFO／天使）・キャラの形は持ち込まない
映える瞬間: ①とじているあいだにピピッと鳴って開けられない ②開けたらうんちと病気で「しまった」 ③開けたら姿が変わっていた ④最期の「ありがと」→たね→芽
結果が気になる点: 「何になるのか」「何さいまで生きるか」「今度こそ死なせずに育てられるか」
成否の見えやすさ: 液晶の中の顔・メーター・うんち・汗・Zzz・「！」
```

## 2. 画面と操作（240×320・mono テーマ）

```
y  0-16   共通HUD（しあわせ／BEST）
y 20-40   【今いつか】「2にちめ・あさ」（左・12px）  「4さい」（右・16px）   ← 開けるたびに必ず大きく出る
y 44-214  液晶の窓（角丸の四角。卵型にしない）。中は1ビットの世界:
            床の線 y=190。まめ（16×16ドット×4）が中央で2コマでちょこまか動く
            左上に メーター「おなか ●●●○」「きげん ●●○○」（常時。本家は隠していたが、ガサツな人のために出す）
            右上に 呼び出し「！」（点滅）＋欲しいものの絵（ボタンと同じ絵）
            うんち（右下・3つ山）・汗（病気）・Zzz（ねんね）はここに出る
y 218-238  とじる ボタン（幅いっぱい・「とじる（ポケットに しまう）」）
y 242-304  世話ボタン5つ（x=4+i×47・幅44・高さ62）: ごはん／あそぶ／そうじ／くすり／でんき（24pxの絵＋9pxラベル）
y 306-318  手引き（dim）: 「ボタンで せわ・キャラを タップで なでなで・とじると 時間が すすむ」
```

- **開いているとき**: ボタンとキャラのタップが効く。「とじる」でポケットへ。何もしなければ 6秒で自動で閉じる（ガサツな人のため）。開けてから 1.2秒は閉じられない（誤タップ対策）
- **とじているとき（1.8秒）**: 液晶が暗くなり、画面の真ん中に「じゅぎょうちゅう…」「ねる…」などの**自分の一日**の札と時計。まめが呼ぶと **ピピッ（音）＋「！」＋欲しいものの絵** が札の横に出るが、**押しても開かない**（「…いまは ひらけない」と出す。無反応にしない）。ここが「気になる」
- **なでる**: 開いているときにキャラをタップ。きげん +1（1回の「ひらく」につき2回まで。3回目から「くすぐったい」で点なし）
- 判定は `input.tap` のみ。ヒット順: 世話ボタン → とじる → キャラ → 液晶の中（空タップは「ん？」） → それ以外

## 3. 一生 ── 8回の「ひらく」

1回の「ひらく」= 最大6秒（閉じれば短い）＋ とじている 1.8秒。8回で 50〜62秒。たまご・なまえ・おわかれを足して **55〜70秒**。

| # | いつ（札） | 年齢 | 何が起きるか（開けたときに見えるもの） | とじているあいだの札 |
|---|---|---|---|---|
| 1 | 1にちめ・あさ | 0さい | たまご→孵化（タップで早まる）→**なまえ**（3枚のカード。5秒で自分で名乗る）→ あかちゃん。すぐ「！ごはん」 | がっこうへ（ピピッ） |
| 2 | 1にちめ・ひる | 1さい | おなか −2・きげん −1。うんち 60%。呼び出しが多い（あかちゃん） | ごご（ピピッ） |
| 3 | 1にちめ・よる | 2さい | **せいちょう①（こども）** を開けた瞬間に見る。夜なので眠い→でんき | ねる（8じかん。長い。うんち・おなか） |
| 4 | 2にちめ・あさ | 4さい | 夜のあいだの結果。うんちを置いて寝ると**病気**になっている | がっこう（ピピッ） |
| 5 | 2にちめ・ひる | 6さい | **せいちょう②（おとな）** | ぶかつ（ピピッ） |
| 6 | 2にちめ・よる | 8さい | 眠い→でんき。きげんが高ければ「なでて」をねだる | ねる |
| 7 | 3にちめ・あさ | 11さい | **おとしより**（白い眉・ゆっくり）。なでて が増える。ごはんは少なめでいい | がっこう（…ピピッが 1回だけ） |
| 8 | 3にちめ・ゆうがた | 14さい | **おわかれ**: こちらを向いて「ありがと」→ たね → 芽 → 記念（§7） | — |

- 年齢は「ひらく」ごとに進む（0,1,2,4,6,8,11,14）。本家は日数＝年齢で、10を超えれば長生き（調査票 §5.3「25歳まで育てたのは初めて」）
- **早い死**: 開けたときに「よわっている」（おなか0、または病気を放置）が**4回積み重なる**と、次にとじているあいだに死ぬ。次の「ひらく」で「…しずかだ」→ たね（夜・dim）。放置しっぱなしでも 6回目（約45秒）まで生きる
- 死んだ回以降の「ひらく」は無い（そのまま記念へ）

### とじているあいだに起きること（時間がすすむ）
- おなか −1〜−2（あかちゃん −2・おとしより −1）、きげん −1（遊ばなかったら）
- ごはんの後の とじる で 60% うんち（画面に1つまで）
- うんちを置いたまま とじる → 50% 病気。2回またぐと 100%
- 病気のまま とじる → よわる（+1）。おなか0のまま とじる → よわる（+1）
- ねる の札（#3・#6 の後）: でんきを消していれば きげん +1、点けたままなら −1
- 呼び出しが鳴る（おなか ≤1 で「ごはん」、うんちで「そうじ」、病気で「くすり」）。**鳴っても開けない**

## 4. 呼び出しと世話の手応え

- 開けた瞬間、困りごとがあれば **ピピッ**（`cue` を進めて共通シェルが鳴らす）＋液晶右上に「！」＋絵。なければ まめが小さく跳ねて「げんき！」（ほっとする）
- 世話の順番は自由。正しい世話をすると: 絵が動く（もぐもぐ／跳ねる／さっと消える／汗が消える／暗くなる）＋メーターの●が増える＋ハート1つ＋しあわせ
- 困りごとが全部片づくと「！」が消え、まめが**こちらを見てにこっ**（これが「ほっとする」の絵）
- 間違い（満腹でごはん 等）は首を振るだけ。減点なし
- **4回以上よわらせてから世話したとき**: 「…まってたよ」（許してくれる。ここで罪悪感が愛着に変わる）

## 5. 育ち（せいちょう①②）と かくれた運

統計（flat）: `fed` `played` `cleaned` `cured` `lit`（消灯成功）`petted` `missed`（呼び出しを聞いたのに閉じた回数）`weak`（よわった累計）`sickDays`／`fav`（なでる・あそぶ・ごはん のどれか。init）／`lucky`（init 25%・非表示）。

| せいちょう | 条件（上から） | 姿 | 理由の1行 |
|---|---|---|---|
| ① こども（#3） | `weak` ≥ 2 → **のらまめ**（葉っぱ・傷） | | ひとりで がんばったから |
| | `fed` ≥ `played`+2 → **ころまめ**（まる） | | ごはんが すきだから |
| | `played` ≥ `fed`+2 → **ぴょんまめ**（耳が長い） | | あそぶのが すきだから |
| | それ以外 → **ぽよまめ**（ほっぺ） | | かまってもらったから |
| ② おとな（#5） | `lucky` かつ `weak`=0 かつ `sickDays`=0 → **きらまめ**（きらきら） | | だいじに そだてられたから |
| | のら: `missed`=0（こども期） → **なつきまめ**／それ以外 → **たびまめ**（帽子・首巻き） | | |
| | ころ: `cleaned` ≥ 2 → **つやまめ**／それ以外 → **まんまるまめ** | | |
| | ぴょん: `lit` ≥ 1 → **はねまめ**／それ以外 → **ねぼまめ**（ナイトキャップ） | | |
| | ぽよ: `petted` ≥ 4 → **もふまめ**／それ以外 → **ほそまめ**（すらっと） | | |

姿は 1ビットのドット（16×16）。ボディ4体＋パーツ差分。顔は矩形・円で 64px 空間に直接描く。おとしよりは 白い眉＋杖、動きが遅い。

## 7. おわかれ と 記念（#8、または早い死）

| | 最期まで生きた | 早く死んだ |
|---|---|---|
| 開けたとき | 夕方の液晶。こちらを向いて手を振る「ありがと」（2秒） | 夜の液晶。まめがいない。「…しずかだ」（2秒） |
| たね | 土に沈み→たね→**芽**（`addPop`） | たねだけが落ちている→小さな芽（ゆっくり） |
| 記念（芽の上・0.7秒おき） | 1.「ぽち（もふまめ）は、」 2.「ごはん 9・あそび 6・そうじ 3・なでなで 8」 3.「ほんとうは なでられるのが すきだった」（fav の世話が最多で3回以上なら「いちばん すきだったのは」） 4.「14さいまで いきた」 | 1.「ぽち（ころまめ）は、」 2.（同じ） 3.「ひとりの じかんが ながかった」 4.「6さいで たねに なった」 |
| 見出し | 「ぽち・14さいまで いきた」 | 「ぽち・6さいで」 |
| `over` | 芽が出て 2.5秒後 | 同じ |

`reason()` = 「ぽち（もふまめ）は 14さいまで いきた」／「ぽち（ころまめ）は 6さいで たねになった」。`meta.ending = { color: 'ink', share: true }`。
翼・輪・星・墓・おばけ・UFO は描かない（調査票 §6）。

## 8. 見た目と音 ── 懐かしさの記号（調査票 §5.8）

- **`theme: 'mono'`**（緑がかったモノクロ液晶の色）。世界は1ビット。影も中間色も使わない（`dim` はメーターの空き●と手引きだけ）
- 液晶の窓は**角丸の四角**（卵型にしない）。窓の外は本体色（`bg2`）で、ボタンは本体についているように
- まめは 2コマの差分アニメで左右にちょこまか動く（本家のレビュー「何もしない時もちょこまか動く姿が愛おしい」）
- **ピピッ**: 呼び出し・開けた瞬間の困りごとで鳴る（共通シェルの矩形波。`BaseState.cue` を足した回数ぶん鳴らす）
- 文字はひらがな。記号は「！」「…」「Zzz」だけ
- ボタンの絵: 茶碗・ボール・ほうき・カプセル・電球（v2 のものを1ビットで描き直す）

## 9. ボット（上手い人）

`{ press, px, py }`。押すフレームは `round(s.time×60) % 2 === 0` だけ。
```
たまご: 0.5秒ごとに押す。なまえ: 0.6秒で左のカード
ひらいている: 病気→くすり／うんち→そうじ／ねんね中で明かりが点いている→でんき／おなか<4→ごはん／きげん<4→あそぶ／
             なでる（2回）／全部済んで 1.2秒たったら とじる（0.35秒に1手）
とじている・おわかれ: 押さない（おわかれは1.0秒ごとに送る）
```
でたらめ（共通の aim ボット）は画面全体を押す。とじるボタンを押してしまうと時間が進む＝放置に近づく。

## 10. ゲートの見込み（nurture）

- **`funGate.idleSurvivalMinSec` を 45 → 35 に下げる**（理由を meta に書く）: genre-map の「放置しても壊れない」は農園型の既定。この題材の核は**放っておくと死ぬ**（調査票 §3.1「死ぬ仕様は社内の反対を押し切った」）。放置は6回目（約45秒）で死ぬ設計なので実測は45前後になる見込みだが、基準に寄せて核を削らない
- 初見でも点: 孵化 +2・せいちょう +5 ✓／腕前: 上手い ≈ 75〜90、でたらめ ≈ 20〜30／上振れ: きらまめ（25%）＋最期まで生きた +10 の有無＋うんち・病気の運／画面が動く間隔: 1回の「ひらく」に 2〜4 回 ✓
- `meta.goals` は最初から暫定（50／70／90／105）を置いて測る

## 11. ガサツな人の1分（想定）

- #1: たまご連打 → 名前を押す → 「！ごはん」→ ごはん → 閉じる（or 6秒で勝手に閉じる）
- とじている: ピピッ。「…いまは ひらけない」。気になる
- #2: 開けたらうんち＋おなか空き。そうじとごはん。ほっとする
- #3: 開けたら**姿が変わっている**。夜。でんきを押し忘れて閉じる
- #4: 朝。うんちを置いて寝たので**病気**。「しまった」→ くすり →「…まってたよ」
- #5: おとなに。#6: 夜。#7: おじいちゃん。なでる
- #8: 「ありがと」→ たね → 芽 → 記念「ほんとうは なでられるのが すきだった」「14さいまで いきた」
- もう一回: 「今度はうんちを片づけてから寝かせよう」

## 12. 権利

調査票 §6 の線引きどおり。**意図して時代の記号（モノクロ液晶・ドット・ビープ・少数ボタン）を使う**ので、距離を取る点を明記する:
液晶の窓は角丸四角（卵型にしない）／本体のシルエットを描かない／「っち」を使わない／死の絵はたね→芽／アイコン・キャラ・文言はすべて自作／
ゲーム内・ページ内・共有文に製品名を出さない。`meta.inspiration.original` は名詞句だけ。**最終判断は人**。

## 13. 人にしか決められない残り

- 「とじているあいだに鳴って開けられない」が、気になるか／ただ待たされるか
- 開けたときの「しまった」と、直したあとの「まってたよ」が刺さるか
- 1ビットの緑の液晶を見て、本家を知る人が「懐かしい、触りたい」と思うか
- 早く死なせてしまったとき、もう一回やりたくなるか（罰に感じないか）
- 6秒の自動クローズ・1.8秒の とじている時間 の長さ
