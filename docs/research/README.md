# 既存作の調査

「なぜあれは流行ったのか」を、**企画の話ではなく作り込みの話として特定する**ための場所。

チャリ走、糸通し、当時のFlashゲーム——ああいうものが刺さった理由は、
たいてい「アイデアが良かった」ではなく、**判定の甘さ・演出のタイミング・目標の刻み**のような
細かい積み重ねにある。それを言葉と数値にして持ち帰る。

調べた結果は次のどれかになる。

1. **今も効く工夫** → [../design/feel-catalog.md](../design/feel-catalog.md) に追記し、使えるものは `src/arcade/feel.ts` に実装する
2. **当時だから効いた事情** → この調査ファイルに記録だけして、実装には持ち込まない
3. **効かなかった／再現しても意味がなかった** → カタログの「効かなかったもの」へ

**1 を貯めることが目的**。調査するたびに、次に作るゲームが強くなる状態を作る。

---

## 調べる人と、作るAIは分ける

🔴 **調査で見たものを、そのまま作る側に渡さない。**

このリポジトリは [記憶から作る](../design/memory-first.md) を既定にしている。
調査と矛盾しないように、**役割を分ける**。

| | 調べる（人） | 作る（AI） |
|---|---|---|
| 見てよいもの | 映像・スクショ・実機・移植版 | **渡さない** |
| 持ち帰るもの | **構造と数値**（判定幅・フレーム数・刻み） | これを受け取る |
| 記録先 | `docs/research/*.md`（言葉と数値だけ。**画像を貼らない**） | ここを読む |

「なぜ流行ったか」は調べる。「どう見えたか」は渡さない。
こうしておけば、**調査ファイルは何度でも安全に読み返せる**。

## いつやるか

- 既存作を下敷きにした企画をやる前（**必ず**）
- オリジナルを作っていて「なんか物足りない」と行き詰まったとき
- 面白さゲートは全部緑なのに、遊ぶと面白くないとき

## 守ること

### ① 憶測と実測を書き分ける

行の頭に必ずラベルをつける。

- `実測:` 自分で遊んだ／映像を数えた結果。**数値を伴う**
- `出典:` 記事・公式・インタビュー。**URLを併記**
- `推測:` 上の2つから考えたこと。**推測であると分かる形で書く**

ラベルのない断定を書かない。あとから読んだとき、どこまで確かなのか分からなくなる。

### ② 「面白い」で止めない

- ❌「操作が気持ちいい」「テンポが良い」
- ⭕️「ジャンプの立ち上がりが3フレーム」「着地後6フレームは入力を受け付ける」「失敗から再開まで0.8秒」

数値に落ちていないものは、実装できない＝持ち帰れていない。

### ③ できる限り実際に遊ぶ

移植版・後継作・公式配信があるなら遊ぶ。無ければ実況動画をコマ送りする。
遊ばずに書いた分析は、だいたい当時の記事の受け売りになる。

### ④ 時代の文脈を切り離す

当時効いた理由には「今はもう無い条件」が混ざっている。

| 当時の条件 | 今どうなっているか |
|---|---|
| 通学中の数分・電波が不安定 | 短時間の暇はあるが、競合が桁違いに多い |
| 端末性能が低く、表現が限られた | 制限が無いぶん「粗さ」は演出として選ぶもの |
| 配信サイトのランキングで話題化 | 人に見せる経路がSNS。共有できる形が要る |

**本質（今も効く）と、当時固有（今は効かない）を必ず分ける。**
ここを分けずに再現すると「当時っぽいけど、今遊ぶと退屈」になる。

### ⑤ 法的な線引き（重要）

学ぶのは**設計の原理だけ**。持ち込まないものを明確にする。

| 持ち込まない | 持ち込んでよい |
|---|---|
| タイトル名・キャラクター名・ロゴ | ジャンルの文法（1ボタン、スコアアタック） |
| 画像・音・フォント・コード | 判定の甘さ、演出のタイミングなどの設計原理 |
| 見た目の模写、UIの配置の写し | 「なぜ効くか」の理解 |

動画やページで触れるときは「◯◯を参考に、自分たちで作ったもの」と分かる形にする。
ゲーム内・リポジトリ内に元作品の固有名詞を残さない（このフォルダの調査メモは除く）。

## 書き方

1. [`_template.md`](./_template.md) をコピーして `docs/research/<英小文字の名前>.md` を作る
2. 上から順に埋める。**埋まらない欄は「未調査」と書いて残す**（消さない）
3. 最後の「持ち帰るもの」を必ず埋める。ここが空なら調査した意味がない
4. カタログと実装に反映し、この調査ファイルへリンクを張り返す

進め方の手順は [`.claude/skills/research-classic/SKILL.md`](../../.claude/skills/research-classic/SKILL.md)。
