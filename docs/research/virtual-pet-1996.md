## 2. 遊びの構造 ── ジャンル共通の文法（調査④）

同時代の製品（たまごっち 1996／デジタルモンスター 1997／ギガペット 1997／ポケットピカチュウ 1998／ぎゃおッPi 1996末 ほか）を比べて、
**複数社が独立に採用していた仕組み**＝誰のものでもない文法を特定した。

## 3. なぜ当時刺さったか（調査①②）

### 3.1 作り手・評論の言葉（調査①）

- 出典: 横井: 「餌をやる」「フン掃除をする」世話の面倒さに加え、怠ると「死ぬ」というリアル感が「ブレイクさせた最大の理由」 https://fika.cinra.net/article/201901-yokoikarakawa
- 出典: 辻太郎（バンダイ）: ヒットの核は生き物を制御しきれない**「ままならなさ」**。「死」「うんち」など**玩具業界のタブーに踏み込んだトゲ**が心に刺さった。パーパスは**「世話のやけるよろこびを世界中の人々に。」** https://xtrend.nikkei.com/atcl/contents/18/00536/00012/ ／ https://dime.jp/genre/2049428/
- 出典: 青柳知里（企画）: 「死ぬと、子どもが悲しんで土に埋葬してしまうこともあった。それくらい人の心にちゃんと届く玩具だった」 https://dime.jp/genre/2049428/
- 出典: 本郷武一（初代開発）: 「人の本能に触れる何かを持ったものは、世代も国境も越えてヒットする」 同上
- 出典: 評論（BAM）: 「モノを所有する」から**「関係性を育てる」体験への転換**。画面の中の存在に感情移入する構造は VTuber やスマホ育成と同じで、1996年に先取りした https://boundless-art.com/culture/4583/
- 出典: ロングセラーの要因: 「フォルムも直感的な操作性も変えていない」、「大人が行っているコミュニケーションを疑似体験できる」、「どの世代にもその人ならではの思い出がある」。通信方式（赤外線→Wi-Fi）だけ更新 https://marketingnative.jp/tamagotch/ ／ https://boundless-art.com/culture/4583/
- 出典: 学校では「授業中にまで熱心に世話をする生徒が多く、禁止令を出す学校も多発」 https://www.nippon.com/ja/japan-topics/today11230/

- ユーザーの状況: 出典: 通学バッグに付けて持ち歩き、授業中も鳴る（§5.1）。**見ていない時間があることが前提の遊び**
- 競合と比べて何が違ったか: （調査④で埋める）
- 話題になった経路: 出典: 女子高生→品薄→報道→学校問題、という社会現象の経路（§1）
- **今も通用する部分**: 推測: 「世話が要る→世話すると応える→怠ると困る→死ぬ」の関係性。「ままならなさ」。見ていない時間への気がかり
- **当時だから効いた部分**（持ち込まない）: 推測: 品薄・転売・学校禁止という社会現象そのもの。実時間で数日かける重さ（1分版では時間の圧縮で代替する）

### 5.7 声から読み取れる「刺さっている気持ち」の順位（調査③の判断）

1. **罪悪感・「自分が死なせた」という責任の重さ**
2. **愛着・「一生を見届けた」という重み**
3. **懐かしさ＝余白の「エモさ」**（効率の時代への反動）
4. **面倒くささの先にある愛おしさ**（催促されることが癒やし）
