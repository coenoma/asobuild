# アテレコ ── 声を録って、本ちゃんに整える

**この番組の声は、台本の読み上げではない。**
編集済みの動画（仮音声つき）を**再生しながら、自由に喋る**。映像を止めて喋ってもいい。
その声が本命で、**映像のほうを声に合わせて調整し直して**公開する。

> 原稿（`voice/<slug>.json`）は撮る前の「予定」。アテレコが済んだら、
> 実際に喋った言葉で原稿を書き直す。**原稿が声に合わせる。逆ではない。**

道具は [`video/scripts/atereco.mjs`](../../video/scripts/atereco.mjs)。
声の書式・言い回しは [voice-and-script.md](./voice-and-script.md)（あちらが声の正本）。

---

## 撮る前に確かめる（30秒でよい）

1. 画面収録の設定で **マイク＝オン／システム音＝オフ**
2. **動画を再生しながら、声を出して10秒録る。**
   この2つを同時にやらないと判定にならない（再生していないと、システム音が入る設定でも無音になる）
3. `--extract` → `--blocks` を通して、**ブロックが2つ以上に割れるか**を見る

```bash
cd video
node scripts/atereco.mjs edl/001-nuimichi.json --extract ~/試し録り.mov
node scripts/atereco.mjs edl/001-nuimichi.json --blocks
```

| 結果 | 意味 |
|---|---|
| ブロックが複数、しきい値が -35dB あたり | ✅ そのまま本番へ |
| ブロックが複数、しきい値が -45dB より下 | ⚠️ 録れてはいるが**声が小さい**。マイクを近づけるか入力を上げる |
| **ブロックが1個以下** | ❌ システム音が混ざっているか、声が部屋の音に埋もれている |

しきい値は**録音の大きさに合わせて自動で決まる**（-35 から順に下げて、2つ以上に割れたら止まる）。
使った値が表示されるので、そこを見れば録音の状態が分かる。

## 録り方

1. 現行版の動画を画面に出す（VOICEVOX の仮音声つきで良い。テンポの当たりが分かる）
2. **画面収録を開始**してから再生する。ウィンドウは**再生位置（シークバー）が映る大きさ**で
   —— あとで「どこの話をしているか」「どこで止めたか」を機械と人が特定する手がかりになる
3. 🔴 **録るのはマイクだけ。システム音（内部音声）は録らない設定にする。**
   ここがいちばん事故る。動画の音まで一緒に録れてしまうと、**音が途切れないので発話ブロックに区切れず**、
   仮音声が文字起こしにも混ざる。**収録前に、設定でシステム音がオフになっていることを目で確かめる**
   （QuickTime の画面収録は既定でマイクのみ。CleanShot 等は「システム音を含める」が既定で入っていることがある）
4. **ヘッドホンで聴く**（スピーカーだと仮音声がマイクに回り込んで、3と同じことになる）
5. 自由に喋る。**止めて喋ってよい。言い直してよい**（言い直しは後のほうが本命）。
   無言の区間があってもよい（あとで機械が無音で区切るので、編集の単位になるだけ）

## 声を別録りするとき（良いマイクを使いたい・システム音が切れない）

**基本は1本で済ませる**（画面収録の音声トラックがそのまま声。同期がいらないので楽）。
別のレコーダー（ボイスメモ等）で録るなら、こうする。

1. `--extract` には**声のファイルのほう**を渡す（画面収録ではなく）
2. 画面収録は「どこの話をしていたか」を目で確かめる参照用にする
3. 2つの時計がズレるので、**`--blocks --offset <秒>`** を付ける。
   表に「画面収録では何分何秒か」が併記され、そこを開けば章が決まる

```bash
node scripts/atereco.mjs edl/<slug>.json --extract ~/収録/ボイスメモ.m4a
node scripts/atereco.mjs edl/<slug>.json --blocks --offset 12.5
```

ズレの測り方: **どちらも回し始めてから、手を1回叩く。** 両方の波形で叩いた音を探し、
`画面収録の時刻 − 声の時刻` が `--offset` の値。

## 文字起こし

**高精度のものを使う**（あとで字幕の原稿になるので、ここの精度がそのまま画面の文字の質になる）。

- podmate studio 同梱の whisper（large 系）か、`pm` コマンド（API）で起こす
  （この端末にはどちらもある: `Podmate Studio.app` と `~/.pyenv/shims/pm`）
- 受け渡し形式は **SRT** か **segments JSON**（whisper の `{segments:[{start,end,text}]}`）。
  別の形式で出たら SRT に変換してから渡す

## 1本通しで喋ったとき（001はこれだった）

止めながらでも**通しで1本**録れているなら、ブロックを詰めずに**章で切り分ける**ほうがよい。

- `--cut --keep-gaps` … 章の最初から最後までを丸ごと切る。**間（ま）がそのまま残る**
- 文字起こしの時刻がそのまま使えるので、**字幕を作り直さなくてよい**（ズレの温床が消える）
- 原稿（`voice/<slug>.json`）には各行の `dur` も書く。
  仮声の実測（layout）は人の声に差し替えたあと役に立たない

001の実測: 全体10:55のうち**無音は8%**、長い間は章の切れ目と一致していた。
この程度なら詰めないほうが喋りのリズムが生きる。

### 補足の録り足し

「ここはもっとこう言ったほうがいいかも」を別録りしたら、**1つの章として扱う**のがいちばん楽。
`human/<章ID>.wav` に置いて、EDL に同じIDの章を足すだけ。

取捨は「**本編で言っていないことを足しているか**」で決める。
同じことを言い直しているだけなら、通しのほうが流れがよい（001では3本中1本だけ採った）。

## 本ちゃんに整える手順

```bash
cd video
node scripts/atereco.mjs edl/<slug>.json --extract ~/収録/アテレコ.mov   # 音声を取り出す
node scripts/atereco.mjs edl/<slug>.json --blocks                       # 無音で発話ブロックに区切る
node scripts/atereco.mjs edl/<slug>.json --sheet --srt ~/収録/文字起こし.srt
```

ここで人の作業（唯一の手作業）:
**`voice/<slug>.atereco.json` の各ブロックに `chapter`（章ID）を書く。**
表（`voice/<slug>.atereco.md`）を見ながら、迷ったら画面収録のその時刻を開く。
捨てるブロックは `"skip"`。**動画を止めて喋っていた区間は `paused: true` も書く。**

```bash
node scripts/atereco.mjs edl/<slug>.json --cut --keep-gaps   # 章ごとの human/<章ID>.wav に切り出す
node scripts/atereco.mjs edl/<slug>.json --tighten           # 間を詰める（下記）
node scripts/atereco.mjs edl/<slug>.json --check             # 声の長さと映像の尺を見比べる
```

`--cut` の出力は `voice/<slug>/human/<章ID>.wav`。
`npm run studio` / `npm run build` が **`prep-audio.mjs` 経由で合成に混ぜる**ので、
ブラウザでも書き出しでも、そのまま人の声で鳴る。

## 章の切れ目は「無音の実測」で置く

章の境界を**言葉の途中に置くと、語尾が削れて次の章の頭に破片が入る**
（001で実際に起き、「つなぎが不自然」と指摘された。「上がってますね」の「ね」が
欠けて、次章の頭に混ざっていた）。

- 境界の候補時刻の前後を `silencedetect` で見て、**本当の無音の中**に置く
- 章を切り直したら、**つなぎ目だけを音つきでレンジ描画して聴く**
  （`--frames=A-B --scale=0.5` で数十秒で出る。全部を書き出して確かめない）
- 章のつなぎの「プツッ」は波形の直切りが原因。**prep-audio が毎回 40ms のフェードを
  自動で焼く**ので、手で処理しない

## 間（ま）を詰める

1本通しで喋ると必ず間ができる。喋るぶんには自然でも、動画にすると**テンポが悪い**。

```bash
node scripts/atereco.mjs edl/<slug>.json --tighten --keep 0.22 --min 0.35
```

- `--min` より長い無音を `--keep` まで縮める。**喋りは1文字も削らない**
- 「元の時刻 → 詰めたあとの時刻」の対応表（`voice/<slug>.tighten.json`）が出るので、
  **字幕と映像の時刻を機械的に引き直せる**（別々に直すとズレる）
- 001の実測: 既定（0.35/0.6）で41秒、強め（0.22/0.35）で**62秒**詰まった。**強めでちょうどよかった**

### 捨てる区間（言い直し・要らない一言）

`voice/<slug>.drops.json` に**章のなかの秒**で書くと、間詰めと同じ回で落ちる。

```json
{ "brushup": [[28.19, 33.04]], "end": [[0, 3.44]] }
```

**同じ回で落とすのが肝**（別々にやると時刻の対応が二重になってズレる）。
捨てた区間の字幕は自動で出なくなる。

編集の芯は Podmate Studio と同じ:
**雑音は削る、人間味は削らない。言い直し・長い沈黙は詰め、相槌・笑いは残す。**

### 映像側の調整

`--check` で「声が映像より長い」章が出る。それが**映像を声に合わせる場所**。

1. 章の `dur` を伸ばす（`paused: true` のブロックがある章は、止めて喋った分。
   その時刻の画で**止め絵にして声を聞かせる**のが基本の受け方）
2. 原稿（`voice/<slug>.json`）の `t` を**実際に喋った言葉**へ書き直し、`at` を声の間に合わせる
   —— 字幕は原稿から出るので、これで字幕が声と一致する
3. `node scripts/voice.mjs edl/<slug>.json --apply` → 再描画 → `--mux`
4. `node scripts/sync-check.mjs edl/<slug>.json`（反応の先回り・無音・時計を機械で見る）
5. **人が通しで見る**（声と画のズレの最終判定は耳と目。AIには確かめられない）

## ルール

- **声が正、映像が従。** 声を切り貼りして映像に合わせない
  （例外は事故ノイズと、言い直しの前テイクを落とすことだけ）
- **文字起こしを整えすぎない。**「なんか」「ちょっと」も声の一部。
  整えて均すと死ぬ（[voice-and-script.md](./voice-and-script.md) の実測）。
  直してよいのは誤変換と、書式（`AIに` の半角スペース等）だけ
- **喋っていないことを字幕にしない**（創作禁止3層はここでも効く。原稿は「記録」になる）
- 止めて喋った区間を編集で無かったことにしない。**止めてまで言いたかったこと**なので、
  むしろ画を止めて聞かせる
