## 確認用の作り方

自撮りは縦持ちで撮れていて（回転メタデータつき・3.2GB）、そのままでは見づらい。
**向きを焼き込み、時刻を2つ出した確認用**を作ると、見どころを拾いやすい。

```bash
cd ~/Documents/tmp/nuimichi
ffmpeg -hwaccel videotoolbox -i 自撮り.MOV \
  -filter_script:v /tmp/sf.txt \
  -c:v h264_videotoolbox -b:v 2600k -c:a aac -b:a 128k \
  -movflags +faststart 自撮り_確認用.mp4
```

`/tmp/sf.txt`（改行を消して1行にして渡す）:

```
scale=960:-2,
drawtext=fontfile=<repo>/video/public/fonts/NotoSansJP.ttf:text='自撮り %{eif\:trunc(t/60)\:d\:2}\:%{eif\:mod(trunc(t)\,60)\:d\:2}':x=16:y=14:fontsize=30:fontcolor=white:box=1:boxcolor=black@0.72:boxborderw=8,
drawtext=fontfile=<repo>/video/public/fonts/NotoSansJP.ttf:text='画面 %{eif\:trunc((t-OFFSET)/60)\:d\:2}\:%{eif\:mod(trunc(t-OFFSET)\,60)\:d\:2}':x=16:y=58:fontsize=26:fontcolor=0xffd23f:box=1:boxcolor=black@0.72:boxborderw=7:enable='gte(t,OFFSET)'
```

`OFFSET` は「自撮りが画面収録より何秒早く回り始めたか」（001回は `423`）。
**2つの時刻が出ていると、どちらで指されても EDL に落とせる。**

> 書式は `%{eif\:式\:d\:桁数}`。`%{eif\:式\:02d}` は通らない（実際にハマった）。
