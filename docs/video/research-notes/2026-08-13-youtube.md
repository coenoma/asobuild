# YouTube調査の精査と、採用したこと（2026-08-13）

元調査: `~/dev/coenoma/tmp/Youtube調査/`（2本。Codex版とClaude版）。
対象は ねっと／ずれん／じぴこ（AI開発系）、水ラーメン／エマス（実験系）。

**鵜呑みにしない**ために、主張ごとに「証拠の強さ」を先に判定した。
判定の物差しは、①同一チャンネル内の対照比較があるか（作者・型が同じで題材だけ違う等）、
②複数チャンネルで再現しているか、③外れ値バズを一般化していないか。

---

## 証拠が強く、採用したもの

| 主張 | 証拠 | 強い理由 | 適用先 |
|---|---|---|---|
| **疑問形は「作ってみた」より伸びる** | 同一作者・同一題材で 2.1万 vs 14.2万（7倍） | 作者・型・題材が同じ対照実験 | タイトルの型（video-doctrine） |
| **題材の知名度が再生数の最大変数** | ねっと内で どう森21万〜イナイレ0.4万の50倍差 | 同一チャンネル内の題材別比較 | 企画選び（video-doctrine） |
| **AI名がサムネの「出演者クレジット」** | 3チャンネルの実物サムネ48枚で共通 | 複数チャンネルで再現 | サムネの型（Thumbnail） |
| **実物・物理モノのサムネが強い** | ねっと上位2本（209万・105万）が実写系 | 上位動画に共通・実物確認 | サムネの型 |
| **バグ・珍挙動が最強のコメント誘発** | 複数動画で上位コメントがタイムスタンプ付きバグ引用 | 複数チャンネルで再現 | 撮る前・編集（バグは資産） |
| **シリーズの定型が登録を作る（バズ≠登録）** | ねっと209万バズ後も登録1.78万 vs 定型反復の2チャンネルは着実増 | 対照的な2パターンの実測 | シリーズ戦略 |
| **参加装置（募集・リクエスト・スコア報告）** | 複数チャンネルの固定コメント運用と反応 | 複数チャンネルで再現 | 締め・固定コメント |
| **縦ゲーム画面はショートと相性が良い** | バズのショート起点証言＋各チャンネルの運用 | 経路の証拠あり | ショート切り出しの仕組み |
| **懐かし題材はコメント欄が同窓会になる** | ねっと3DS回の上位コメントが思い出話 | 実コメントの観察 | 固定コメント文案 |

## 証拠が弱い・外れ値と判断し、そのまま採用しなかったもの

| 主張 | 判断 | 理由 |
|---|---|---|
| 「AIを遊ばせる」路線が大きい（209万） | **追わない** | 単発のショート起点バズで、登録転換も低いと調査自身が言っている。番組の主題（実験の記録）と別物 |
| 時間制限なしの方が伸びる | **制約は残す** | 1チャンネルの視聴者の声。うちは制約が番組の企画そのもの。ただし「本気回」を続編に置ける設計は採る（2本立て） |
| 冒頭で完成品を見せる（ねっと型フック） | **見せない方針を維持** | 疑問形（作れるのか？）で引くなら、答えを冒頭に置くのは矛盾。「決定的瞬間の気配」までにする。**これは調査と意図的に違えた判断** |
| 本家酷似のAI生成サムネ＋「※イメージです」 | **採用しない** | 調査自身が「危うい綱渡り」と明記。うちの権利方針と真っ向から矛盾 |
| 尺は8〜13分 | **今は採らない** | 既知チャンネルの慣行であって因果の証拠がない。無名の1本目は密度優先（実測でテンポ差し戻しも経験済み）。素材が持つなら伸ばす |
| 生き物系の数値（1,400万再生等） | 文法だけ借りる | ジャンル成熟度が違う。サムネ・参加装置の文法のみ移植 |

## うちの既存ルールと衝突した点と、その解決

1. **「元作品の名前をタイトルに書かない」（旧ルール） vs 「題材の知名度が最大変数」（調査）**
   → 言及の仕方で切り分けるルールに更新した。「糸通し**みたいな**」「◯◯**風**」のような
   **着想の言及はタイトル・喋り・テロップで可**（もともと rights-and-originality も言及自体は認めていた）。
   **不可なのは**: ゲーム名・配布物・ロゴへの使用、公式と誤認させる書き方、公式素材の使用。
   ※「糸通し」はそもそも一般名詞なのでリスクが一段低い。固有性の強い題材名ほど「っぽい」を必ず挟む。
2. **「完成品をサムネに出さない」（旧ルール） vs 「ゲーム画面のサムネが標準」（調査）**
   → 「**プレイ途中の決定的瞬間はよい。結果（最終スコア・成否・完成の宣言）は出さない**」に精緻化。
