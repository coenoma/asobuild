## 出すときの一式

### タイトル案

型は「AIに『◯◯』って頼んでみた」＝**実験の形**（[video-doctrine.md](../video-doctrine.md) §2）。

| | 案 | 狙い |
|---|---|---|
| A | AIに「糸通しみたいなゲーム作って」って雑に頼んでみた | いちばん実験らしい。「雑に」が効く |
| B | コーヒー1杯ぶんの時間で、AIはゲームを作れるのか | 一般層に届きやすい。制約が主役 |
| C | AIに雑にお願いしたら、元のゲームより面白くなった | 結果を書いてしまっている（この番組ではやらない） |

**A を推します。** 「雑に」が入ると、うまくやった自慢ではなく実験になります。
Cは結果が見えるので押す理由が消えます（参考として残しています）。
