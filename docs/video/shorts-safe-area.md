# ショートの安全域（実機で測った数字）

2026-08-23、**iPhone の YouTube アプリで実際にショートを再生した画面**を撮って測った。
推測ではなく実測なので、**ここに書いた数字を関所として使う**。

計測に使った画面: 1206×2622。9:16 の動画は**幅いっぱいに表示され、上下に 239px ずつ黒帯**が入る
（動画の表示サイズ 1206×2144）。以下はすべて **1080×1920 の動画座標に換算した値**。

---

## 使えない場所（3箇所）

| どこ | 動画座標 | 何があるか |
|---|---|---|
| **上** | `y 0〜50`（この端末）／**端末によっては y 210 付近まで** | 左に戻る矢印（x 40〜100）、右に検索アイコン（x 835〜905） |
| **右** | `x 920〜1080` の `y 1050〜1560` | いいね・コメント・共有・リミックスの縦列（**日本語ラベルのぶん横に広い**） |
| **下** | `y 1435〜1920` | チャンネル名（y 1435〜1495）／動画タイトル（y 1540〜1580）／関連動画チップ（y 1620〜1680） |

### 上がブレる理由（重要）

YouTube のアイコンは**画面**に対して固定されているので、**黒帯が薄い端末ほど動画に深く食い込む**。

| 画面の縦横比 | 黒帯 | アイコンが食い込む深さ（動画座標） |
|---|---|---|
| 20:9（縦長） | 厚い | 〜26px |
| **19.5:9（いまの iPhone の主流）** | — | **〜50px**（実測） |
| 18:9 | 薄い | 〜120px |
| 16:9（古い端末） | なし | 〜213px |

→ **文字は y 160 より下**に置く。全幅の帯なら y 160 から。

## 使ってよい場所

```
        x0                      x920   x1080
   y0   ┌─────────────────────────┬──────┐
        │  ✕ 上（戻る・検索）      │      │
   y160 ├─────────────────────────┴──────┤
        │                                │
        │        ⭕️ ここに全部入れる       │
        │                                │
  y1050 │                         ┌──────┤
        │                         │ ✕ 右 │
  y1420 ├─────────────────────────┴──────┤
        │  ✕ 下（チャンネル名・タイトル）   │
  y1920 └────────────────────────────────┘
```

**文字と、読ませたいものは `y 160〜1420` × `x 0〜910` に収める。**

## アソビルドで実際に起きていたこと（001 のショートを実機で確認）

| 症状 | 原因 |
|---|---|
| 上部の企画タイトル「劇的改善で、ハマるゲームに」に**検索アイコンと戻る矢印が重なる** | 帯が **y 0 から**始まっている。y 160 より下へ |
| 字幕「15分で、出てきた**た**」の右端が**いいね／共有の下に入って読めない** | 字幕が全幅。右 170px を空ける |
| 字幕「自己ベスト、560点ですよ**！**」に**チャンネル名とリミックスが重なる** | 字幕の下端が低すぎる。下 500px を空ける |
| `steps` の右端のチップが画面端ぎりぎり | 同上（右 170px） |

**直し方の優先順**（安い順）:

1. 上部の帯（`pinTitle` / `steps`）を **y 160 から**始める
2. 字幕・`overlays`・`bigText` の左右を **右 170px 空ける**（`pos: 'low'` の帯も同じ）
3. 字幕の下端を **y 1420 より上**にする（下 500px を空ける）
4. `cta.bottomPad` も同じ基準で見直す

## やりがちな失敗（実機で確認したもの）

- **帯を y 0 から置く** → 戻る矢印と検索アイコンが文字に重なる
- **字幕を全幅にする** → 右端の文字が「いいね」「共有」の下に入って読めない
- **字幕を下端 360 に置く** → チャンネル名（y 1435〜）と重なる
- **下 360px だけ空ける** → 足りない。**下は 500px 空ける**

## 測り直したくなったら

実機でショートを再生してスクショを撮り、次の式で動画座標に直す。

```
黒帯 = (画面高 - 画面幅 × 1920/1080) / 2
動画座標 y = (画面 y - 黒帯) / (画面幅 / 1080)
動画座標 x = 画面 x / (画面幅 / 1080)
```

**必ず複数枚（別の場面）を撮る。** 同じ位置に写っているものが YouTube の UI で、変わるものが動画。
