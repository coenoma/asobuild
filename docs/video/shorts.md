# ショートの作り方（レシピ式）

縦 1080×1920 のショートを、**レシピ（`video/edl/shorts/*.json`）→ Remotion** で組む。
2026-08-17 に全面刷新した。それ以前の `scripts/shorts.mjs`（素材の等分チョップ）は廃止。

**このドキュメントが保証するのは「最低品質」**。001 の S1（そうじゃない）を
60点→100点まで磨いたときの処方を、毎回やることとして固定したもの。
ここから下げない。上げるのは自由。

---

## なぜ作り直したか

旧方式（素材をそのまま切って上下に文字）は、2026年のショート環境の調査に全敗した。

| 調査で分かったこと | 旧方式 |
|---|---|
| 評価軸は**完走率とリプレイ**。最初の0.5〜3秒で決まる | 頭に何も起きない |
| **音オン視聴が前提**（テレビと同じ）。無音は「壊れてる」と等価 | 無音 |
| 字幕は**常時・デカく**（60px級）。声のリズムで切り替える | 静止テロップ2枚 |
| **ループ構造**（終わりが頭に接続）がリプレイを作る | ぶつ切り |
| セーフゾーン: 上〜130px / 下〜360px / 右〜120px はUIに食われる | 無視 |
| 「いい場面の等分チョップ」は禁じ手。**最強の一言を頭に** | 等分チョップ |

## アソビルドのショート文法（最低保証）

0. **ショートは切り抜き集ではなく、1本の物語**。骨格は毎回これ:
   **企画を張る**（「AIに"糸通し"を丸投げしたら…」のカード）→ **展開カード**が話を進める
   （「変なのが、できた」「けど、すぐ進化！」）→ **声は証拠**として挟む → **締めの期待とCTA**。
   声の面白い部分を並べただけのものは、初見の視聴者には前提が無いので成立しない
   （001のS2/S3はこれで一度ボツになった。企画カードなしの「声＋字幕」は出さない）

1. **開幕2.5秒以内に「音・動き・読ませる一言」の3つが揃う**。
   型は2つ: タイトルカード型（`titleLines` を1行ずつ叩き込む）／フック型（`hook` の一言＋いきなり映像＋声）。
   どちらも頭にシリーズの音ロゴ（`jingleStart`）を置く
2. **声が主役**。字幕は声のリズムに合わせて分割する。
   1枚3秒以内・**句の切れ目で切る**（文字起こしの機械分割「〜分から/ないんですが」をそのまま使わない。
   手で直したら `noAutoSubs: true`）
3. **言い淀みは中抜き**（「えー」「っぽいけど」）。`voiceSrc.parts` に切れ端を並べれば、
   フェード付きで自動接続される。
   🔴 **切る位置は、切る前に必ず語単位で実測する**（`pm transcribe-local -f json` の words）。
   本編から引き継いだ文単位の転記（gen）の時刻をアテにして切ると、
   語の途中で切れる・別の語が混ざる・**言ってない言葉の字幕を作る**
   （「自己ベスト更新」と書いたが実際の発話は「自己ベスト560点」だった——001の実害3連発）。
   **切り出しの尻は次の発話の頭まで確保する**。転記の行末時刻ぴったりで切ると語尾が欠ける
   （「急に終わりました」の実害。頭の欠けも同じ——「ちょっと」の実害）。
   ⚠️ prep は尻に **+0.05秒** 足して切る。次の発話の頭が0.1秒以内に迫っているときは
   `to` を控えめにしないと次の語頭が混ざる（「…ました。**いが**」の実害）
4. **クライマックスを必ず1つ作る**。「止めてツッコむ」の3点セット:
   `overlays`（ツッコミ文字＋flash）＋ `punches`（パンチイン＋揺れ0.45秒）＋ SEの重ね（`stampHit`+`hit` 等）。
   拍をまたいで出し続けるときは次の拍に `still: true` のoverlayを置く（入りの演出を繰り返さない）
5. **タメを作る**。`titleStagger` で行を遅らせて叩き込む（「その後、修正を頼んだら…」→0.45秒→「革命が！？」）
6. **締めは「次への期待」＋CTA**。本編誘導型（エンディングカード＋モザイク小窓＝続きは見せない）か、
   行動型（「あなたは、何点いける？」＋URLはコメント欄）。CTAは静止のでかバナー（`cta.main`）＋チップ（`cta.sub`）。
   動かさない。カードと小窓の間に置くときは `cta.bottomPad` で位置を合わせる
7. **ループ**。`loopText`（最後0.9秒の接続の一言）で頭に繋ぐ。エンディングカードで締めるなら無しでよい。
   BGMは尻1.2秒でフェードして、頭のジングルに繋がるようにする
8. **音は本編と同じ出所**。BGM=本編と同曲（頂点 **-35.5dB**。本編の-38より2.5dB強い）。
   SE=`src/arcade/sfx.ts` と同じ矩形波シンセ。外から持ち込まない（PUBLIC リポジトリ）
9. **仕上げに毎回ラウドネスを実測して -14 LUFS へ**。
   measure → `volume=<gain>dB` → `alimiter=0.891`（配信基準。ゲインの使い回し禁止。
   loudnorm一発は動的モードに落ちて声が破綻する——本編で実害あり）
10. **画面の主役を隠さない**。置き場は4つ:
    **字幕の無い拍の展開カードは `pos: 'sub'`（字幕の定位置）か `pos: 'top'`（最上部）**。
    下で起きていることを全部見せたいときは `top`、画の見どころが上半分なら `sub`。
    字幕と同時に出すツッコミは `pos: 'low'`（字幕帯のすぐ上）。
    中央（`mid`）に被せてよいのは、リザルトなど**止まっている画**の上だけ（001の実害2回）
11. **改行は意味の切れ目で手で入れる**。titleLines は行ごとに設計、overlay・bigText も `\n` を自分で置く。
    自動折り返しは「それっぽいの、で/きた！」「分かります/か…？」を平気で作る（001の実害）
12. **数字・結果の瞬間は、声と画面を完全同期させる**。「560点ですよ」の声の頭に、
    リザルトの560点が出るフレームを合わせる（**拍を割ってでも**。素材のどの秒に出るかを
    フレーム実測して `video.from` を逆算する）。ズレた同期は気持ちよさが出ない
13. **声が指しているものを、画面に出す**。「表情が無表情ですが」と喋っているのに
    ゲーム画面だけ映っていたら、視聴者には謎（001の実害）。
    顔の話なら自撮り素材（`self-*` クリップ）へ切り替える。指示対象と画は常に一致させる

## 作る手順

```bash
cd video

# 1. レシピを書く（edl/shorts/001-s1-sonja.json などを下敷きに）
# 2. 声の切り出し・尺の実測・字幕注入
node scripts/prep-shorts.mjs
# 3. 確認しながら直す（音つきでスクラブできる）
npm run studio        # → Short-s1-sonja 等のコンポジション
# 4. 書き出し
npx remotion render src/index.ts Short-s1-sonja /tmp/s1.mp4 --public-dir=public
# 5. ラウドネス実測 → 正規化（gain = -14 - input_i）
ffmpeg -i /tmp/s1.mp4 -af loudnorm=I=-14:TP=-1:print_format=json -f null -
ffmpeg -i /tmp/s1.mp4 -af "volume=<gain>dB,alimiter=level_in=1:level_out=1:limit=0.891:attack=5:release=80:level=false" \
  -ar 48000 -c:v copy out/shorts/S1-◯◯-フル.mp4
```

## レシピの部品

| フィールド | 何をするか |
|---|---|
| `hook` | 開幕1.8秒の一言チップ（フック型の開幕） |
| `beats[].titleLines` | 行ごとに設計するタイトルカード（`size` / `marker`=黄マーカー強調） |
| `beats[].titleStagger` | 行を叩き込む間隔（秒）。タメにも使う |
| `beats[].voiceSrc` | 本編アテレコから声を切り出す。`{ch, from, to}` か `{ch, parts:[{from,to},…]}`（中抜き） |
| `beats[].voiceDelay` | 拍の頭に置く無声の間（秒）。フリのテロップ用 |
| `beats[].noAutoSubs` | 字幕の自動注入を止める（手書きに切り替えたら必ず付ける） |
| `beats[].subs` | 下帯の字幕。`gen: true` は prep が作った印（手書きには付けない） |
| `beats[].overlays` | 画面中央のツッコミ。`flash`（白閃光）/ `still`（拍またぎの継続表示） |
| `beats[].punches` | パンチイン（+9%ズーム＋揺れ、0.45秒で減衰） |
| `beats[].video` | ゲーム映像。`mosaic`（見せない）/ `small`（下段小窓）/ `label`（？？？） |
| `beats[].diagram` | 自作図解（線が引かれるアニメ。尺を詰めるほどキビキビ） |
| `beats[].bigText` | 画面中央のでか文字（560点 など）。`bigSize` で大きさ調整 |
| `beats[].bigTyped` | bigText を1文字ずつタイプライター表示（読点でタメ・2文字ごとにぴこ音）。問いかけ・小粋な間に |
| `cta` | 締めバナー。`main`（黄・でか）/ `sub`（黒チップ）/ `bottomPad`（位置調整） |
| `loopText` | 最後0.9秒の「頭に戻る一言」 |
| `bgm` | `{file: 'bgm/main.mp3', gainDb: -35.5}` |

## 出す前のチェックリスト（最低品質の関所）

- [ ] 頭2.5秒以内に、音・動き・一言が揃っている
- [ ] 字幕は1枚3秒以内・句の切れ目・声と食い違っていない
- [ ] クライマックス（overlay＋punch＋SE）が1箇所以上ある
- [ ] 締めにCTA（行動 or 本編誘導）と「次への期待」がある
- [ ] 尺は15〜30秒
- [ ] ラウドネスを**実測して** -14 LUFS 帯（実測値を記録する）
- [ ] セーフゾーン（上130 / 下360 / 右120px）に常設UIを置いていない
- [ ] カード・ツッコミが、その瞬間に見せたいものを隠していない（既定は `pos: 'low'`）
- [ ] 声の頭と尻が欠けていない（切り出しは次の発話の頭まで）
- [ ] 数字・結果の発話と、画面のその表示が同フレーム
- [ ] 改行がぜんぶ意味の切れ目にある（自動折り返しに任せた行がない）
- [ ] **人が音ありで通しで見た**（AIは音の当たり・テンポの体感を確かめられない）

## AIに確かめられないこと

キーフレームの静止画検査（文字位置・演出の発火）まではAIがやる。
**SEの当たり・音量バランス・テンポの体感は人の耳でしか分からない**。
「レンダした」を「確認した」と言わないこと（本編の playtest と同じ思想）。
