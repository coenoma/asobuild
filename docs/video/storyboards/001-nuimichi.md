## 直したいときは

| 直すもの | どこを触るか |
|---|---|
| 文字（テロップ・数字・カード） | `video/edl/*.json` の該当 `text` / `value` / `title` |
| 順番・尺 | 同じく `at` / `dur`（章の `dur` を変えたら中の `at` も動かす） |
| 使う画 | `clips` の `in` / `dur`。切り出し直しが要る |
| 心情の書き方 | `chapters[].mood` |

EDL を直したら、この2つを走らせる。

```bash
cd video
node scripts/extract.mjs edl/001-nuimichi.json                 # 尺と映り込みの検査つき
node scripts/storyboard.mjs edl/001-nuimichi.json > ../docs/video/storyboards/001-nuimichi.md
npx remotion render src/index.ts Episode out/<slug>.mp4
```
