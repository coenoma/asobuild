# テロップの決まり

**動画の見た目は、ゲームの見た目と揃える。**
色は [palette.ts](../../src/arcade/palette.ts) の `keitai` をそのまま使い、
文言は [retro-style.md](../design/retro-style.md) §5 の書き方に従う。

**揃っていること自体がチャンネルの記号になる**（palette.ts に書いてあるのと同じ理由）。

|---|---|---|

**この8色だけ。** 増やしたくなったら、それは文字量が多すぎるサイン。

## 2. 書体とサイズ（1920×1080 基準）

書体は **Noto Sans JP**。太さは 700 / 900 の2つだけ使う。

| 種類 | サイズ | 太さ | 位置 |
|---|---|---|---|
| **章タイトル** | 96px | 900 | 画面中央、2秒 |
| **主役テロップ** | 64px | 900 | 下から 120px、最大2行 |
| **数字の強調** | 160px | 900 | その数字が出ている場所の近く |
| **小注釈** | 34px | 700 | 指したいものの真横 |
| **番組バー** | 30px | 700 | 上端 |
| **出典・補足** | 26px | 700 | 左下 |

### 1行の文字数

**主役テロップは1行16文字まで、2行まで。** 3行になったら文が長すぎる。

> ❌ 「AIが判定の甘さを調整して再度テストを実行しています」
> ⭕️ 「判定を甘くしてもらいました」

## 3. 形（レトロに寄せる）

[retro-style.md](../design/retro-style.md) §6 の「やりすぎない」をそのまま適用する。

| 決まり | 理由 |
|---|---|
| **角丸を使わない**（radius 0） | 当時の画面に角丸はない |
| **ぼかし・グラデーションを使わない** | 同上。影は硬い2pxのオフセットのみ |
| 枠線は 2px、`line` 色 | 太くすると画面が重くなる |
| 帯は `bg` の不透明度 0.93 | 0.82 だとターミナルの文字が透けて読めなくなる（実測） |
| **スキャンライン風フィルタを入れない** | 当時の液晶にスキャンラインはない |

**アニメーションは 0.15秒で出して 0.1秒で消す。** それ以上かけると読む前に次へ行く。
移動は使わず、**不透明度と縦2pxのオフセットだけ**（当時の画面に滑らかな動きはない）。

## 4. テロップは2層ある ── 字幕と、演出

この動画は**通しでずっと喋っている**。文字は次の2層に分かれる。

| 層 | 何か | どこから来るか | 見た目 |
|---|---|---|---|
| **字幕** | 喋りの全文 | **ナレーション原稿**（`video/voice/<slug>.json`）から `voice.mjs --apply` が生成 | 46px・700・小さめの帯 |
| **演出** | デカ文字・数字・カード・小注釈 | 原稿の行に `big` を付ける／EDLに手書き | 64px・900ほか |

- **字幕は手で書かない。** 原稿が声と字幕の両方の源なので、ずれようがない
- 「長い」「死んだ」のような一言は、原稿の行に `big` と `color` を付けると**演出級**で出る
- 数字（232点・560点）・章カード・小注釈（「14分」）は EDL に手書きのまま残す

### 🔴 盤面と**明暗を逆にする**（001のFBで3回作り直した）

**盤面は「暗い地に薄い文字」。** テロップを同じ作りにすると、色も雰囲気も似ていて
「ゲームのUIの一部」に見える。黒い帯にして大きくしても直らなかった（3回指摘された）。

**答えは色相ではなく明度。** 番組の文字は**明るい地に黒い文字**へ振り切る。
盤面と正反対なので、一目で「番組側の文字」に見える。

| | 形 | 実体 |
|---|---|---|
| **字幕（sub）** | 全幅・**明るい帯に黒文字**・上下に太い黒線 | `SUB_BG` `SUB_INK` `SUB_EDGE` / 56px / 800 |
| **演出（main）** | 明るい札＋**太い色枠**＋外側の黒線＋硬い影 | `8px solid C[color]` ＋ `outline 5px` / 82px / 900 |
| **小見出し（note）** | 同じ作りの小さい版 | `4px solid` ＋ `outline 3px` / 38px / 800 |
| **点数の判子（BigNumber right）** | 同じ明るい札。**数字も黒** | 盤面の点数と見分けるため色を使わない |

- 盤面の色（`bg` `bg2` `line` `ink`）を**テロップの地にも文字色にも使わない**
- 色は**枠**にだけ使う（accent＝進んだ / bad＝まずい / good＝よくなった / cool＝仕切り直し）
- 字幕を小さくしない。**スマホで読めるか**が基準
- 演出テロップを画面の**真ん中に置くのは、下が黒のときだけ**。
  映像の上で真ん中に置くと、見せたいもの（一覧・盤面）を隠す

### ゲームの盤面とワイプ

- 盤面は **`fit: contain` ＋ `box`** で全体を見せる。全画面に伸ばすと点数・死因が枠外に出る
- **点数の強調は盤面の外へ**（`BigNumber` の `place: 'right'`）。盤面の真ん中に重ねると、
  ゲーム自身の点数と二重になって「動画が足した点数」に見える
- **プレイ中は自撮りをワイプで入れる**。定位置は**右下** `{x:81, y:50, w:16, h:29}`
  （字幕の帯にかからない高さ。顔の向きに合わせる）

### 部品の一覧（新しいものを作る前にここを見る）

| 部品 | 何のため | 使いどころ |
|---|---|---|
| `timeStamp`（stamp） | 画を止めて経過時間を大きく | 場面の切れ目。1本で4〜6回 |
| `timeStamp`（chip） | 止めずに時刻を隅へ添える | 喋りが時刻に触れるとき |
| `spot` | 画面のここを見て、と指す | 小さな変化（一覧に増えた等） |
| `scrim` | 下の映像を暗くする | 映像を残したまま文字を主役に |
| `loading` | 場面転換 | 章と章のあいだ |
| `punch` | **決めの瞬間**（一気に寄る・止まる・音） | 記録更新・初めて動いた・即死。**1本2〜3回まで**（structure.md §決めの瞬間） |
| `endCard` | 締めのURL | 最後 |

**同じ役割の札をその場で作らない。** 位置も見た目もバラバラになって、画面に謎の札が残る。

### 字幕どうしにすきまを作らない

続けて喋っているところで字幕を一瞬だけ消すと、**帯がまたたいて「読めない謎のテロップ」に見える**。
`voice.mjs --apply` は、次の行が 0.6秒以内なら**すきまなくつなぐ**。
間を置きたいときは原稿の `at` を 0.6秒以上あける（＝意図した間だけが残る）。

### 飾りの位置を % で決め打ちしない

`top: 38%` のように**画面に対する割合**で線や枠を置くと、
文字数や行の有無で中身の高さが変わったとき、**文字の上を線が横切る**（001で実際に起きた）。

- 線・枠・帯は**中身と一緒に縦に積む**（flex の列にして、帯・文字・帯 の順に流す）
- 「この文言なら大丈夫」で決めない。**文言が変わっても壊れない作り**にする
- 共通パーツは毎回そのまま使い回すので、ここを守らないと次回も同じ事故になる

### 締めの案内は、カードに書かずテロップで出す

`EndCard` にお願いの文を並べると、字幕と二重になり、声ともズレる。
**カードは URL だけ**にして、文はナレーション原稿から演出テロップとして出す
（原稿から出す＝声と必ず同期する）。

### 文言の書き方 ── 声に合わせる

**字幕もデカ文字も、原稿から生まれる＝全部「喋り」。**
書き方の本体は [voice-and-script.md](./voice-and-script.md)（yuto-no-tonari の声の写し＋アソビルド差分）。
以下は要点の抜粋。

| 決まり | 例 |
|---|---|
| **一人称は「ぼく」** | 「ぼくは見てるだけ」 |
| **カジュアル＋ですます調** | 「ぶっこみます」「合ってます」 |
| **数字/英字と日本語のあいだに半角スペースを入れない** | `30分` ✅ / `30 分` ❌、`AIに` ✅ / `AI に` ❌ |
| **分かち書きしない** | 「これを飲み干すまでに」✅ /「これを 飲み干す までに」❌ |
| 断言しすぎない・余韻で終える | 「かもしれない」「〜んですけど」 |
| **有益化しない** | 「〜する3つのコツ」「いかがでしたか」は声の外 |
| 絵文字は使わない。「！」は使ってよい | |

### アソビルドでは、感情の上下を足す

同じ人だが、**開発しているときは声が上下する**。ゆとのとなり（落ち着いた語り）より振れ幅を大きくとる。

| 種類 | 書き方 | 例 |
|---|---|---|
| **落ちたとき** | 素で言う。取り繕わない | 「長い」「これ、時間切れじゃない？」「死んだ」 |
| **上がったとき** | 短く、勢いで | 「お、なんかできてる！」「いいね、いいね」「はまるやつだ」 |
| **半信半疑** | 疑問形のまま置く | 「お？いけてそう？」「……なんか考えてる？」 |
| **説明** | ですます調に戻す | 「一覧に並んで、もう開けます」 |

**感情のテロップは説明しない。** 「思ったより時間がかかっています」ではなく「長い」。

### 🔴 本人が書いた文章に、テロップを重ねない

画面のテキストには2種類ある。**重ねてよいのは片方だけ。**

| | 見分け方 | テロップ |
|---|---|---|
| **本人が書いたもの**（依頼文・補足・感想） | **だいたい日本語** | **重ねない。読ませたいから映している** |
| 道具が出したもの（ログ・コマンド・英語の出力） | だいたい英語・記号 | 重ねてよい |

ターミナルを映す回は、本人の日本語がどこにあるかを先に見て、
**空いている側にテロップを置く**（`place` を `top` / `bottom` で選ぶ）。
避けきれないなら、寄せる位置（`origin`）を動かして本人の文章を枠の中央に持ってくる。

### 主語を書かない

テロップは画面のとなりで喋っているもので、文章ではない。

> ❌ 「AIがゲームの雛形を作成しました」
> ⭕️ 「お、なんかできてる！」

### 題材の言及は「〜みたいな」の形で

「糸通し**みたいな**ゲーム」「◯◯**風**」はテロップ・タイトルで使ってよい（言及）。
元作品の**表現**（画・音・ロゴ・名前をゲーム名に使う）は出さない（使用）。
線引きの全体は [rights-and-originality.md](../design/rights-and-originality.md) §言及と使用。

## 5. いつ出すか

| 種類 | タイミング |
|---|---|
| 主役テロップ | **画面でその事が起きる 0.2秒前**。後から出すと説明に見える |
| 数字の強調 | 数字が確定した瞬間（0秒） |
| 章タイトル | 章の頭。前の画を 0.2秒だけ黒で切ってから |
| 小注釈 | 指したいものが画面にある間ずっと |

**同時に出すのは2種類まで。** 主役テロップ＋小注釈、または数字＋小注釈。

## 6. 常時出しておくもの（番組バー）

画面上端に細い帯を1本。**ここだけは最初から最後まで消えない。**

```
┌──────────────────────────────────────────────┐
│ アソビルド  │  ソイラテ1杯  │ ▓▓▓▓▓░░░ │  12:40 / 30:00 │
└──────────────────────────────────────────────┘
   番組名        その回の制約     残量        経過
```

- **残量メーター**は制約の現物（カップ）と連動させる。減っていくのが見えることが仕事
- 経過時間は**開発の実時間**（動画の再生時間ではない）。「30分でここまで来た」が伝わる

## 7. 効果音

**動画の効果音は、ゲームと同じ音源で作る。**
[sfx.ts](../../src/arcade/sfx.ts) の矩形波シンセを Node に移して WAV を書き出す
（`video/scripts/sfx.mjs`）。音源ファイルを買ってこない。

| 場面 | 音 |
|---|---|
| テロップが出る | `tap` |
| 数字が確定する | `score` |
| 記録更新 | `best` |
| うまくいかない・死ぬ | `hit` |
| うまくいった | `jingleGoal` |
| ゲームオーバー | `jingleOver` |
| 章の切り替え | `jingleStart` |

**ゲーム画面を映しているときは、その音を鳴らさない**（ゲーム側の音と二重になる）。

## 8. 素材の扱い

### 画面収録（2560×1664）

そのまま置かない。**必ず寄る。**

| 見せたいもの | 切り出し（元画像の座標） |
|---|---|
| ゲーム画面 | `x 1340, y 330, w 840, h 1065` |
| ターミナル | `x 0, y 110, w 960, h 1440` |
| ブラウザ全体 | `x 960, y 110, w 1600, h 1440` |
| 全景 | `x 0, y 110, w 2560, h 1440` |

**メニューバー（y < 110）は必ず落とす。** 時計・他アプリのアイコン・通知が映る。

### 自撮り（実効 1920×1080）

- **顔は左寄り、右は窓で白飛びしている。右側は使わない**
- ワイプに使うときは **左 55% を切り出して正方形寄りに**する
- 全体的に眠い絵なので、コントラストと彩度を上げる（`video/scripts/extract.mjs` が自動で当てる）
