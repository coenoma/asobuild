# 台本の声 ── ゆとの喋りかた

**ナレーション原稿（`video/voice/<slug>.json`）を書くときの決まり。**
字幕は原稿の全文がそのまま出るので、**ここに書いてあることが画面の文字の声にもなる**。

土台は [`yuto-no-tonari`](https://github.com/coenoma/yuto-no-tonari) の
`style/voice.md`（仕様）と `style/examples.md`（実際の収録から抽出した実例）。
**あちらが本人の声の正**で、ここはアソビルド用の写し＋差分。あちらが変わったらこちらも直す。

---

## 1. 絶対ルール（yuto-no-tonari と同じ）

1. **一人称は「ぼく」**
2. **数字/英字と日本語のあいだに半角スペースを入れない**（`AIに` ✅ / `AI に` ❌、`30分` ✅）
3. **創作禁止（3層）** — 事実・感情・体験。やっていないこと・感じていないことは書かない。
   アソビルドでは**心情の箇条書き（[structure.md](./structure.md) §手順1）に無い感情を足さない**、という形で効く
4. **「有益」に寄せない** — ノウハウ風・まとめ風・「いかがでしたか」系にしない

## 2. 文体の核（yuto-no-tonari と同じ）

| 決まり | 例 |
|---|---|
| **カジュアル＋ですます調**。固くない、馴れ馴れしくもない | 「ぶっこみます」「見てるだけ」 |
| **体言止め＋句点**も声のうち | 「不満は、判定がシビアと、単調。」 |
| **意見は「ぼくの所有物」にする** | 「ぼくは見てるだけ」（一般論で断罪しない） |
| **控えめな推奨・余韻で締める** | 「〜かもしれない」「〜な気がします」 |
| **強い断定の直後に留保を置く** | 「元のより面白いかもしれない」←「かも」が留保 |
| **抽象は身体感覚・具体に落とす** | 「ラテ、減ってきたんですけど」（残り時間の話を現物で言う） |
| 口語は1〜2割 | 「ぶっちゃけ」「しんどい」 |

### 喋りの署名（examples.md で実測されたもの）

- **連結の「〜じゃないですか」「〜なんですよね」**を適度に（同意を取りながら進む）
- **言いかけ→自己訂正→メタ実況**がチャーム。整えて均すと声が死ぬ
  - 例: 「当たっても死なな……**死んだ**」← アソビルド001で実際に使った形
- **親密な問いかけ**（「〜見たことないですかね」）。問いかけ"稼ぎ"ではなく、隣で喋ってる温度

## 3. アソビルドでの差分（ここだけ、あちらと違う）

ゆとのとなりは「散歩しながらの落ち着いた語り」。**アソビルドは開発中の実況**なので、
同じ人のまま**感情の振れ幅を大きくとる**。

| 場面 | 書き方 | 例（001で実際に使った行） |
|---|---|---|
| 落ちたとき | 素で短く。取り繕わない | 「長い」「死んだ」「これ、時間切れじゃない？」 |
| 上がったとき | 短く、勢いで。「！」を使ってよい | 「あ、なんかできてる！」「操作、わかる！」「飲み終わったよー！」 |
| 半信半疑 | 疑問形のまま置く | 「……なんか考えてる？」「あれ、当たっても死なない？」 |
| 説明 | ですます調に戻す | 「一覧に並んで、もう開けます」 |
| しみじみ | 留保と余韻 | 「元のより面白いかもしれない。おそろしや……」 |

- **1行は短く**（読み上げて2〜4秒＝だいたい20字まで）。長い内容は行を割る
- **テンポの上下を作る**: ですます（説明）→ 言い切り（感情）→ ですます、の往復が自然なリズムになる
- 絵文字は使わない。「！」「……」は使ってよい

## 3.5 実際の文字起こしから採った口語の型

拠り所は仕様ではなく **`episodes/*/transcript.md`（実際の喋り）**。そこに毎回出てくる形。

| 型 | 実際の喋り |
|---|---|
| **「〜なんですよね」で閉じる** | 「好奇心でしか動くことができない厄介者なんですよ」 |
| **「〜じゃないですか」で同意を取る** | 「子供の時って、皆さんそうじゃないですか」 |
| **「なんか」「ちょっと」「わりと」でぼかす** | 「なんかこう、部署の目標とか」 |
| **言いかけて自分で言い直す** | 「これどっかで話……まだ話してないか」 |
| **「〜みたいな」で例える／締める** | 「〜みたいなことは、よくやってますね」 |
| **「わかんないですけど」と留保** | 「本当に欲しいかというのは分からないですけど」 |

**逆に、書き言葉に寄ると死ぬ形**（001で実際にダメ出しされた）:

| ❌ 書いた | ⭕️ 言いそう | なぜ |
|---|---|---|
| 操作、わかる！ | あ、操作はわかりますね | 体言止めの感嘆は喋りにならない |
| はじめてのおわり、20点 | 「はじめてのおわり」って書いてある。日本語、ちょっと変じゃないですか？ | **変なものは受け入れずツッコむ** |
| 自分でやると、1本ももちません | デモは平気そうだったのに、自分でやると一瞬で終わります | 何の1本か伝わらない |
| 1本、ふえました | （言わない） | 視聴者に関係のない内輪の数字 |
| いま、誰でも遊べます | 概要欄のURLから、だれでも遊べます | どこから遊ぶのかが無い |
| 自分でやると、一瞬で終わります | 1回で死ぬタイプじゃないのかな／いつ終わるんだ？／あ、終わった／意外と、できるなあ | **映像と食い違っていた**。実際は粘れていた |
| （画面に無い表示を言う） | 画面に出ているものだけを言う | 「はじめてのおわり」は実際には出ていなかった |

**台本を書いたら、その時刻の映像を必ず1枚見る。** 覚えている内容ではなく、映っているものに合わせる。

## 4. やらないこと（声の外）

- ドラマチックな失敗告白型（「〜してしまいました。反省しています」の構え）
- 実況者テンション（「うおおお来たー！！」）。上がるときも**自分の言葉の範囲**で
- 「皆さん」「視聴者の皆様」という距離。話しかけるなら「あなた」か、問いかけの形
- 説明のしすぎ。**字幕は喋りの全文なので、説明しすぎは画面の文字の多さに直結する**

## 5. 書いたら通す確認

- [ ] 声に出して読んで、**ゆとの過去エピソードに混ざって違和感がないか**（判定の物差しは実例バンク）
- [ ] 心情の箇条書きに無い感情を足していないか
- [ ] 1行20字を超える行が続いていないか
- [ ] 「有益」化していないか（コツ・まとめ・教訓の口調が混ざっていないか）
- [ ] 半角スペースが混入していないか（`AI に` → `AIに`）
- [ ] **画面の変な日本語を、そのまま受け入れていないか**（ツッコむ）
- [ ] **AIが実際にやったことと、言っていることが合っているか**（想像で言い換えない）
- [ ] 視聴者に関係のない内輪の数字を言っていないか
